## Joomla

Para código de componente Joomla (controller, model, task, importação, exportação, upload, fila), use a skill `joomla-helpers`: leia o `SKILL.md` dela antes de escrever, abra só a ficha de `references/` da área do pedido e use `scripts/` (`onde.sh` primeiro, `api.sh` para a API, `instalar.sh` para copiar helpers, `checar.sh` antes de entregar). PHP 7.0, Joomla 3/4/5.
Ela fica em `.agents/skills/joomla-helpers/` (no projeto) ou em `~/.agents/skills/joomla-helpers/`. Se não estiver instalada: `npx skills add heuderdev/helpers-joomla --skill joomla-helpers`.
