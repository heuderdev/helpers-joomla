## Joomla

Para qualquer código de componente Joomla (controller, model, task, importação, exportação, upload, fila), siga a skill em `/developer/helpersJoomla/skill-local/SKILL.md`: leia-a antes de escrever, abra só a ficha de `references/` da área do pedido e use os scripts de `scripts/` (`api.sh` para a API, `instalar.sh` para copiar helpers, `checar.sh` antes de entregar). PHP 7.0, Joomla 3/4/5.
