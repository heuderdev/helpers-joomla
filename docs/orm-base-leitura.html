OrmBase: leitura

Buscar registros, valores, contagens e páginas, e processar grandes volumes em lotes.

Visão geral

Os métodos desta página executam a consulta montada com os filtros e depois os limpam. Com softDeletes ligado, registros excluídos nunca aparecem.

Preciso de…Use
uma lista de registrosget()
o primeiro registro que atende aos filtrosfirst()
um registro pelo idfind() / findOrFail()
um registro por outra colunafindBy()
um único valorvalue()
uma lista de valores, ou um mapa id ⇒ nomepluck()
saber se existeexists()
contar, somar, média, mínimo, máximocount(), sum()…
uma página de resultados com totalpaginate()
processar milhares de registroschunk()

Buscando registros

get()executa a consulta

$orm->get(): array

Executa a consulta e devolve todas as linhas como stdClass, com casts aplicados.

Retorna: array de stdClass; vazio se nada for encontrado.

$pedidos = OrmTables::table('#__loja_pedidos')
    ->where('cliente_id', $clienteId)
    ->latest()
    ->get();

if (empty($pedidos)) {
    echo 'Nenhum pedido.';
}

foreach ($pedidos as $pedido) {
    echo $pedido->id . ': ' . $pedido->status . PHP_EOL;
}

first()executa a consulta

$orm->first(): object|null

Como get(), mas com LIMIT 1: devolve só a primeira linha.

$ultimo = OrmTables::table('#__loja_pedidos')
    ->where('cliente_id', $clienteId)
    ->latest()
    ->first();

if ($ultimo !== null) {
    echo $ultimo->total;
}

find()executa a consulta

$orm->find(int $id): object|null

Busca pela chave primária. Descarta filtros montados antes. O id é convertido para inteiro.

$produto = OrmTables::table('#__loja_produtos')->find(10);

findOrFail()executa a consulta

$orm->findOrFail(int $id): object

Como find(), mas lança RuntimeException com código 404 se não encontrar.

try {
    $produto = OrmTables::table('#__loja_produtos')->findOrFail($id);
} catch (RuntimeException $e) {
    if ($e->getCode() === 404) {
        return ApiResponseHelper::notFound('Produto não encontrado.');
    }

    throw $e;
}

findBy()executa a consulta

$orm->findBy(string $coluna, mixed $valor): object|null

Primeiro registro em que $coluna = $valor. Descarta filtros montados antes.

$cliente = OrmTables::table('#__loja_clientes')->findBy('email', 'ana@exemplo.com');

all()executa a consulta

$orm->all(): array

Todos os registros da tabela, ignorando filtros montados antes. Cuidado com tabelas grandes: prefira chunk().

Buscando valores

value()executa a consulta

$orm->value(string $coluna): mixed

O valor de uma coluna da primeira linha encontrada, ou null. Sem casts.

$email = OrmTables::table('#__loja_clientes')
    ->where('id', 7)
    ->value('email');

Não combine com select(): a coluna é acrescentada às já selecionadas, e o valor devolvido é o da primeira.

pluck()executa a consulta

$orm->pluck(string $coluna, string|null $colunaChave = null): array

Os valores de uma coluna, como lista simples. Com $colunaChave, devolve [chave => valor]: perfeito para montar <select>. Respeita limit(). Sem casts.

$ids = OrmTables::table('#__loja_pedidos')
    ->where('status', 'aberto')
    ->pluck('id');                    // ['3', '8', '15']

$opcoes = OrmTables::table('#__loja_produtos')
    ->where('ativo', 1)
    ->orderBy('nome')
    ->pluck('nome', 'id');            // [10 => 'Caneta', 12 => 'Lápis']

foreach ($opcoes as $id => $nome) {
    echo '<option value="' . (int) $id . '">' . htmlspecialchars($nome) . '</option>';
}

Como em value(), não combine com select(). Com chave, se dois registros tiverem a mesma chave, vale o último.

exists()executa a consulta

$orm->exists(): bool

Há ao menos um registro que atende aos filtros? Mais leve que count() > 0.

$emailEmUso = OrmTables::table('#__loja_clientes')
    ->where('email', $email)
    ->where('id', '!=', $idAtual)
    ->exists();

Contagem e agregados

count()executa a consulta

$orm->count(string $coluna = '*'): int

Quantos registros atendem aos filtros. Com uma coluna, conta só os valores não nulos dela.

$abertos = OrmTables::table('#__loja_pedidos')->where('status', 'aberto')->count();
$comEmail = OrmTables::table('#__loja_clientes')->count('email');

Com groupBy(), count() devolve a contagem do primeiro grupo, não o número de grupos. Para contar por grupo, use select(['status', 'COUNT(*) AS total'])->groupBy('status')->get().

sum() / avg() / min() / max()executa a consulta

$orm->sum(string $coluna): float|null $orm->avg(string $coluna): float|null $orm->min(string $coluna): float|null $orm->max(string $coluna): float|null

Soma, média, menor e maior valor da coluna nos registros filtrados. Devolvem null quando não há registros.

$pagos = OrmTables::table('#__loja_pedidos')->where('status', 'pago');

$faturamento = (float) (clone $pagos)->sum('total');   // 0.0 em vez de null
$ticketMedio = (clone $pagos)->avg('total');
$maiorPedido = (clone $pagos)->max('total');

Por devolverem float, não use min/max em colunas de data ou texto: para isso, use orderBy('coluna')->value('coluna').

Paginação

paginate()executa a consulta

$orm->paginate(int $porPagina = 15, int $paginaAtual = 1): array

Executa duas consultas, uma de contagem e uma da página, e devolve os itens e os dados de paginação. Valores menores que 1 viram 1.

Retorna: array com as chaves abaixo.

$resultado = OrmTables::table('#__loja_pedidos')
    ->where('cliente_id', $clienteId)
    ->latest()
    ->paginate(20, InputHelper::uint('pagina', 1, 'get'));

// Em API JSON: itens em 'data', números em 'meta.paginacao' (sem o JPagination)
return ApiResponseHelper::paginated($resultado, 'Pedidos.');
ChaveTipoConteúdo
itensarrayRegistros da página (com casts).
totalintTotal de registros com os filtros.
por_paginaintItens por página.
pagina_atualintPágina pedida.
total_paginasintNúmero de páginas.
paginacaoJPaginationObjeto do Joomla para views HTML (getListFooter()…).

Uma página além da última devolve itens vazio, e o total continua correto.

Processamento em lotes

chunk()executa a consulta

$orm->chunk(int $tamanho, callable $callback): int

Lê os registros em lotes de $tamanho e chama $callback($lote, $numeroDoLote) para cada um. Assim, milhões de linhas são processadas sem estourar a memória. Devolver false no callback interrompe. Sem orderBy(), ordena pela chave primária para os lotes serem estáveis.

Retorna: quantidade de lotes processados.

$arquivo = fopen($caminho, 'w');

OrmTables::table('#__loja_pedidos')
    ->where('status', 'pago')
    ->select(['id', 'cliente_id', 'total', 'created_at'])
    ->chunk(500, function ($lote, $numero) use ($arquivo) {
        foreach ($lote as $pedido) {
            fputcsv($arquivo, [$pedido->id, $pedido->cliente_id, $pedido->total, $pedido->created_at], ',', '"', '\\');
        }

        // return false;   // para parar antes do fim
    });

fclose($arquivo);

Os lotes avançam por OFFSET. Se o callback alterar uma coluna usada no filtro (por exemplo, filtra status = 'pendente' e muda para 'processado'), registros serão pulados. Nesse caso, veja a receita de processamento de fila.
