PlatformHelper

Os helpers de arquivo, log, upload e exportação (LogHelper, FileHelper, ExportHelper, CsvHelper, ChunkHelper e UploadMaster) funcionam no Joomla 3, 4, 5 e 6, no Laravel e em PHP puro com o mesmo código. Esta página mostra como, com um sistema completo montado nas três plataformas.

Visão geral

Os seis helpers não chamam mais JFile, JFolder, JLog, JFactory ou JUri diretamente: passam pelo PlatformHelper.php, que descobre onde está rodando e usa o recurso nativo de cada ambiente. No Joomla, as chamadas vão para as mesmas classes de antes, então os sites que já usam os helpers continuam iguais.

A detecção é automática: _JEXEC definido → Joomla; app() do Laravel ativo → Laravel; senão, PHP puro. Para forçar, use PlatformHelper::setPlatform('php').

Copie o PlatformHelper.php junto com os helpers: cada um o carrega com require_once __DIR__ . '/PlatformHelper.php'. O instalar.sh e o IncludeHelper já tratam ele como dependência.

O sistema de exemplo

Os três exemplos abaixo montam o mesmo cadastro de clientes (nome, e-mail, CPF, cidade, limite de crédito, foto e documento), com quatro fluxos completos. O código de cada plataforma foi executado de ponta a ponta antes de entrar nesta página (veja Como foi testado).

FluxoO que fazHelpers
Importar planilhaRecebe o CSV, mostra a prévia, grava as linhas válidas e devolve um CSV com as recusadas para corrigir.UploadMaster · CsvHelper (preview, import/process, writeRejectedCsv) · ValidationHelper · LogHelper
ExportarBaixa os clientes em CSV (abre certo no Excel), lendo o banco em lotes.ExportHelper (generatorFromQuery, download/csv) · LogHelper
Foto e documentoFoto pública com miniatura; PDF privado que só sai depois do login.UploadMaster (upload, thumbnail, publicData, delete, stream/info) · LogHelper
Rotinas (CLI)Planilha de milhões de linhas em fatias com retomada; backup diário em ZIP e limpeza do que venceu.ChunkHelper (readLines, resumeLines) · ValidationHelper · ExportHelper · FileHelper (createZip, cleanOlderThan, listFiles) · UploadMaster · LogHelper

Em todos eles:

  • Planilhas, rejeitados e documentos ficam numa pasta privada, fora do alcance da URL. Só as fotos ficam numa pasta pública.
  • O passo de confirmação usa o arquivo guardado na sessão, nunca um caminho mandado pelo navegador.
  • Toda escrita exige login e token CSRF; o download de documento passa por permissão e gera log de auditoria.
  • O UploadMaster confere o tipo real do arquivo: um JPG renomeado para .pdf é recusado ("A extensão do arquivo não corresponde ao seu tipo real.").

A tela de importação (igual nas três)

O mesmo JavaScript serve às três plataformas: as URLs vêm dos atributos data-previa e data-confirmar do formulário, e o token CSRF é um campo escondido dele. O texto que vem do servidor (e da planilha) é sempre inserido com textContent, nunca como HTML. As telas de cada plataforma estão nas seções seguintes.

clientes-importacao.js (media/com_clientes/js no Joomla, public/js no Laravel e no PHP puro)
// clientes-importacao.js: envia a planilha, mostra a prévia e confirma a importação.
// O mesmo arquivo serve ao Joomla, ao Laravel e ao PHP puro: as URLs vêm do formulário
// (data-previa e data-confirmar) e o token CSRF é um campo escondido dele.
document.addEventListener('DOMContentLoaded', function () {
    var form = document.getElementById('form-importacao');

    if (!form) {
        return;
    }

    var saida = document.getElementById('resultado-importacao');
    var confirmar = document.getElementById('confirmar-importacao');

    function enviar(url, dados) {
        return fetch(url, {
            method: 'POST',
            body: dados,
            credentials: 'same-origin',
            headers: { 'Accept': 'application/json', 'X-Requested-With': 'XMLHttpRequest' }
        }).then(function (resposta) {
            return resposta.json().then(function (json) {
                if (!resposta.ok) {
                    throw new Error(json.mensagem || json.message || 'Erro ' + resposta.status);
                }

                return json;
            });
        });
    }

    // textContent: o texto vindo do servidor (e da planilha) nunca vira HTML.
    function paragrafo(texto) {
        var p = document.createElement('p');
        p.textContent = texto;

        return p;
    }

    function previa(json) {
        var tabela = document.createElement('table');
        var cabecalho = tabela.insertRow();

        json.colunas.forEach(function (coluna) {
            var th = document.createElement('th');
            th.textContent = coluna;
            cabecalho.appendChild(th);
        });

        json.previa.forEach(function (linha) {
            var tr = tabela.insertRow();

            json.colunas.forEach(function (coluna) {
                tr.insertCell().textContent = linha.dados[coluna] === null ? '' : linha.dados[coluna];
            });
        });

        return tabela;
    }

    form.addEventListener('submit', function (evento) {
        evento.preventDefault();
        confirmar.hidden = true;
        saida.replaceChildren(paragrafo('Enviando a planilha…'));

        enviar(form.dataset.previa, new FormData(form)).then(function (json) {
            saida.replaceChildren(paragrafo(json.mensagem || json.message), previa(json));
            confirmar.hidden = false;
        }).catch(function (erro) {
            saida.replaceChildren(paragrafo(erro.message));
        });
    });

    confirmar.addEventListener('click', function () {
        var dados = new FormData(form);
        dados.delete('planilha');   // o servidor usa a planilha guardada na sessão
        confirmar.hidden = true;
        saida.replaceChildren(paragrafo('Importando…'));

        enviar(form.dataset.confirmar, dados).then(function (json) {
            // Joomla devolve novos/atualizados; Laravel e PHP puro, gravadas.
            var gravadas = json.gravadas !== undefined ? json.gravadas : json.novos + json.atualizados;
            var itens = [paragrafo(json.linhas + ' linhas · ' + gravadas + ' gravadas · ' + json.rejeitadas + ' recusadas')];

            json.erros.forEach(function (erro) {
                itens.push(paragrafo('Linha ' + erro.line + ': ' + erro.message));
            });

            if (json.download_rejeitados) {
                var link = document.createElement('a');
                link.href = json.download_rejeitados;
                link.textContent = 'Baixar as linhas recusadas para corrigir e importar de novo';
                itens.push(link);
            }

            saida.replaceChildren.apply(saida, itens);
        }).catch(function (erro) {
            saida.replaceChildren(paragrafo(erro.message));
        });
    });
});

Joomla 3, 4, 5 e 6

Um componente de administrador com_clientes. As classes usam só APIs com namespace que existem do Joomla 3.8 ao 6 (Factory, BaseController, Session, Uri), então o mesmo código roda nas quatro versões. A gravação da planilha usa o CsvHelper::import(), que grava direto na tabela pelo OrmTables (inserindo ou atualizando pelo CPF).

A pasta privada fica dentro do site (os helpers só aceitam caminhos dentro de JPATH_SITE), por isso precisa ser bloqueada no servidor web:

Apache
# arquivos/.htaccess (Apache 2.4): nada desta pasta sai pela URL
Require all denied
Nginx
# Nginx: bloqueie a pasta privada no server {} do site
location ^~ /arquivos/ {
    deny all;
}

Sem esse bloqueio, planilhas e documentos ficam acessíveis por quem souber o nome do arquivo. Os nomes são gerados com 32 caracteres aleatórios, mas isso não substitui o bloqueio.

Regras da planilha

Um serviço com as regras usadas pelo controller e pela linha de comando: pasta privada, colunas aceitas, validação e as opções do import(). Ele também carrega os helpers pelo IncludeHelper.

administrator/components/com_clientes/src/Service/ClientesArquivos.php
<?php
// administrator/components/com_clientes/src/Service/ClientesArquivos.php
// Regras da planilha de clientes; usadas pelo controller e pela CLI.

namespace Acme\Component\Clientes\Administrator\Service;

\defined('_JEXEC') or die;

require_once JPATH_ADMINISTRATOR . '/components/com_clientes/helpers/IncludeHelper.php';

\IncludeHelper::load(array('UploadMaster', 'CsvHelper', 'ExportHelper', 'FileHelper', 'ChunkUploadHelper', 'LogHelper'));

class ClientesArquivos
{
    // Pasta privada: na raiz do site, bloqueada no .htaccess ("Require all denied").
    const PRIVADO = 'arquivos/com_clientes';

    // destino => apelidos aceitos no cabeçalho
    const COLUNAS = array(
        'nome' => array('nome', 'nome completo', 'cliente', 'razao social'),
        'email' => array('email', 'e-mail', 'correio'),
        'cpf' => array('cpf', 'documento', 'cpf/cnpj'),
        'cidade' => array('cidade', 'municipio'),
        'limite_credito' => array('limite', 'limite de credito', 'credito')
    );

    const OBRIGATORIAS = array('nome', 'email', 'cpf');

    const REGRAS = array(
        'nome' => 'required|min_length:3|max_length:150',
        'email' => 'required|email',
        'cpf' => 'required|cpf',
        'cidade' => 'max_length:100',
        'limite_credito' => 'numeric|min:0'
    );

    const LABELS = array('email' => 'E-mail', 'cpf' => 'CPF', 'limite_credito' => 'Limite de crédito');

    // A tabela usa criado_em/atualizado_em no lugar de created_at/updated_at.
    const ORM = array('createdAtColumn' => 'criado_em', 'updatedAtColumn' => 'atualizado_em');

    public static function tabela()
    {
        return \OrmTables::table('#__clientes', self::ORM);
    }

    public static function configurar()
    {
        \CsvHelper::setBaseDirectory(self::PRIVADO);
        \ChunkHelper::setBaseDirectory(self::PRIVADO);
    }

    // Opções do CsvHelper::import() para a tabela #__clientes.
    public static function opcoesImportacao()
    {
        return array(
            'columns' => self::COLUNAS,
            'required_columns' => self::OBRIGATORIAS,
            'types' => array('cpf' => 'string', 'limite_credito' => 'decimal'),
            'rules' => self::REGRAS,
            'labels' => self::LABELS,
            'transform' => function (array $linha) {
                $linha['cpf'] = preg_replace('/\D/', '', $linha['cpf']);   // grava só os dígitos

                return $linha;
            },
            'mode' => 'upsert',
            'unique_by' => 'cpf',
            'orm' => self::ORM,                // preenche criado_em e atualizado_em
            'chunk_size' => 500
        );
    }
}

Controller

Uma task por passo. Escritas exigem token (Session::checkToken) e permissão no componente; as respostas são JSON e terminam com $app->close(), para o Joomla não acrescentar o HTML do template.

administrator/components/com_clientes/src/Controller/ArquivosController.php
<?php
// administrator/components/com_clientes/src/Controller/ArquivosController.php
// Tarefas: index.php?option=com_clientes&task=arquivos.importar (e as demais abaixo)

namespace Acme\Component\Clientes\Administrator\Controller;

\defined('_JEXEC') or die;

use Acme\Component\Clientes\Administrator\Service\ClientesArquivos;
use Joomla\CMS\Factory;
use Joomla\CMS\MVC\Controller\BaseController;
use Joomla\CMS\Session\Session;

class ArquivosController extends BaseController
{
    // Passo 1: recebe a planilha e devolve a prévia.
    public function importar()
    {
        $this->exigir('core.create', 'post');
        ClientesArquivos::configurar();

        $arquivo = \UploadMaster::getFileFromInput('planilha');

        if ($arquivo === null) {
            $this->json(422, array('mensagem' => 'Escolha a planilha.'));
        }

        $envio = \UploadMaster::upload($arquivo, ClientesArquivos::PRIVADO . '/importacoes/' . date('Y-m'), null, array(
            'allowed_extensions' => array('csv', 'txt'),
            'max_size' => 20 * 1024 * 1024,
            'prefix' => 'clientes'
        ));

        if (!$envio['success']) {
            $this->json(422, array('mensagem' => $envio['mensagem']));
        }

        // Relativo à pasta privada (base do CsvHelper).
        $planilha = substr($envio['data']['relative_path'], strlen(ClientesArquivos::PRIVADO) + 1);
        $previa = \CsvHelper::preview($planilha, null, 5, array('columns' => ClientesArquivos::COLUNAS));
        $faltando = $previa['success']
            ? array_intersect(ClientesArquivos::OBRIGATORIAS, $previa['data']['missing_columns'])
            : array();

        if (!$previa['success'] || !empty($faltando)) {
            \UploadMaster::delete($envio['data']['relative_path']);
            $this->json(422, array(
                'mensagem' => $previa['success'] ? 'Faltam colunas na planilha: ' . implode(', ', $faltando) . '.' : $previa['mensagem']
            ));
        }

        // O passo 2 usa o arquivo guardado na sessão, nunca um caminho vindo do navegador.
        Factory::getApplication()->setUserState('com_clientes.importacao', $planilha);

        \LogHelper::upload('Planilha de clientes recebida.', array(
            'arquivo' => $planilha,
            'tamanho' => $envio['data']['size_formatted']
        ));

        $linhas = array();

        foreach ($previa['data']['rows'] as $linha) {
            $linhas[] = array('linha' => $linha['line'], 'dados' => $linha['converted']);
        }

        $this->json(200, array(
            'mensagem' => 'Confira a prévia e confirme a importação.',
            'colunas' => array_keys($previa['data']['matches']),
            'previa' => $linhas
        ));
    }

    // Passo 2: grava direto em #__clientes (insere ou atualiza pelo CPF).
    public function confirmar()
    {
        $this->exigir('core.create', 'post');
        ClientesArquivos::configurar();

        $app = Factory::getApplication();
        $planilha = $app->getUserState('com_clientes.importacao');
        $app->setUserState('com_clientes.importacao', null);

        if (!$planilha) {
            $this->json(409, array('mensagem' => 'Envie a planilha antes de confirmar.'));
        }

        $resultado = \CsvHelper::import($planilha, '#__clientes', null, ClientesArquivos::opcoesImportacao());
        $relatorio = $resultado['data'];

        if (empty($relatorio['total_rows']) && !$resultado['success']) {
            $this->json(422, array('mensagem' => $resultado['mensagem']));
        }

        $resposta = array(
            'mensagem' => $resultado['mensagem'],
            'linhas' => $relatorio['total_rows'],
            'novos' => $relatorio['inserted_rows'],
            'atualizados' => $relatorio['updated_rows'],
            'rejeitadas' => $relatorio['errors_count'],
            'erros' => array_slice($relatorio['errors'], 0, 20)
        );

        if ($relatorio['errors_count'] > 0) {
            $rejeitados = \CsvHelper::writeRejectedCsv(
                'rejeitados/' . date('Y-m') . '/' . \ExportHelper::temporaryFileName('clientes-rejeitados'),
                $relatorio['errors'],
                null,
                array('reimportable' => true)
            );

            if ($rejeitados['success']) {
                $app->setUserState('com_clientes.rejeitados', ClientesArquivos::PRIVADO . '/' . $rejeitados['data']['relative_path']);
                $resposta['download_rejeitados'] = 'index.php?option=com_clientes&task=arquivos.rejeitados';
            }
        }

        \LogHelper::info('Importação de clientes concluída.', 'clientes', array(
            'arquivo' => $planilha,
            'novos' => $relatorio['inserted_rows'],
            'atualizados' => $relatorio['updated_rows'],
            'rejeitadas' => $relatorio['errors_count']
        ));

        $this->json(200, $resposta);
    }

    // Passo 3: baixa o CSV das linhas recusadas.
    public function rejeitados()
    {
        $this->exigir('core.create');

        $arquivo = Factory::getApplication()->getUserState('com_clientes.rejeitados');

        if (!$arquivo || !\UploadMaster::exists($arquivo)) {
            $this->json(404, array('mensagem' => 'Nenhuma planilha de rejeitados disponível.'));
        }

        \UploadMaster::stream($arquivo, 'clientes-para-corrigir.csv');   // encerra com $app->close()
    }

    // index.php?option=com_clientes&task=arquivos.exportar&cidade=Curitiba
    public function exportar()
    {
        $this->exigir('core.manage');

        $app = Factory::getApplication();
        $db = method_exists('Joomla\\CMS\\Factory', 'getContainer')
            ? Factory::getContainer()->get('Joomla\\Database\\DatabaseInterface')
            : Factory::getDbo();

        $query = $db->getQuery(true)
            ->select($db->quoteName(array('id', 'nome', 'email', 'cpf', 'cidade', 'limite_credito', 'criado_em')))
            ->from($db->quoteName('#__clientes'))
            ->order($db->quoteName('id'));   // ordem estável: o gerador lê em lotes

        $cidade = $this->input->getString('cidade');

        if ($cidade !== '') {
            $query->where($db->quoteName('cidade') . ' = ' . $db->quote($cidade));
        }

        \LogHelper::info('Exportação de clientes.', 'clientes', array('cidade' => $cidade));

        \ExportHelper::download('clientes-' . date('Y-m-d') . '.csv', \ExportHelper::generatorFromQuery($query), array(
            'id' => 'Código',
            'nome' => 'Nome',
            'email' => 'E-mail',
            'cpf' => array('label' => 'CPF', 'callback' => function ($linha) {
                return preg_replace('/(\d{3})(\d{3})(\d{3})(\d{2})/', '$1.$2.$3-$4', $linha['cpf']);
            }),
            'cidade' => 'Cidade',
            'limite_credito' => array('label' => 'Limite (R$)', 'callback' => function ($linha) {
                return number_format((float) $linha['limite_credito'], 2, ',', '.');
            }),
            'criado_em' => 'Cadastrado em (UTC)'
        ), array('utf8_bom' => true));

        $app->close();   // sem isto, o Joomla acrescenta o HTML do template ao arquivo
    }

    // Foto pública em images/clientes/{id}, com miniatura.
    public function foto()
    {
        $this->exigir('core.edit', 'post');

        $id = $this->input->getInt('id');
        $cliente = ClientesArquivos::tabela()->find($id);

Planilha gigante. O ChunkHelper lê o arquivo em lotes de 1.000 linhas e grava a posição exata num checkpoint depois de cada lote. O callback devolve stop => true perto de 50 s; o próximo cron chama resumeLines() e continua da linha seguinte, sem repetir nem pular nenhuma.

cli/clientes-importar-grande.php
<?php
// cli/clientes-importar-grande.php importacoes/base-completa.csv [segundos]
// Planilhas de milhões de linhas: fatias de até 50 s, continuando de onde parou.
// Cron: * * * * * php /var/www/site/cli/clientes-importar-grande.php importacoes/base-completa.csv
require __DIR__ . '/clientes-bootstrap.php';

use Acme\Component\Clientes\Administrator\Service\ClientesArquivos;

$arquivo = isset($argv[1]) ? $argv[1] : '';                   // relativo a arquivos/com_clientes
$segundos = isset($argv[2]) ? (int) $argv[2] : 50;
$checkpoint = 'checkpoints/' . md5($arquivo) . '.json';
$inicio = microtime(true);
$colunas = array('nome', 'email', 'cpf', 'cidade', 'limite_credito');   // ordem das colunas no arquivo

$info = ChunkHelper::info($arquivo);

if (!$info['success']) {
    fwrite(STDERR, $info['mensagem'] . PHP_EOL);
    exit(1);
}

$processar = function (array $linhas, array $status) use ($colunas, $inicio, $segundos) {
    $validas = array();

    foreach ($linhas as $linha) {
        if ($linha['line'] === 1 || trim($linha['value']) === '') {
            continue;                                              // cabeçalho e linhas vazias
        }

        $valores = array_pad(array_slice(str_getcsv($linha['value'], ';'), 0, 5), 5, null);
        $dados = array_combine($colunas, $valores);
        $dados['limite_credito'] = str_replace(array('.', ','), array('', '.'), (string) $dados['limite_credito']);
        $dados['cpf'] = preg_replace('/\D/', '', (string) $dados['cpf']);

        $validacao = ValidationHelper::validate($dados, ClientesArquivos::REGRAS, array(), ClientesArquivos::LABELS);

        if (!$validacao['valid']) {
            LogHelper::warning('Linha recusada na importação grande.', 'clientes', array(
                'linha' => $linha['line'],
                'erro' => $validacao['first_error']
            ));

            continue;
        }

        $validas[] = $dados;
    }

    // Um lote por transação; erro de banco desfaz só este lote.
    try {
        DbTransactionHelper::run(function () use ($validas) {
            foreach ($validas as $dados) {
                ClientesArquivos::tabela()->updateOrCreate(array('cpf' => $dados['cpf']), $dados);
            }
        });
    } catch (Throwable $erro) {
        LogHelper::exception($erro, 'clientes');

        return array('stop' => true);                              // tenta de novo no próximo cron
    }

    echo sprintf("linha %d · %s%%\n", $status['line_number'], $status['percentual']);

    return array('stop' => microtime(true) - $inicio > $segundos);
};

$opcoes = array('rows_per_chunk' => 1000, 'checkpoint_path' => $checkpoint);

$resultado = FileHelper::exists(ClientesArquivos::PRIVADO . '/' . $checkpoint)
    ? ChunkHelper::resumeLines($arquivo, $checkpoint, $processar, null, $opcoes)
    : ChunkHelper::readLines($arquivo, $processar, null, $opcoes);

if (!$resultado['success']) {
    LogHelper::error('Importação grande falhou.', 'clientes', array('arquivo' => $arquivo, 'erro' => $resultado['mensagem']));
    fwrite(STDERR, $resultado['mensagem'] . PHP_EOL);
    exit(1);
}

if (!$resultado['data']['completed']) {
    echo "Pausada em {$resultado['data']['percentual']}%: o próximo cron continua.\n";
    exit(0);
}

ChunkHelper::deleteCheckpoint($checkpoint);
LogHelper::info('Importação grande concluída.', 'clientes', array(
    'arquivo' => $arquivo,
    'linhas' => $resultado['data']['line_number'],
    'tamanho' => $info['data']['size_formatted']
));
echo "Concluída.\n";

<?php

namespace App\Services;

use Illuminate\Support\Facades\DB;

// Regras da planilha de clientes e gravação em lote; usado pelo controller e pelo comando Artisan.
class ImportadorClientes
{
    // destino => apelidos aceitos no cabeçalho (o CsvHelper casa por aproximação)
    public const COLUNAS = [
        'nome' => ['nome', 'nome completo', 'cliente', 'razao social'],
        'email' => ['email', 'e-mail', 'correio'],
        'cpf' => ['cpf', 'documento', 'cpf/cnpj'],
        'cidade' => ['cidade', 'municipio'],
        'limite_credito' => ['limite', 'limite de credito', 'credito'],
    ];

    public const OBRIGATORIAS = ['nome', 'email', 'cpf'];

    // Mesmas regras do ValidationHelper (iguais às do Vigia.js no navegador)
    public const REGRAS = [
        'nome' => 'required|min_length:3|max_length:150',
        'email' => 'required|email',
        'cpf' => 'required|cpf',
        'cidade' => 'max_length:100',
        'limite_credito' => 'numeric|min:0',
    ];

    public const LABELS = ['email' => 'E-mail', 'cpf' => 'CPF', 'limite_credito' => 'Limite de crédito'];

    public function opcoes(): array
    {
        return [
            'columns' => self::COLUNAS,
            'required_columns' => self::OBRIGATORIAS,
            'types' => ['cpf' => 'string', 'limite_credito' => 'decimal'],
            'convert' => true,
            'rules' => self::REGRAS,
            'labels' => self::LABELS,
            'chunk_size' => 500,
        ];
    }

    /*
     * Grava um lote do CsvHelper::process(): insere ou atualiza pelo CPF
     * numa transação. Devolver false marca as linhas do lote como erro
     * no relatório (e no CSV de rejeitados).
     */
    public function salvarLote(array $lote): array|false
    {
        $agora = now();

        $linhas = array_map(fn (array $item) => [
            'nome' => $item['data']['nome'],
            'email' => $item['data']['email'],
            'cpf' => preg_replace('/\D/', '', $item['data']['cpf']),
            'cidade' => $item['data']['cidade'] ?? null,
            'limite_credito' => $item['data']['limite_credito'] ?? 0,
            'created_at' => $agora,
            'updated_at' => $agora,
        ], $lote);

        try {
            DB::transaction(fn () => DB::table('clientes')->upsert(
                $linhas,
                ['cpf'],
                ['nome', 'email', 'cidade', 'limite_credito', 'updated_at']
            ));
        } catch (\Throwable $erro) {
            \LogHelper::database($erro, null, ['linhas' => count($linhas)]);

            return false;
        }

        return ['success_rows' => count($linhas)];
    }
}

        $planilha = substr($envio['data']['relative_path'], strlen('storage/app/private/'));
        $previa = \CsvHelper::preview($planilha, null, 5, ['columns' => ImportadorClientes::COLUNAS]);

        $faltando = $previa['success']
            ? array_intersect(ImportadorClientes::OBRIGATORIAS, $previa['data']['missing_columns'])
            : [];

        if (!$previa['success'] || $faltando) {
            \UploadMaster::delete($envio['data']['relative_path']);

            return response()->json([
                'message' => $previa['success'] ? 'Faltam colunas na planilha: ' . implode(', ', $faltando) . '.' : $previa['mensagem'],
            ], 422);
        }

        // O passo seguinte usa o arquivo da sessão, nunca um caminho vindo do navegador.
        $request->session()->put('importacao_clientes', $planilha);

        \LogHelper::upload('Planilha de clientes recebida.', [
            'arquivo' => $planilha,
            'tamanho' => $envio['data']['size_formatted'],
        ]);

        return response()->json([
            'message' => 'Confira a prévia e confirme a importação.',
            'colunas' => array_keys($previa['data']['matches']),
            'previa' => collect($previa['data']['rows'])->map(fn ($linha) => [
                'linha' => $linha['line'],
                'dados' => $linha['converted'],
            ]),
        ]);
    }

    // POST /clientes/importacao/confirmar: grava as linhas válidas e separa as recusadas.
    public function confirmar(Request $request, ImportadorClientes $importador): JsonResponse
    {
        $planilha = $request->session()->pull('importacao_clientes');

        abort_if(!$planilha, 409, 'Envie a planilha antes de confirmar.');

        $resultado = \CsvHelper::process($planilha, [$importador, 'salvarLote'], null, $importador->opcoes());
        $relatorio = $resultado['data'];

        if ($relatorio['total_rows'] === 0 && !$resultado['success']) {
            return response()->json(['message' => $resultado['mensagem']], 422);
        }

        $resposta = [
            'message' => $resultado['mensagem'],
            'linhas' => $relatorio['total_rows'],
            'gravadas' => $relatorio['success_rows'],
            'rejeitadas' => $relatorio['errors_count'],
            'erros' => array_slice($relatorio['errors'], 0, 20),
        ];

        if ($relatorio['errors_count'] > 0) {
            $rejeitados = \CsvHelper::writeRejectedCsv(
                'rejeitados/' . date('Y-m') . '/' . \ExportHelper::temporaryFileName('clientes-rejeitados'),
                $relatorio['errors'],
                null,
                ['reimportable' => true]
            );

            if ($rejeitados['success']) {
                $request->session()->put('rejeitados_clientes', $rejeitados['data']['path']);
                $resposta['download_rejeitados'] = route('clientes.importacao.rejeitados');
            }
        }

        \LogHelper::info('Importação de clientes concluída.', 'clientes', [
            'arquivo' => $planilha,
            'gravadas' => $relatorio['success_rows'],
            'rejeitadas' => $relatorio['errors_count'],
        ]);

        return response()->json($resposta);
    }

<?php

namespace App\Console\Commands;

use App\Services\ImportadorClientes;
use Illuminate\Console\Command;

// php artisan clientes:importar-grande importacoes/base-completa.csv
// Planilhas de milhões de linhas: roda em fatias e continua de onde parou (agendado a cada minuto).
class ImportarClientesGrande extends Command
{
    protected $signature = 'clientes:importar-grande {arquivo : relativo a storage/app/private} {--segundos=50}';

    protected $description = 'Importa uma planilha gigante de clientes em fatias, com retomada';

    private const COLUNAS = ['nome', 'email', 'cpf', 'cidade', 'limite_credito'];

    public function handle(ImportadorClientes $importador): int
    {
        $arquivo = $this->argument('arquivo');
        $checkpoint = 'checkpoints/' . md5($arquivo) . '.json';
        $inicio = microtime(true);
        $limite = (int) $this->option('segundos');

        $info = \ChunkHelper::info($arquivo);

        if (!$info['success']) {
            $this->error($info['mensagem']);

            return self::FAILURE;
        }

        $processar = function (array $linhas, array $status) use ($importador, $inicio, $limite) {
            $lote = [];

            foreach ($linhas as $linha) {
                if ($linha['line'] === 1 || trim($linha['value']) === '') {
                    continue;   // cabeçalho e linhas vazias
                }

                $valores = array_pad(array_slice(str_getcsv($linha['value'], ';'), 0, 5), 5, null);
                $dados = array_combine(self::COLUNAS, $valores);
                $dados['limite_credito'] = str_replace(['.', ','], ['', '.'], (string) $dados['limite_credito']);

                $validacao = \ValidationHelper::validate($dados, ImportadorClientes::REGRAS, [], ImportadorClientes::LABELS);

                if (!$validacao['valid']) {
                    \LogHelper::warning('Linha recusada na importação grande.', 'clientes', [
                        'linha' => $linha['line'],
                        'erro' => $validacao['first_error'],
                    ]);

                    continue;
                }

                $lote[] = ['line' => $linha['line'], 'data' => $dados];
            }

            if ($lote && $importador->salvarLote($lote) === false) {
                return ['stop' => true];   // erro de banco: para e tenta de novo no próximo minuto
            }

            $this->line(sprintf('linha %d · %s%%', $status['line_number'], $status['percentual']));

            // Para antes do próximo agendamento; o checkpoint guarda a posição exata.
            return ['stop' => microtime(true) - $inicio > $limite];
        };

        $opcoes = ['rows_per_chunk' => 1000, 'checkpoint_path' => $checkpoint];

        $resultado = \FileHelper::exists('storage/app/private/' . $checkpoint)
            ? \ChunkHelper::resumeLines($arquivo, $checkpoint, $processar, null, $opcoes)
            : \ChunkHelper::readLines($arquivo, $processar, null, $opcoes);

        if (!$resultado['success']) {
            \LogHelper::error('Importação grande falhou.', 'clientes', ['arquivo' => $arquivo, 'erro' => $resultado['mensagem']]);
            $this->error($resultado['mensagem']);

            return self::FAILURE;
        }

        if (!$resultado['data']['completed']) {
            $this->info("Pausada em {$resultado['data']['percentual']}%: o próximo agendamento continua.");

            return self::SUCCESS;
        }

        \ChunkHelper::deleteCheckpoint($checkpoint);
        \LogHelper::info('Importação grande concluída.', 'clientes', [
            'arquivo' => $arquivo,
            'linhas' => $resultado['data']['line_number'],
            'tamanho' => $info['data']['size_formatted'],
        ]);
        $this->info('Concluída.');

        return self::SUCCESS;
    }
}

class ManutencaoArquivos extends Command

    protected $signature = 'arquivos:manutencao';

    protected $description = 'Fotografa os clientes em CSV, faz o backup em ZIP e limpa arquivos vencidos';

    public function handle(): int
    {
        $base = 'storage/app/private';
        $dia = date('Y-m-d');

        // 1. Fotografia diária da tabela.
        $exportacao = \ExportHelper::csv(
            'exportacoes/clientes-' . $dia . '.csv',
            \ExportHelper::generatorFromQuery(Cliente::query()->orderBy('id'), 2000),
            ['id', 'nome', 'email', 'cpf', 'cidade', 'limite_credito', 'created_at'],
            $base
        );

        // 2. Backup: o CSV do dia e os documentos do ano num ZIP só.
        $arquivos = $exportacao['success'] ? [$exportacao['data']['file']['relative_path']] : [];
        $documentos = \FileHelper::listFiles('documentos/' . date('Y'), $base, ['recursive' => true, 'filter' => '\.pdf$']);

        foreach ($documentos['success'] ? $documentos['data']['files'] : [] as $documento) {
            $arquivos[] = $documento['relative_path'];
        }

        $zip = \FileHelper::createZip('backups/backup-' . $dia . '.zip', $arquivos, $base, ['overwrite' => true]);

        // 3. Limpeza do que venceu.
        $removidos = collect([
            ['importacoes', 30, ['recursive' => true]],
            ['rejeitados', 7, ['recursive' => true]],
            ['exportacoes', 15, []],
            ['backups', 15, ['filter' => '\.zip$']],
        ])->sum(function ($regra) use ($base) {
            $r = \FileHelper::cleanOlderThan($regra[0], $regra[1], $base, $regra[2]);

            return $r['success'] ? $r['data']['deleted_count'] : 0;
        });

        // Pastas de mês que ficaram vazias (o index.html criado pelos helpers não conta).
        foreach (['importacoes', 'rejeitados'] as $pasta) {
            $meses = \FileHelper::listDirectories($pasta, $base);

            foreach ($meses['success'] ? $meses['data']['directories'] : [] as $mes) {
                \UploadMaster::removeEmptyDirectories($base . '/' . $mes['relative_path'], ['stop_at_directory' => $base . '/' . $pasta]);
            }
        }

        \LogHelper::info('Manutenção diária concluída.', 'manutencao', [
            'exportacao' => $exportacao['success'] ? $exportacao['data']['export']['rows_written'] . ' linhas' : $exportacao['mensagem'],
            'backup' => $zip['success'] ? $zip['data']['added_count'] . ' arquivos' : $zip['mensagem'],
            'arquivos_removidos' => $removidos,

        $this->info(($zip['success'] ? "Backup: {$zip['data']['added_count']} arquivos" : "Falha no backup: {$zip['mensagem']}") . " · removidos: {$removidos}");

        return $exportacao['success'] && $zip['success'] ? self::SUCCESS : self::FAILURE;
    }

    const LABELS = array('email' => 'E-mail', 'cpf' => 'CPF', 'limite_credito' => 'Limite de crédito');

    private $pdo;

    public function __construct(PDO $pdo)
    {
        $this->pdo = $pdo;
    }

    /*
     * Grava um lote do CsvHelper::process() numa transação. Insere ou
     * atualiza pelo CPF. Devolve o formato que o CsvHelper entende:
     * linhas gravadas e erros por linha (que viram o CSV de rejeitados).
     */
    public function salvarLote(array $lote)
    {
        $agora = gmdate('Y-m-d H:i:s');
        $busca = $this->pdo->prepare('SELECT id FROM clientes WHERE cpf = ?');
        $insere = $this->pdo->prepare(
            'INSERT INTO clientes (nome, email, cpf, cidade, limite_credito, criado_em) VALUES (?, ?, ?, ?, ?, ?)'
        );
        $atualiza = $this->pdo->prepare(
            'UPDATE clientes SET nome = ?, email = ?, cidade = ?, limite_credito = ?, atualizado_em = ? WHERE id = ?'
        );

        $gravadas = 0;
        $erros = array();

        $this->pdo->beginTransaction();

        try {
            foreach ($lote as $item) {
                $c = $item['data'];
                $cpf = preg_replace('/\D/', '', $c['cpf']);
                $limite = isset($c['limite_credito']) && $c['limite_credito'] !== null ? $c['limite_credito'] : 0;
                $cidade = isset($c['cidade']) ? $c['cidade'] : null;

                try {
                    $busca->execute(array($cpf));
                    $id = $busca->fetchColumn();

                    if ($id) {
                        $atualiza->execute(array($c['nome'], $c['email'], $cidade, $limite, $agora, $id));
                    } else {
                        $insere->execute(array($c['nome'], $c['email'], $cpf, $cidade, $limite, $agora));
                    }

                    $gravadas++;
                } catch (PDOException $erro) {
                    $erros[] = array('line' => $item['line'], 'message' => 'Não foi possível gravar o cliente.', 'data' => array('row' => $c));
                    LogHelper::database($erro, null, array('linha' => $item['line']));
                }
            }

            $this->pdo->commit();
        } catch (Throwable $erro) {
            $this->pdo->rollBack();
            throw $erro;
        }

        return array('success_rows' => $gravadas, 'skipped_rows' => count($erros), 'errors' => $erros);
    }

    public function buscar($id)
    {
        $stmt = $this->pdo->prepare('SELECT * FROM clientes WHERE id = ?');
        $stmt->execute(array((int) $id));

        return $stmt->fetch() ?: null;
    }

    public function atualizarArquivos($id, array $campos)
    {
        // Só as colunas de arquivo: o nome da coluna nunca vem do usuário.
        $campos = array_intersect_key($campos, array_flip(array('foto', 'foto_miniatura', 'documento')));
        $sets = array();

        foreach (array_keys($campos) as $campo) {
            $sets[] = $campo . ' = ?';
        }

        $stmt = $this->pdo->prepare('UPDATE clientes SET ' . implode(', ', $sets) . ', atualizado_em = ? WHERE id = ?');
        $stmt->execute(array_merge(array_values($campos), array(gmdate('Y-m-d H:i:s'), (int) $id)));
    }
}

$processar = function (array $linhas, array $status) use ($repositorio, $colunas, $inicio, $segundos) {
    $lote = array();
    $erros = 0;

    foreach ($linhas as $linha) {
        if ($linha['line'] === 1 || trim($linha['value']) === '') {
            continue;                                                  // cabeçalho e linhas vazias
        }

        $valores = str_getcsv($linha['value'], ';');
        $dados = array_combine($colunas, array_pad(array_slice($valores, 0, count($colunas)), count($colunas), null));
        $dados['limite_credito'] = str_replace(array('.', ','), array('', '.'), (string) $dados['limite_credito']);   // 1.500,50 → 1500.50
        $validacao = ValidationHelper::validate($dados, ClienteRepositorio::REGRAS, array(), ClienteRepositorio::LABELS);

        if (!$validacao['valid']) {
            $erros++;
            LogHelper::warning('Linha recusada na importação grande.', 'clientes', array(
                'linha' => $linha['line'],
                'erro' => $validacao['first_error']
            ));

            continue;
        }

        $dados['limite_credito'] = (float) $dados['limite_credito'];
        $lote[] = array('line' => $linha['line'], 'data' => $dados);
    }

    if (!empty($lote)) {
        $repositorio->salvarLote($lote);
    }

    echo sprintf("linha %d · %s%%\n", $status['line_number'], $status['percentual']);

    // Para antes do próximo cron; o checkpoint guarda a posição exata.
    return array('stop' => microtime(true) - $inicio > $segundos, 'recusadas' => $erros);
};

$opcoes = array(
    'rows_per_chunk' => 1000,
    'checkpoint_path' => $checkpoint,
    'checkpoint_base_directory' => $base
);

$resultado = FileHelper::exists($base . '/' . $checkpoint)
    ? ChunkHelper::resumeLines($arquivo, $checkpoint, $processar, $base, $opcoes)
    : ChunkHelper::readLines($arquivo, $processar, $base, $opcoes);

if (!$resultado['success']) {
    LogHelper::error('Importação grande falhou.', 'clientes', array('arquivo' => $arquivo, 'erro' => $resultado['mensagem']));
    fwrite(STDERR, $resultado['mensagem'] . PHP_EOL);
    exit(1);
}

if ($resultado['data']['completed']) {
    ChunkHelper::deleteCheckpoint($checkpoint, $base);
    LogHelper::info('Importação grande concluída.', 'clientes', array(
        'arquivo' => $arquivo,
        'linhas' => $resultado['data']['line_number'],
        'tamanho' => $info['data']['size_formatted']
    ));
    echo "Concluída.\n";
} else {
    echo "Pausada em {$resultado['data']['percentual']}%: o próximo cron continua.\n";
}

Configuração do PlatformHelper

No Joomla e no Laravel nada precisa ser configurado. Em PHP puro, configure no bootstrap o que não servir no padrão.

MétodoO que faz
setPlatform($platform)Força 'joomla', 'laravel' ou 'php'.
setRootPath($path)Raiz onde os helpers podem ler e gravar. Caminhos relativos partem dela e nada fora dela é aceito (vale também para ../ e links simbólicos).
setRootUrl($url)URL pública da raiz inteira. Use só quando a raiz toda é servida na web; senão, prefira addPublicPath().
addPublicPath($path, $url)Pasta servida na web e a URL dela. Em PHP puro, só as pastas informadas aqui geram URL (o resto devolve url = null); no Joomla e no Laravel elas se somam às do framework.
setLogPath($path)Pasta padrão dos logs. Precisa estar dentro da raiz.
setPdo(PDO $pdo)Conexão das consultas do ExportHelper em PHP puro.
setUserResolver(callable $fn)Função que devolve o id do usuário logado, gravado no contexto dos logs. Vale em qualquer plataforma.

ExportHelper::fromQuery(), downloadFromQuery() e generatorFromQuery() aceitam SQL em texto e o objeto de query do Joomla; no Laravel, também Query/Eloquent Builder e array($sql, $bindings); em PHP puro, array($sql, $bindings). Fora do Joomla, o gerador pagina com LIMIT ... OFFSET ... (MySQL, PostgreSQL e SQLite).

O que continua só no Joomla

  • CsvHelper::import() grava pelo OrmTables e pelo DbTransactionHelper, que usam a conexão do Joomla (3 a 6). Fora dele, use CsvHelper::process() e grave com o banco do projeto, como nos exemplos de Laravel e PHP puro.

Problemas comuns

SintomaCausa e solução
"O diretório base deve estar dentro de JPATH_SITE."O caminho está fora da raiz permitida. Fora do Joomla, a raiz é a do PlatformHelper: ajuste com setRootPath().
url vem nullO arquivo não está numa pasta servida na web (o esperado para privados). Para fotos: no Laravel, php artisan storage:link; em PHP puro, addPublicPath().
"A extensão do arquivo não corresponde ao seu tipo real."O conteúdo não é do tipo da extensão (ex.: imagem renomeada para .pdf). É a proteção funcionando.
CSV baixado com HTML no fim (Joomla)Faltou $app->close() depois do ExportHelper::download().
Download sem sessão ou com "headers already sent" (Laravel)Use response()->download()/file() em vez de ExportHelper::download()/UploadMaster::stream().
"O arquivo foi alterado desde a criação do checkpoint."A planilha mudou no meio da importação. Apague o checkpoint com ChunkHelper::deleteCheckpoint() e comece de novo.
"Sem conexão: chame PlatformHelper::setPdo($pdo)"Em PHP puro, o ExportHelper::*FromQuery precisa do PDO configurado no bootstrap.
Upload falha só com arquivos grandesLimites do PHP e do servidor: upload_max_filesize, post_max_size e client_max_body_size (Nginx) maiores que o max_size do helper.
