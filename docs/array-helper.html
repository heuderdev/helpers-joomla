ArrayHelper

Arrays e objetos com caminho em notação de ponto (cliente.endereco.cidade, itens.*.preco) e operações de coleção sobre listas de registros: filtrar, agrupar, indexar, ordenar, somar, montar árvore e reorganizar chaves. Funciona igual com o stdClass[] do ORM, o array do json_decode e objetos do Joomla.

Visão geral

require_once JPATH_COMPONENT . '/helpers/ArrayHelper.php';

$pedidos = OrmTables::table('#__loja_pedidos')->where('criado_em', '>=', $inicio)->get();   // stdClass[]

$ids       = ArrayHelper::pluck($pedidos, 'id');                       // ['12', '13', '14']
$porStatus = ArrayHelper::groupBy($pedidos, 'status');                 // ['pago' => [...], 'pendente' => [...]]
$grandes   = ArrayHelper::whereCompare($pedidos, 'total', '>=', 500);
$total     = ArrayHelper::sum($pedidos, 'total');
$cidade    = ArrayHelper::get($cliente, 'endereco.cidade', 'Não informada');
$precos    = ArrayHelper::get($pedido, 'itens.*.preco');               // [100, 50]
  • Sem dependências. PHP 8.2 ou superior; Joomla 4.4, 5 e 6, Laravel e PHP puro (bloqueia só o acesso direto pela URL, como o PlatformHelper).
  • Aceita qualquer estrutura: arrays, stdClass, objetos com propriedades públicas, objetos com __get/__isset (JTable, JObject/CMSObject) e ArrayAccess (Registry, ArrayObject). Pode misturar: array de objetos com arrays dentro.
  • Não altera o que você passa, exceto set(), forget(), pull() e add(), que recebem a variável por referência (e também a devolvem).
  • Erros de uso lançam InvalidArgumentException (caminho de tipo inválido, operador desconhecido, gravar dentro de um texto). Dado ausente nunca lança: devolve o padrão.

SQL primeiro Se o filtro, a soma ou o agrupamento cabem na consulta (where(), sum(), groupBy(), pluck() do OrmBase), faça no banco: trafega menos e usa índice. O ArrayHelper é para o que já está na memória: o JSON de uma API (HttpHelper), o payload de um webhook, as linhas de um formulário, o resultado de uma consulta que você precisa em vários formatos, ou dados de dois bancos diferentes que o SQL não junta.

Caminho em notação de ponto

Todo método que recebe $caminho aceita as mesmas formas:

FormaExemploLê
Texto com pontos'cliente.endereco.cidade'$d['cliente']['endereco']['cidade'] (ou ->cliente->endereco->cidade)
Índice de lista'contatos.0.email', 3primeiro contato; item 3
Lista de segmentos['config', 'smtp.host']chave que tem ponto no nome
Chave literal'smtp.host' quando existe $d['smtp.host']a chave literal vence o caminho
Curinga (get/has)'itens.*.preco', '*.itens.*.sku'lista com o valor de cada item; * aninhado já sai achatado
Closure (métodos de coleção)function ($registro, $chave) { ... }valor calculado por registro

Ler, conferir, gravar e remover

MétodoRetornoO que faz
get($dados, $caminho, $padrao = null)mixedValor no caminho; $padrao se não existir (Closure: chamada só quando precisa). Com *, devolve lista.

add(&$dados, $caminho, $valor)os dadosGrava só se o caminho ainda não existe.

pull(&$dados, $caminho, $padrao = null)mixedLê e remove.

Montar o corpo de uma requisição sem criar cada nível à mão:

$corpo = [];
ArrayHelper::set($corpo, 'cliente.nome', $pedido->nome);
ArrayHelper::set($corpo, 'cliente.documento', FormatHelper::onlyDigits($pedido->cpf));
ArrayHelper::set($corpo, 'entrega.cep', FormatHelper::onlyDigits($pedido->cep));
ArrayHelper::set($corpo, 'valor', FormatHelper::toCents($pedido->total));
// ['cliente' => ['nome' => 'Ana', 'documento' => '12345678909'], 'entrega' => ['cep' => '01310100'], 'valor' => 15000]

$r = $erp->post('/pedidos', $corpo);

null existe Se o campo existe valendo null, get() devolve null, não o padrão, e has() devolve true. Para "vazio ou ausente", use ArrayHelper::get($d, 'campo') ?: $padrao.

Escolher campos: only, except, select

MétodoRetornoO que faz
only($dados, $chaves)arraySó as chaves pedidas (aceita caminho; monta os níveis).
except($dados, $chaves)mesmo tipoTudo menos as chaves; objeto volta como cópia.

Responder sem vazar campos internos, e mandar para a API externa só o que ela aceita:

$cliente = OrmTables::table('#__loja_clientes')->findOrFail($id);

return ApiResponseHelper::success('Cliente.', ArrayHelper::except($cliente, ['senha_hash', 'token_api', 'observacao_interna']));
$clientes = OrmTables::table('#__loja_clientes')->where('sincronizar', 1)->get();

$lote = ArrayHelper::select($clientes, ['id', 'nome', 'email']);
// [['id' => '7', 'nome' => 'Ana', 'email' => 'ana@x.com'], ...]

Filtrar registros

MétodoMantém o registro quando
where($r, $caminho, $valor, $preservarChaves = false, $estrito = true)campo === valor (== com $estrito = false)
whereIn($r, $caminho, $valores, $preservarChaves = false, $estrito = false)campo está na lista
whereNotIn(...)campo não está na lista, ou não existe
whereNull($r, $caminho) / whereNotNull($r, $caminho)campo é null ou não existe / campo existe e não é null
whereCompare($r, $caminho, $operador, $valor, $preservarChaves = false)a comparação é verdadeira (tabela abaixo)
first($dados, $filtro = null, $padrao = null) / last(...)primeiro / último item (que passa no filtro function ($valor, $chave))
partition($dados, $filtro)devolve [$passam, $naoPassam], com as chaves

Por padrão o resultado é reindexado (0, 1, 2…); $preservarChaves = true mantém as chaves originais. Registros sem o campo ficam de fora, exceto em whereNotIn e whereNull. Em todos, $caminho pode ser uma Closure.

Operador de whereCompareExemplo
= == === != <> !==whereCompare($r, 'status', '!=', 'cancelado')
< <= > >=whereCompare($r, 'total', '>=', 100) (texto numérico compara como número; null nunca passa)
between not betweenwhereCompare($r, 'total', 'between', [40, 100]) (inclusivo)
in not inwhereCompare($r, 'status', 'in', ['pago', 'enviado'])
like not likewhereCompare($r, 'nome', 'like', 'ana%') (% e _ como no SQL, sem diferenciar maiúsculas, com acentos)
contains starts with ends withwhereCompare($r, 'cidade', 'starts with', 'são') (sem diferenciar maiúsculas; texto vazio não casa)

Títulos do financeiro do ERP (não estão no seu banco, então não há SQL para filtrar):

$titulos = ArrayHelper::get($erp->get('/financeiro/titulos', ['cliente' => $codigo])['json'], 'data', []);

$abertos  = ArrayHelper::where($titulos, 'situacao', 'ABERTO');
$vencidos = ArrayHelper::whereCompare($abertos, 'vencimento', '<', DateHelper::today());   // 'Y-m-d' compara certo como texto
$boletos  = ArrayHelper::whereIn($abertos, 'forma', ['BOLETO', 'PIX']);
$semNota  = ArrayHelper::whereNull($titulos, 'nota_fiscal');
$proximo  = ArrayHelper::first(ArrayHelper::sortBy($abertos, 'vencimento'));

list($emDia, $atrasados) = ArrayHelper::partition($abertos, function ($t) {
    return $t['vencimento'] >= DateHelper::today();
});

O banco devolve texto Sem casts, o Joomla devolve todo número como texto ($p->id === '7'). Por isso where(), que é estrito, não acha where($pedidos, 'cliente_id', 7). Passe o valor como texto ('7'), use $estrito = false, ou declare casts no OrmBase. whereIn/whereNotIn já comparam sem tipo.

Indexar, agrupar e contar

MétodoExemplo de retorno
pluck($r, $caminho, $chavePor = null)['Ana', 'Bruno'] ou, com $chavePor = 'id', [7 => 'Ana', 9 => 'Bruno']
keyBy($r, $caminho)[7 => {registro}, 9 => {registro}] (repetido: o último vence)
groupBy($r, $caminho, $preservarChaves = false)['pago' => [{...}, {...}], 'pendente' => [{...}]]
countBy($r, $caminho = null)['pago' => 2, 'pendente' => 1]
unique($dados, $caminho = null, $estrito = false)sem repetidos, mantém o primeiro e as chaves
map($dados, $callback)como array_map, mas mantém as chaves e passa ($valor, $chave)
mapWithKeys($dados, $callback)o callback devolve [chave => valor]; os pares são juntados

O valor do campo vira chave assim: null → '', true/false → 1/0, data → 'Y-m-d H:i:s', enum → valor. Texto numérico vira chave inteira (regra do PHP). Um array como valor lança exceção.

Evitar N+1: uma consulta para os clientes de todos os pedidos, depois juntar na memória.

$pedidos = OrmTables::table('#__loja_pedidos')->where('status', 'pago')->orderBy('id', 'DESC')->limit(50)->get();

$clienteIds = array_values(ArrayHelper::unique(ArrayHelper::pluck($pedidos, 'cliente_id')));
$clientes = $clienteIds === [] ? [] : ArrayHelper::keyBy(
    OrmTables::table('#__loja_clientes')->select('id, nome, email')->whereIn('id', $clienteIds)->get(),
    'id'
);

foreach ($pedidos as $pedido) {
    $pedido->cliente = isset($clientes[$pedido->cliente_id]) ? $clientes[$pedido->cliente_id] : null;
}

Ordenar: sortBy, sortByMany

$porTotal = ArrayHelper::sortBy($pedidos, 'total', true);                 // maior total primeiro
$fila     = ArrayHelper::sortByMany($pedidos, ['prioridade' => 'desc', 'criado_em' => 'asc']);
$porNome  = ArrayHelper::sortBy($clientes, function ($c) {
    return FormatHelper::removeAccents($c->nome);                         // 'Ágata' junto do 'A'
});
  • Estável: empate mantém a ordem original (ordenar duas vezes funciona como "por A, depois B").
  • Texto compara em ordem natural sem diferenciar maiúsculas (item2 antes de item10); texto numérico ('80.50') compara como número; datas (DateTime) por instante.
  • null fica antes de tudo no crescente (e por último no decrescente).
  • Os dois devolvem lista reindexada; o último parâmetro ($preservarChaves) mantém as chaves. Em sortByMany, critério com Closure: [[function ($r) { ... }, 'desc']].

Somar, média, mínimo e máximo

sum($r, $caminho = null), avg, min, max: aceitam caminho, Closure ou, sem caminho, os próprios valores. Ignoram o que não é número (null, '', 'abc') e aceitam texto numérico do banco. avg, min e max devolvem null sem valores.

$pagos = ArrayHelper::where($pedidos, 'status', 'pago');

echo FormatHelper::money(ArrayHelper::sum($pagos, 'total'));             // faturamento
echo FormatHelper::money(ArrayHelper::avg($pagos, 'total'));             // ticket médio
echo ArrayHelper::sum(ArrayHelper::get($pedido, 'itens.*.quantidade', []));   // peças no pedido

Dinheiro em centavos Para valor que será cobrado ou gravado, some inteiros: ArrayHelper::sum($itens, function ($i) { return FormatHelper::toCents($i['preco']) * (int) $i['qtd']; }) e mostre com FormatHelper::moneyFromCents(). Veja FormatHelper.

Árvore: toTree

toTree($registros, $campoId = 'id', $campoPai = 'parent_id', $filhos = 'children', $raiz = null) monta a hierarquia de registros com id/pai (categorias, menus, comentários, plano de contas). Cada nó ganha children (chave em array, propriedade em objeto). Registro cujo pai não está na lista, ou que é pai de si mesmo, fica na raiz. Os objetos são copiados: os originais não ganham children.

$categorias = OrmTables::table('#__categories')
    ->select('id, parent_id, title')
    ->where('extension', 'com_loja')
    ->where('published', 1)
    ->orderBy('lft')
    ->get();

$arvore = ArrayHelper::toTree($categorias);
// A raiz do Joomla (id 1, extension 'system') não vem na consulta,
// então as categorias de primeiro nível (parent_id = 1) ficam na raiz.

function opcoesCategoria(array $nos, $nivel = 0)
{
    $html = '';

    foreach ($nos as $no) {
        $html .= '<option value="' . (int) $no->id . '">'
            . str_repeat('— ', $nivel) . htmlspecialchars($no->title, ENT_QUOTES, 'UTF-8')
            . '</option>';
        $html .= opcoesCategoria($no->children, $nivel + 1);
    }

    return $html;
}

Para um menu em JavaScript, devolva a árvore direto: ApiResponseHelper::success('Categorias.', $arvore). Comentários de um artigo: toTree($comentarios, 'id', 'resposta_de').

Ciclos somem Se A é pai de B e B é pai de A, nenhum dos dois chega à raiz e os dois ficam fora do resultado. Isso só acontece com dado corrompido; para conferir, compare count($registros) com o total de nós da árvore.

Conversão entre array e objeto

MétodoO que faz
toArray($dados, $recursivo = false)Qualquer objeto vira array: stdClass, objeto com toArray() (Registry), Traversable, JsonSerializable, propriedades públicas. Datas, enums e closures ficam como estão; referência circular não entra em loop.
toObject($dados, $recursivo = false, $preservarListas = true)Array vira stdClass; com $recursivo, os níveis internos também (listas continuam arrays).
toObjects($registros, $recursivo = false)Lista de arrays vira lista de objetos (mesmo formato do get() do ORM).
isList($a) / isAssoc($a)Chaves 0, 1, 2… em sequência / qualquer outra coisa.
wrap($v)null → [], valor → [valor], array como está.
accessible($v)true para array ou objeto.
// Mesma view para o banco (stdClass) e para a API (array): $item->nome nos dois
$itens = $origem === 'erp' ? ArrayHelper::toObjects($produtosDoErp) : $produtosDoBanco;

// Parâmetro que aceita um id ou vários
foreach (ArrayHelper::wrap($ids) as $id) { ... }

// Registry do Joomla para array simples (ex.: guardar no cache)
$params = ArrayHelper::toArray(JComponentHelper::getParams('com_loja'));

Receitas com outros helpers

Itens de pedido vindos do formulário

controllers/pedido.php
public function salvar()
{
    if (!PermissionHelper::requireToken()) {
        return;
    }

    try {
        // itens[0][produto_id]=7&itens[0][qtd]=2&itens[1][produto_id]=9&itens[1][qtd]=1
        $itens = array_values(InputHelper::array('itens', [], 'post'));

        $v = ValidationHelper::validate(['itens' => $itens], [
            'itens'              => 'required|array',
            'itens.*.produto_id' => 'required|int|min:1',
            'itens.*.qtd'        => 'required|int|min:1|max:99',
        ]);

        if (!$v['valid']) {
            return ApiResponseHelper::fromValidation($v);
        }

        $ids = array_values(ArrayHelper::unique(ArrayHelper::pluck($itens, 'produto_id')));
        $produtos = ArrayHelper::keyBy(
            OrmTables::table('#__loja_produtos')->whereIn('id', $ids)->where('ativo', 1)->get(),
            'id'
        );

        $faltando = ArrayHelper::whereNotIn($itens, 'produto_id', array_keys($produtos));

        if ($faltando !== []) {
            return ApiResponseHelper::conflict(
                'Produto indisponível: ' . implode(', ', ArrayHelper::pluck($faltando, 'produto_id')) . '.'
            );
        }

        $totalCentavos = ArrayHelper::sum($itens, function ($item) use ($produtos) {
            return FormatHelper::toCents($produtos[$item['produto_id']]->preco) * (int) $item['qtd'];
        });

        $pedido = DbTransactionHelper::run(function () use ($itens, $produtos, $totalCentavos) {
            $pedido = OrmTables::table('#__loja_pedidos')->create([
                'cliente_id' => PermissionHelper::userId(),
                'total'      => $totalCentavos / 100,
                'status'     => 'aberto',
            ]);

            OrmTables::table('#__loja_pedido_itens')->createMany(ArrayHelper::map($itens, function ($item) use ($pedido, $produtos) {
                return [
                    'pedido_id'  => $pedido->id,
                    'produto_id' => $item['produto_id'],
                    'quantidade' => (int) $item['qtd'],
                    'preco'      => $produtos[$item['produto_id']]->preco,
                ];
            }));

            return $pedido;
        });

        return ApiResponseHelper::created('Pedido criado. Total: ' . FormatHelper::moneyFromCents($totalCentavos) . '.', ['id' => $pedido->id]);
    } catch (Throwable $e) {
        return ApiResponseHelper::exception($e);
    }
}

Painel do mês com uma consulta

Uma consulta, vários números, guardados por 5 minutos. Para tabelas grandes (centenas de milhares de linhas), troque por count()/sum() do ORM ou SQL com GROUP BY.

$painel = CacheHelper::remember('dashboard:pedidos-mes', 300, function () {
    $mes = DateHelper::range('month');

    $pedidos = OrmTables::table('#__loja_pedidos')
        ->select('id, status, total, cidade')
        ->whereBetween('criado_em', $mes['start'], $mes['end'])
        ->get();

    $pagos = ArrayHelper::where($pedidos, 'status', 'pago');
    $porCidade = ArrayHelper::map(ArrayHelper::groupBy($pagos, 'cidade'), function ($lista) {
        return ArrayHelper::sum($lista, 'total');
    });
    arsort($porCidade);

    return [
        'por_status'   => ArrayHelper::countBy($pedidos, 'status'),      // ['pago' => 41, 'pendente' => 7]
        'faturamento'  => ArrayHelper::sum($pagos, 'total'),
        'ticket_medio' => ArrayHelper::avg($pagos, 'total'),
        'top_cidades'  => array_slice($porCidade, 0, 5, true),           // ['São Paulo' => 9120.5, ...]
    ];
});

echo FormatHelper::money($painel['faturamento']);

}

$locais = ArrayHelper::keyBy(
    OrmTables::table('#__loja_produtos')->select('id, codigo_erp')->whereIn('codigo_erp', ArrayHelper::pluck($remotos, 'codigo_erp'))->get(),
    'codigo_erp'
);

list($existentes, $novos) = ArrayHelper::partition($remotos, function ($p) use ($locais) {
    return isset($locais[$p['codigo_erp']]);
});

DbTransactionHelper::run(function () use ($existentes, $novos, $locais) {
    $tabela = OrmTables::table('#__loja_produtos', ['fillable' => ['codigo_erp', 'nome', 'preco']]);

    foreach ($novos as $p) {
        $tabela->create($p);
    }

    foreach ($existentes as $p) {
        $tabela->update($locais[$p['codigo_erp']]->id, $p);
    }
});

LogHelper::info('Produtos sincronizados.', 'erp', ['novos' => count($novos), 'atualizados' => count($existentes)]);

Comportamentos e limites

  • Tudo na memória. Para milhares de linhas, filtre e some no banco; para processar tabelas grandes, chunk() do ORM ou a fila.
  • except() copia os objetos do caminho removido: except($cliente, ['endereco.referencia']) não mexe no $cliente original, mesmo com endereco sendo objeto. forget() e set(), ao contrário, alteram a variável recebida.
  • get($d, null) devolve $d inteiro (o mesmo em has: false). Cuidado ao usar um campo que pode ser null como caminho.
  • set() num caminho que passa por um valor que não é array nem objeto substitui esse valor por um nível novo; gravar em null começa um array.
  • pluck($r, $campo) sem $chavePor devolve null para registro sem o campo; keyBy, groupBy e pluck com $chavePor pulam esse registro.
  • first()/last() aceitam qualquer callable como filtro; outro tipo lança TypeError.
  • Lançam InvalidArgumentException: caminho que não é texto, inteiro ou array; toObject()/set() em valor escalar; operador desconhecido; between sem [mín, máx]; agrupar por um campo cujo valor é array.
