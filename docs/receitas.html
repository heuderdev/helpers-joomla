Receitas

Soluções prontas para copiar e adaptar: filtros de tela, estoque, importação, exportação, filas, lixeira e mais.

Soluções completas para situações comuns. Todas usam OrmTables direto, para funcionar sem models. Com models, troque OrmTables::table('#__x') por XModel::query().

Listagem com filtros, ordenação e paginação

Filtros opcionais com when(), ordenação restrita a uma lista de colunas permitidas e paginação para API JSON.

Controller
public function listar()
{
    $filtros = [
        'status' => InputHelper::cmd('status', '', 'get'),
        'busca' => InputHelper::string('busca', '', 'get'),
        'de' => InputHelper::string('de', '', 'get'),          // 2026-10-01
        'ate' => InputHelper::string('ate', '', 'get'),
    ];

    $ordenaveis = ['created_at', 'total', 'status'];
    $ordenar = InputHelper::cmd('ordenar', 'created_at', 'get');
    $ordenar = in_array($ordenar, $ordenaveis, true) ? $ordenar : 'created_at';
    $direcao = InputHelper::cmd('direcao', 'desc', 'get');

    try {
        $resultado = OrmTables::table('#__loja_pedidos', ['casts' => ['total' => 'float']])
            ->when($filtros['status'], function ($q, $status) {
                $q->where('status', $status);
            })
            ->when($filtros['busca'], function ($q, $busca) {
                $q->whereGroup(function ($g) use ($busca) {
                    $g->whereLike('cliente_nome', $busca)
                      ->orWhereLike('cliente_email', $busca);
                });
            })
            ->when($filtros['de'], function ($q, $de) {
                $q->where('created_at', '>=', $de . ' 00:00:00');
            })
            ->when($filtros['ate'], function ($q, $ate) {
                $q->where('created_at', '<=', $ate . ' 23:59:59');
            })
            ->orderBy($ordenar, $direcao)
            ->paginate(20, InputHelper::uint('pagina', 1, 'get'));

        unset($resultado['paginacao']);

        return ApiResponseHelper::success('Pedidos carregados.', $resultado);
    } catch (Throwable $e) {
        return ApiResponseHelper::exception($e);
    }
}

Baixa de estoque sem vender o que não tem

Dois clientes compram a última unidade ao mesmo tempo. Com lockForUpdate(), o segundo espera o primeiro terminar e então já vê o estoque zerado.

Service
public static function baixarEstoque($produtoId, $quantidade)
{
    return DbTransactionHelper::run(function () use ($produtoId, $quantidade) {
        $produtos = OrmTables::table('#__loja_produtos', ['casts' => ['estoque' => 'int']]);

        $produto = $produtos->where('id', (int) $produtoId)->lockForUpdate()->first();

        if ($produto === null) {
            throw new RuntimeException('Produto não encontrado.', 404);
        }

        if ($produto->estoque < $quantidade) {
            throw new DomainException('Estoque insuficiente para ' . $produto->nome . '.');
        }

        return $produtos->decrement($produto->id, 'estoque', $quantidade);
    });
}

DomainException é uma exceção de regra de negócio. Como run() relança o tipo original, o controller pode responder com a mensagem dela, e responder com uma mensagem genérica para erros técnicos.

Pedido com itens: tudo ou nada

Service (usa a receita anterior)
public static function criarPedido($clienteId, array $itens)
{
    return DbTransactionHelper::run(function () use ($clienteId, $itens) {
        $pedido = OrmTables::table('#__loja_pedidos')->create([
            'cliente_id' => (int) $clienteId,
            'status' => 'aberto',
            'total' => 0,
        ]);

        $total = 0.0;
        $linhas = [];

        foreach ($itens as $item) {
            $produto = self::baixarEstoque($item['produto_id'], (int) $item['quantidade']);  // savepoint

            $linhas[] = [
                'pedido_id' => $pedido->id,
                'produto_id' => $produto->id,
                'quantidade' => (int) $item['quantidade'],
                'preco_unitario' => $produto->preco,
            ];

            $total += $produto->preco * $item['quantidade'];
        }

        OrmTables::table('#__loja_pedido_itens', ['timestamps' => false])->createMany($linhas);

        return OrmTables::table('#__loja_pedidos')->update($pedido->id, ['total' => round($total, 2)]);
    });
}

baixarEstoque() tem o seu próprio run(). Chamado aqui dentro, ele vira um savepoint: se faltar estoque no terceiro item, o pedido inteiro é desfeito, inclusive a baixa dos dois primeiros.

Importação que ignora duplicados

Cada linha num run() aninhado: um erro desfaz só aquela linha. Funciona também no PostgreSQL, onde um erro sem savepoint bloquearia o resto da transação.

Service
public static function importar(array $linhas)
{
    $relatorio = [];

    DbTransactionHelper::run(function () use ($linhas, &$relatorio) {
        // Zera aqui: em deadlock, o callback roda de novo do começo
        $relatorio = ['importados' => 0, 'ignorados' => []];

        foreach ($linhas as $numero => $linha) {
            try {
                DbTransactionHelper::run(function () use ($linha) {
                    OrmTables::table('#__loja_clientes')->create([
                        'documento' => $linha['documento'],
                        'nome' => $linha['nome'],
                        'email' => $linha['email'],
                    ]);
                }, ['retries' => 0]);

                $relatorio['importados']++;
            } catch (RuntimeException $e) {
                if (!self::ehDuplicidade($e)) {
                    throw $e;                 // erro inesperado: desfaz tudo
                }

                $relatorio['ignorados'][] = $numero + 1;
            }
        }
    });

    return $relatorio;
}

// MySQL: "Duplicate entry" (1062) / PostgreSQL: "duplicate key" (23505)
protected static function ehDuplicidade(Throwable $erro)
{
    for ($atual = $erro; $atual !== null; $atual = $atual->getPrevious()) {
        $mensagem = strtolower($atual->getMessage());

        if (strpos($mensagem, 'duplicate') !== false || strpos($mensagem, '23505') !== false) {
            return true;
        }
    }

    return false;
}

O $relatorio é zerado dentro do callback porque, em caso de deadlock, run() executa o callback de novo desde o início. Zerado fora, ele somaria as contagens da tentativa que foi desfeita.

Exportar milhares de registros para CSV

public static function exportarClientes($caminho)
{
    $arquivo = fopen($caminho, 'w');

    try {
        fputcsv($arquivo, ['id', 'nome', 'email', 'cadastro'], ';', '"', '\\');

        OrmTables::table('#__loja_clientes')
            ->select(['id', 'nome', 'email', 'created_at'])
            ->where('ativo', 1)
            ->chunk(1000, function ($lote) use ($arquivo) {
                foreach ($lote as $cliente) {
                    fputcsv($arquivo, [$cliente->id, $cliente->nome, $cliente->email, $cliente->created_at], ';', '"', '\\');
                }
            });
    } finally {
        fclose($arquivo);
    }
}

Processar uma fila em lotes

Quando o processamento muda a coluna do filtro (de pendente para enviado), chunk() pularia registros, porque avança por OFFSET. Avance pelo id:

public static function enviarPendentes()
{
    $ultimoId = 0;
    $enviados = 0;

    do {
        $lote = OrmTables::table('#__loja_notificacoes')
            ->where('status', 'pendente')
            ->where('id', '>', $ultimoId)
            ->orderBy('id')
            ->limit(100)
            ->get();

        foreach ($lote as $notificacao) {
            $ultimoId = $notificacao->id;
            $ok = NotificacaoService::enviar($notificacao);

            OrmTables::table('#__loja_notificacoes')->update($notificacao->id, [
                'status' => $ok ? 'enviado' : 'erro',
            ]);

            $enviados += $ok ? 1 : 0;
        }
    } while (count($lote) === 100);

    return $enviados;
}

Lixeira com soft delete

// Instância normal: esconde os excluídos
function pedidos()
{
    return OrmTables::table('#__loja_pedidos', ['softDeletes' => true]);
}

// Instância da lixeira: sem softDeletes, para enxergar os excluídos
function lixeira()
{
    return OrmTables::table('#__loja_pedidos')->whereNotNull('deleted_at');
}

pedidos()->delete(10);                               // vai para a lixeira

$naLixeira = lixeira()->latest('deleted_at')->get(); // lista a lixeira
pedidos()->restore(10);                              // tira da lixeira

// Esvazia a lixeira: só os excluídos há mais de 30 dias
$removidos = lixeira()
    ->where('deleted_at', '<', date('Y-m-d H:i:s', strtotime('-30 days')))
    ->deleteWhere();                                 // DELETE de verdade
