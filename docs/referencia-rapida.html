MétodoRetornoO que faz

begin($connection = null)boolAbre transação/savepoint.
commit($connection = null)boolConfirma o nível atual.
rollback($connection = null)boolDesfaz o nível atual.
isActive($connection = null)boolHá transação aberta?
depth($connection = null)intProfundidade (0 = nenhuma).
setMaxRetries($n)voidRetries padrão (0–10; padrão 3).
setRetryDelayMicroseconds($us)voidEspera inicial do retry.
setRetryableErrorCodes(array $codes)voidCódigos que disparam retry.
setAuditEnabled($bool)voidLiga auditoria via AuditHelper.
setLogCategory($categoria)voidCategoria dos logs.
setLogDirectory($diretorio)voidDiretório dos logs (LogHelper).

Opções de run()/attempt(): connection, retries, context, audit_event.
