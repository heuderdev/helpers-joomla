HttpHelper

Chamadas a APIs externas (ERP, pagamento, frete, WhatsApp) sem travar o site: timeout sempre ligado, nova tentativa só quando é seguro repetir, JSON de ida e volta, autenticação, log com segredos mascarados e bloqueio de endereços internos.

Visão geral

require_once JPATH_COMPONENT . '/helpers/HttpHelper.php';

$r = HttpHelper::get('https://viacep.com.br/ws/01310100/json/');

if (!$r['ok']) {
    return ApiResponseHelper::error(HttpHelper::errorMessage($r));   // "O serviço externo não respondeu a tempo..."
}

$endereco = $r['json'];   // array decodificado

Por que não file_get_contents ou cURL na mão:

  • Timeout padrão de 15 s (conexão: 5 s). Sem timeout, uma API lenta prende um processo do PHP por minutos; algumas dezenas de pedidos assim derrubam o site inteiro.
  • Nova tentativa só quando é seguro: em falha de rede, 429, 500, 502, 503 e 504, com espera crescente (300 ms, 600 ms…) e respeitando o Retry-After. POST e PATCH não se repetem por padrão: repetir "cobrar R$ 100" após um timeout pode cobrar duas vezes.
  • Nunca lança exceção (salvo 'throw' => true): devolve sempre a mesma estrutura, inclusive em falha de rede.
  • Log em api.*.php pelo LogHelper: método, host, status, tempo e tentativas, com token, key, signature… mascarados na URL. O cabeçalho Authorization nunca é registrado.
  • Só http e https, inclusive em redirecionamentos (sem file://, gopher://), SSL verificado e proxy do Joomla (Configuração global → Servidor) respeitado.

A resposta

ChaveTipoO que é

statusintCódigo HTTP; 0 quando nem houve resposta (rede, timeout, URL inválida, endereço bloqueado).
jsonarray|nullCorpo decodificado (quando é JSON válido).

headersarrayCabeçalhos da resposta, com nomes em minúsculas ($r['headers']['x-total-count']).

HttpHelper::errorMessage($r) traduz a falha em uma frase para quem usa o sistema (rede, timeout, SSL, 401/403, 429, 5xx). Os detalhes técnicos ficam no log.

Métodos

get()estático

HttpHelper::get(string $url, array $query = array(), array $options = array()): array

$query vira query string (listas viram l[0]=1&l[1]=2; acentos codificados).

post() / put() / patch() / delete()estático

HttpHelper::post(string $url, array|object|string|null $body = null, array $options = array()): array

Array ou objeto no $body vai como JSON (Content-Type: application/json, acentos sem escape); string vai como está. Para formulário use 'form', para upload 'multipart'.

HttpHelper::post($url, array('pedido' => 15, 'itens' => $itens));                   // JSON
HttpHelper::post($url, null, array('form' => array('grant_type' => 'client_credentials')));   // x-www-form-urlencoded
HttpHelper::post($url, null, array('multipart' => array(                            // upload
    'descricao' => 'Nota fiscal 123',
    'arquivo' => new CURLFile($caminho, 'application/pdf', 'nf-123.pdf'),
)));
HttpHelper::post($url, $xml, array('headers' => array('Content-Type' => 'application/xml')));   // corpo cru

request() / head()estático

HttpHelper::request(string $method, string $url, array $options = array()): array

Qualquer método, com as mesmas opções.

download()estático

HttpHelper::download(string $url, string $destino, array $options = array()): array

Grava o corpo direto no arquivo, sem passar pela memória (arquivos de centenas de MB). Baixa em destino.part e só renomeia quando termina com 2xx: um download interrompido nunca deixa um arquivo pela metade no destino. Use um timeout maior.

$r = HttpHelper::download('https://erp.exemplo.com/relatorios/123.zip', JPATH_ROOT . '/tmp/relatorio-123.zip', array('timeout' => 300, 'bearer' => $token));

client()estático

HttpHelper::client(array $defaults): HttpClient

Um cliente com padrões fixos para uma API: URL base, autenticação, cabeçalhos, timeout. Os métodos do cliente (get, post, put, patch, delete, request, download) aceitam caminhos relativos e as mesmas opções; cabeçalhos e query se somam aos padrões. withOptions(array) devolve uma cópia com opções a mais.

class ErpApi
{
    private static $cliente;

    public static function cliente()
    {
        if (!self::$cliente) {
            $params = JComponentHelper::getParams('com_loja');

            self::$cliente = HttpHelper::client(array(
                'base_url' => 'https://erp.exemplo.com/api/v2',
                'bearer' => $params->get('erp_token'),
                'timeout' => 10,
                'headers' => array('X-Empresa' => $params->get('erp_empresa')),
                'log_category' => 'erp',
            ));
        }

        return self::$cliente;
    }
}

$r = ErpApi::cliente()->get('/clientes', array('documento' => $cpf));
$r = ErpApi::cliente()->post('/pedidos', $pedido, array('headers' => array('Idempotency-Key' => $pedido['uuid'])));

isPublicUrl()estático

HttpHelper::isPublicUrl(string $url): bool

Verdadeiro se o host resolve só para IPs públicos. Veja SSRF.

setDefaults() / getDefaults()estático

HttpHelper::setDefaults(array $defaults): void

Troca os padrões de todas as chamadas (ex.: array('timeout' => 8, 'user_agent' => 'MinhaLoja/2.0')).

Novas tentativas: quando repetir é seguro

SituaçãoGET, HEAD, PUT, DELETE, OPTIONSPOST, PATCH
Falha de rede / timeoutrepetenão repete (o servidor pode ter processado)
429, 500, 502, 503, 504repete (respeita Retry-After)não repete
4xx (400, 401, 404, 422…)não repete (repetir não muda nada)não repete

Para POST que pode ser repetido, use a chave de idempotência da API (Stripe, Pagar.me, Asaas e Mercado Pago aceitam) e ligue retry_post:

$r = HttpHelper::post('https://api.gateway.com/v1/cobrancas', $cobranca, array(
    'bearer' => $chave,
    'headers' => array('Idempotency-Key' => $pedido->uuid),   // mesmo pedido = mesma cobrança
    'retry_post' => true,
));

Novas tentativas somam tempo à requisição de quem está esperando (2 tentativas extras com timeout de 15 s = até 45 s). Em telas, use timeout baixo e retries 0 ou 1; para integrações que podem esperar, faça a chamada num job da fila, que tem as próprias novas tentativas.

URLs que vêm de fora (SSRF)

Quando a URL vem de quem usa o sistema (webhook configurável, "importar imagem de uma URL", callback de integração), um atacante pode apontar para endereços internos: http://169.254.169.254/ (credenciais da nuvem), http://localhost:6379 (Redis), o painel do roteador. Use block_private:

$url = InputHelper::string('webhook_url');

if (!HttpHelper::isPublicUrl($url)) {
    return ApiResponseHelper::validationError(array('webhook_url' => array('Informe um endereço público (https://...).')));
}

$r = HttpHelper::post($url, $evento, array('block_private' => true, 'timeout' => 5, 'retries' => 0));

O host é resolvido e todos os IPs precisam ser públicos (bloqueia redes privadas, 127.0.0.0/8, link-local, reservadas e os equivalentes IPv6). Mantenha follow_redirects em 0 nessas chamadas: um redirecionamento poderia levar a um endereço interno depois da checagem.

Receitas

Token OAuth com cache

public static function token()
{
    // CacheHelper::remember guarda o token até perto de expirar (veja CacheHelper)
    return CacheHelper::remember('erp.token', 3300, function () {
        $r = HttpHelper::post('https://erp.exemplo.com/oauth/token', null, array(
            'form' => array('grant_type' => 'client_credentials'),
            'basic' => array(ERP_CLIENT_ID, ERP_CLIENT_SECRET),
            'throw' => true,
        ));

        return $r['json']['access_token'];
    });
}

Ler todas as páginas de uma API

$pagina = 1;

do {
    $r = ErpApi::cliente()->get('/produtos', array('pagina' => $pagina, 'por_pagina' => 100), array('throw' => true));

    foreach ($r['json']['dados'] as $produto) {
        // sincroniza
    }

    $pagina++;
} while ($pagina <= (int) $r['json']['total_paginas']);

Na tela: falha da API vira mensagem, não erro 500

public function calcularFrete()
{
    try {
        $cep = InputHelper::string('cep');
        $r = HttpHelper::get('https://frete.exemplo.com/cotacao', array('cep' => $cep), array('timeout' => 5, 'retries' => 1));

        if (!$r['ok']) {
            return ApiResponseHelper::serviceUnavailable('Não foi possível calcular o frete agora. ' . HttpHelper::errorMessage($r));
        }

        return ApiResponseHelper::success('Frete calculado.', $r['json']);
    } catch (Throwable $e) {
        return ApiResponseHelper::exception($e);
    }
}

Requisitos

  • Extensão curl do PHP (sem ela, a resposta vem com error explicando).
  • PHP 7.0+, Joomla 3, 4 e 5 (usa o proxy da configuração global quando ativo).
  • LogHelper opcional: sem ele, nada é registrado.

  • QueueHelper: integrações em segundo plano.
  • LogHelper: onde as chamadas ficam registradas.
  • ApiResponseHelper: responder à tela quando a API externa falha.
