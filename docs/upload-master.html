UploadMaster

Receba, valide, grave e entregue arquivos com segurança: tipo real conferido, imagens tratadas, miniaturas e downloads que funcionam em qualquer navegador.

Visão geral

O UploadMaster recebe arquivos enviados por formulários e os grava no servidor depois de conferir tamanho, extensão e tipo real do conteúdo. Também copia, move, exclui, gera miniaturas e entrega arquivos para download. Todas as operações ficam presas a um diretório base, e arquivos sensíveis do site nunca são tocados.

require_once JPATH_COMPONENT . '/helpers/UploadMaster.php';

$arquivo = UploadMaster::getFileFromInput('documento');   // campo <input type="file" name="documento">

$resultado = UploadMaster::upload($arquivo, 'contratos/2026', null, array(
    'allowed_extensions' => array('pdf'),
    'max_size' => 5 * 1024 * 1024,
));

if (!$resultado['success']) {
    echo $resultado['mensagem'];   // "Não foi possível enviar o arquivo. O arquivo excede o tamanho máximo permitido de 5 MB."
}

echo $resultado['data']['url'];    // https://seusite.com.br/contratos/2026/arquivo_20261004101500_9f2c....pdf

O que os métodos devolvem

Quase todos os métodos devolvem o mesmo formato, sem lançar exceção:

$resultado = array(
    'success' => true,                // ou false
    'status' => 'sucesso',            // ou 'erro'
    'mensagem' => 'Arquivo enviado com sucesso.',
    'data' => array(/* dados do arquivo (veja abaixo) */),
    'errors' => array(),              // na falha: array('_general' => array('motivo'))
);

Na falha, mensagem traz a frase genérica seguida do motivo: "Não foi possível enviar o arquivo. A extensão do arquivo não é permitida." O motivo também fica em errors['_general'][0]. Detalhes técnicos (caminhos, erros do PHP) vão só para o log, na categoria upload_master. Exceções: exists() e stream() devolvem bool, e formatBytes()/maxUploadSize() devolvem valores.

Onde os arquivos ficam: o diretório base

Todo caminho (destino de upload, arquivo a excluir, a baixar…) é relativo ao diretório base e precisa ficar dentro dele. O padrão é a raiz do site (JPATH_SITE). Caminhos com ../ ou que saiam da base são recusados.

// Base padrão (raiz do site): 'images/produtos' = JPATH_SITE/images/produtos
UploadMaster::upload($arquivo, 'images/produtos');

// Base própria para o componente
UploadMaster::setBaseDirectory('media/com_loja/uploads');
UploadMaster::upload($arquivo, 'produtos');   // → JPATH_SITE/media/com_loja/uploads/produtos

// Base só para uma chamada
UploadMaster::upload($arquivo, 'produtos', null, array('base_directory' => 'media/com_loja/uploads'));
Tipo de arquivoOnde guardarComo entregar
Públicos (fotos de produtos, banners)Pasta pública, como images/… ou media/com_x/…Pela url devolvida no upload.
Privados (contratos, documentos pessoais, notas fiscais)Pasta que o servidor web não sirva diretamente (veja abaixo)Por stream(), depois de conferir a permissão do usuário.
Arquivos privados

Uma pasta dentro do site é acessível pela URL. Para arquivos privados, bloqueie o acesso direto. No Apache, coloque na pasta um .htaccess com Require all denied; no Nginx, um location com deny all. Entregue esses arquivos só com stream(), que lê o arquivo pelo PHP.

Cada pasta criada pelo helper recebe um index.html vazio, como o Joomla faz, para o servidor não listar o conteúdo. Desligue com setCreateIndexFiles(false).

Arquivos que nunca são tocados

Mesmo dentro da base, stream(), delete(), move(), copy(), info(), exists() e thumbnail() recusam:

  • configuration.php (tem a senha do banco), .htaccess, .htpasswd, web.config, .user.ini, php.ini, .env;
  • arquivos ocultos (nome começando com ponto);
  • arquivos com extensão executável ou de configuração: php, phtml, phar, sh, exe, sql, ini, env…

Assim, mesmo que um caminho venha da requisição, ninguém baixa ou apaga a configuração do site. Ainda assim, nunca use um caminho enviado pelo usuário sem conferir que o arquivo é dele: veja a receita de download.

O que é verificado no upload

  1. Envio: erros do PHP (limite do servidor, envio parcial, campo sem arquivo) viram mensagens claras. O limite do servidor aparece com o valor: "O arquivo excede o limite de 2 MB definido no servidor".

  2. Tamanho: até max_size (padrão 50 MB).

  3. Extensão: precisa estar na lista permitida e nunca pode ser executável (php, exe, sh…).

  4. Tipo real: o conteúdo é analisado e precisa combinar com a extensão. Um .jpg com código PHP, um .csv com HTML ou um ZIP renomeado para .docx são recusados. Veja os tipos aceitos.

  5. Imagens: precisam abrir como imagem e respeitar os limites (8000×8000 px, 40 megapixels), o que evita arquivos feitos para estourar a memória.

  6. Nome e destino: nome aleatório por padrão; pasta criada se não existir; nome repetido ganha sufixo (_1, _2), a menos que se use overwrite.

  7. Gravação: pelo JFile::upload do Joomla, que faz a própria verificação de segurança do arquivo. Com reencode_images, a imagem é regravada em seguida.

Upload

getFileFromInput()estático

UploadMaster::getFileFromInput(string $fieldName, int|null $index = null): array|null

Lê o arquivo enviado num campo do formulário. Para campos múltiplos (name="fotos[]"), devolve a lista; com $index, um item dela. Devolve null se o campo não veio.

$primeira = UploadMaster::getFileFromInput('fotos', 0);

uploadMany()estático

UploadMaster::uploadMany(array $files, string $directory, array $options = array()): array

Envia vários arquivos com as mesmas opções. Cada arquivo é validado separadamente: um recusado não impede os outros.

$resultado = UploadMaster::uploadMany(UploadMaster::getFileFromInput('fotos'), 'images/galeria', array(
    'allowed_extensions' => array('jpg', 'png'),
));

// data: total, success_count, error_count, files (um resultado por arquivo, com 'index')
foreach ($resultado['data']['files'] as $item) {
    if (!$item['success']) {
        echo 'Arquivo ' . ($item['index'] + 1) . ': ' . $item['mensagem'];
    }
}

Arquivos já gravados

Todos aceitam caminho relativo à base (ou absoluto, dentro dela) e a opção base_directory.

info() / exists()estático

UploadMaster::info(string $path, array $options = array()): array UploadMaster::exists(string $path, array $options = array()): bool

Dados do arquivo, ou só se ele existe (e pode ser acessado).

if (UploadMaster::exists($produto->foto)) {
    $info = UploadMaster::info($produto->foto);
    echo $info['data']['width'] . 'x' . $info['data']['height'];
}

copy() / move()estático

UploadMaster::copy(string $source, string $destinationDirectory, string|null $destinationFileName = null, array $options = array()): array UploadMaster::move(string $source, string $destinationDirectory, string|null $destinationFileName = null, array $options = array()): array

Copia ou move um arquivo, validando extensão e tipo real do mesmo jeito que o upload. Sem nome de destino, gera um nome aleatório; para manter o nome, passe keep_original_name. Para bases diferentes na origem e no destino, use source_base_directory e destination_base_directory.

// Arquivo temporário confirmado: vai para a pasta definitiva com o mesmo nome
$resultado = UploadMaster::move('temporarios/' . $nome, 'contratos/2026', null, array(
    'keep_original_name' => true,
));

delete()estático

UploadMaster::delete(string $path, array $options = array()): array

Exclui o arquivo. Devolve os dados que ele tinha.

UploadMaster::delete($produto->foto);

removeEmptyDirectories()estático

UploadMaster::removeEmptyDirectories(string $directory, array $options = array()): array

Depois de excluir arquivos, remove a pasta se ficou vazia, e as pastas acima dela enquanto também estiverem vazias, até stop_at_directory (padrão: a base). O index.html criado pelo helper não conta como conteúdo.

UploadMaster::delete('contratos/2026/10/arquivo.pdf');

UploadMaster::removeEmptyDirectories('contratos/2026/10', array(
    'stop_at_directory' => 'contratos',     // nunca remove a própria pasta contratos
));

Imagens e miniaturas

Regravar imagens no upload

Com 'reencode_images' => true, depois de gravar um JPEG, PNG ou WebP, o helper abre a imagem e a salva de novo. Isso:

  • coloca a foto em pé: celulares gravam a foto "deitada", com uma marcação de orientação que nem todo lugar respeita;
  • remove os metadados: modelo do aparelho, data e a localização GPS de onde a foto foi tirada;
  • elimina conteúdo escondido: um arquivo pode ser uma imagem válida e carregar código no fim.

GIF não é regravado, para não perder a animação. Recomendado para imagens enviadas por usuários e exibidas publicamente.

thumbnail()estático

UploadMaster::thumbnail(string $path, string $destinationDirectory, int $width, int $height, array $options = array()): array

Gera uma miniatura de uma imagem já gravada, aplicando a orientação da foto. Por padrão, cabe na caixa $width×$height mantendo a proporção, sem aumentar imagens menores.

$foto = UploadMaster::upload($arquivo, 'images/produtos', null, array('reencode_images' => true));

$miniatura = UploadMaster::thumbnail($foto['data']['relative_path'], 'images/produtos/thumbs', 300, 300, array(
    'crop' => true,       // exatamente 300x300, recortando o excesso
    'format' => 'webp',   // arquivos menores
    'quality' => 80,
));
OpçãoPadrãoEfeito
cropfalseRecorta pelo centro para o tamanho exato.
upscalefalseAumenta imagens menores que a caixa.
formato da origemjpeg, png, webp ou gif. Transparência vira fundo branco em JPEG.

Exige a extensão GD do PHP (e suporte a WebP para format => 'webp'). Antes de abrir a imagem, o helper confere se há memória suficiente; se não houver, recusa com uma mensagem em vez de derrubar o PHP.

Downloads: stream()

stream()estático

UploadMaster::stream(string $path, string|null $downloadName = null, array $options = array()): bool

Envia o arquivo ao navegador e encerra a aplicação: nada que o controller faça depois é executado. Sem isso, o Joomla acrescentaria o HTML da página ao fim do arquivo. Devolve false (sem enviar nada) se o arquivo não puder ser entregue.

ParâmetroTipoDescrição
$pathstringArquivo, relativo à base.
$downloadNamestring|nullNome que o usuário verá ao salvar. Pode ter acentos e espaços. Padrão: o nome gravado.
$optionsarrayVeja a tabela abaixo.
if (!UploadMaster::stream($contrato->arquivo, 'Contrato ' . $contrato->numero . '.pdf')) {
    return ApiResponseHelper::notFound('Arquivo não encontrado.');
}
OpçãoPadrãoEfeito
inlinefalseExibe no navegador em vez de baixar. Só vale para imagens, PDF, texto, áudio e vídeo: HTML, SVG e outros são sempre baixados.

max_age0Segundos de cache no navegador. 0 = sem cache.

Vídeos e downloads grandes: o helper atende pedidos parciais (Range), que o Safari/iOS exige para avançar vídeos e que permitem retomar downloads; libera a sessão do usuário durante o envio; e responde a HEAD.

Tipos de arquivo

Duas listas decidem o que é aceito:

  1. Extensões permitidas: o que o seu sistema aceita. Padrão: jpg, jpeg, png, gif, webp, pdf, txt, csv, xlsx, xls, doc, docx, zip, mp4, webm, mov. Troque com setAllowedExtensions() ou allowed_extensions por chamada.
  2. Mapa de tipos reais: para cada extensão, quais tipos de conteúdo são aceitos. Já inclui as variações que servidores diferentes informam para o mesmo formato.
Extensões que o mapa já conhecePara liberar
Imagens: jpg jpeg png gif webp bmp tif tiff avif heic heifBasta incluir em allowed_extensions.
Documentos: pdf txt csv tsv json rtf doc docx xls xlsx ppt pptx odt ods odpIdem.
Compactados: zip 7z rar gz tarIdem.
Áudio e vídeo: mp3 wav ogg m4a mp4 webm movIdem.
svgIdem, mas veja o aviso abaixo.
Qualquer outraRegistre com setMimeMap() e inclua em allowed_extensions.
// Aceitar MP3 só neste formulário
UploadMaster::upload($audio, 'podcasts', null, array('allowed_extensions' => array('mp3')));

// Formato que o mapa não conhece: registre o tipo real e libere a extensão
UploadMaster::setMimeMap(array('dwg' => array('image/vnd.dwg', 'application/acad')));
UploadMaster::upload($planta, 'projetos', null, array('allowed_extensions' => array('dwg')));

SVG pode conter JavaScript. Aberto direto no navegador, ele executa no domínio do seu site. Só aceite SVG de usuários confiáveis, nunca o entregue com stream() inline (o helper já força o download) e prefira exibir por <img src>, que não executa scripts.

Para .docx, .xlsx, .pptx e formatos do LibreOffice, que são arquivos ZIP, alguns servidores informam só "zip" ou "binário". Nesse caso, o helper confere a estrutura interna: um .docx precisa ter a pasta word/, e um ZIP qualquer renomeado é recusado.

Configuração global

Configure uma vez, no carregamento do componente. Os valores valem para o request inteiro.

setBaseDirectory() / getBaseDirectory()estático

UploadMaster::setBaseDirectory(string $directory): bool UploadMaster::getBaseDirectory(): string

Diretório base, relativo à raiz do site ou absoluto dentro dela. Criado se não existir. Devolve false se for inválido.

setAllowedExtensions() / setMaxFileSize()estático

UploadMaster::setAllowedExtensions(array $extensions): void UploadMaster::setMaxFileSize(int $bytes): void

Lista padrão de extensões e tamanho máximo padrão. As opções de cada chamada têm prioridade.

UploadMaster::setAllowedExtensions(array('jpg', 'jpeg', 'png', 'pdf'));
UploadMaster::setMaxFileSize(10 * 1024 * 1024);   // 10 MB

setMimeMap()estático

UploadMaster::setMimeMap(array $map, bool $replace = false): void

Acrescenta tipos reais aceitos para extensões. Com $replace = true, substitui os tipos da extensão em vez de somar. Para formatos baseados em ZIP, 'ooxml:pasta/' aceita o ZIP que contém a pasta.

setAllowedMimes()estático

UploadMaster::setAllowedMimes(array $mimes): void

Lista extra de tipos reais exigidos em todos os uploads, além do mapa. Use para restringir ainda mais: por exemplo, só imagens, qualquer que seja a extensão.

setCreateIndexFiles() / setThrowExceptions()estático

UploadMaster::setCreateIndexFiles(bool $create): void UploadMaster::setThrowExceptions(bool $throw): void

setCreateIndexFiles(false) deixa de criar o index.html nas pastas novas. setThrowExceptions(true) faz os métodos lançarem a exceção em vez de devolver success => false, útil em scripts e testes.

maxUploadSize() / formatBytes()estático

UploadMaster::maxUploadSize(int|null $maxSize = null): int UploadMaster::formatBytes(int $bytes, int $precision = 2): string

maxUploadSize() devolve o maior arquivo que pode ser enviado de fato: o menor entre o limite do helper e os do PHP (upload_max_filesize e post_max_size). Mostre ao usuário antes do envio.

echo 'Tamanho máximo: ' . UploadMaster::formatBytes(UploadMaster::maxUploadSize());   // "Tamanho máximo: 8 MB"

Receitas

Formulário com foto, gravando no banco

Controller
public function salvar()
{
    if (!JSession::checkToken()) {
        return ApiResponseHelper::forbidden('Token inválido.');
    }

    $id = InputHelper::uint('id', 0, 'post');
    $produtos = OrmTables::table('#__loja_produtos');
    $antigo = $id > 0 ? $produtos->find($id) : null;

    $dados = array('nome' => InputHelper::string('nome', '', 'post'));
    $foto = UploadMaster::getFileFromInput('foto');

    if ($foto !== null && (int) $foto['error'] !== UPLOAD_ERR_NO_FILE) {
        $envio = UploadMaster::upload($foto, 'images/produtos', null, array(
            'allowed_extensions' => array('jpg', 'jpeg', 'png', 'webp'),
            'max_size' => 3 * 1024 * 1024,
            'reencode_images' => true,
        ));

        if (!$envio['success']) {
            $motivo = isset($envio['errors']['_general'][0]) ? $envio['errors']['_general'][0] : $envio['mensagem'];

            return ApiResponseHelper::validationError(array('foto' => array($motivo)));
        }

        $dados['foto'] = $envio['data']['relative_path'];
    }

    try {
        $produto = $id > 0 ? $produtos->update($id, $dados) : $produtos->create($dados);
    } catch (Throwable $e) {
        if (isset($dados['foto'])) {
            UploadMaster::delete($dados['foto']);           // não deixa arquivo órfão
        }

        return ApiResponseHelper::exception($e);
    }

    if ($antigo !== null && isset($dados['foto']) && !empty($antigo->foto)) {
        UploadMaster::delete($antigo->foto);                 // foto trocada: apaga a anterior
    }

    return ApiResponseHelper::success('Produto salvo.', $produto);
}

Guarde no banco o relative_path, nunca o path absoluto: se o site mudar de servidor ou de pasta, o caminho relativo continua valendo.

Download protegido

O arquivo fica numa pasta sem acesso direto, e só é entregue a quem pode vê-lo. Repare que o caminho vem do banco, a partir de um id conferido, e nunca da requisição.

Controller
public function baixar()
{
    $id = InputHelper::uint('id', 0, 'get');
    $usuario = JFactory::getUser();

    $documento = OrmTables::table('#__loja_documentos')->find($id);

    if ($documento === null) {
        return ApiResponseHelper::notFound();
    }

    if ((int) $documento->cliente_id !== (int) $usuario->id && !$usuario->authorise('core.manage', 'com_loja')) {
        return ApiResponseHelper::forbidden();
    }

    if (!UploadMaster::stream($documento->arquivo, $documento->nome_original, array(
        'base_directory' => 'media/com_loja/privado',
        'inline' => InputHelper::bool('ver', false, 'get'),
    ))) {
        return ApiResponseHelper::notFound('Arquivo não encontrado.');
    }
}

Envio pelo JavaScript com barra de progresso

JavaScript
function enviarArquivo(input, url, aoProgredir) {
    return new Promise(function (resolver, rejeitar) {
        var dados = new FormData();
        dados.append('foto', input.files[0]);
        dados.append(Joomla.getOptions('csrf.token'), '1');   // token CSRF para JSession::checkToken()

        var xhr = new XMLHttpRequest();
        xhr.open('POST', url);
        xhr.setRequestHeader('X-Requested-With', 'XMLHttpRequest');   // resposta em JSON

        xhr.upload.onprogress = function (e) {
            if (e.lengthComputable) aoProgredir(Math.round(e.loaded / e.total * 100));
        };

        xhr.onload = function () {
            var json = JSON.parse(xhr.responseText);
            json.success ? resolver(json.data) : rejeitar(new Error(json.mensagem));
        };

        xhr.send(dados);
    });
}

Mostre ao usuário o limite real antes do envio, com maxUploadSize(), e confira o tamanho no navegador (input.files[0].size): um arquivo maior que o limite do PHP nem chega ao helper.

Checklist de segurança

  • Libere só as extensões que o formulário precisa, com allowed_extensions.
  • Use nome aleatório (o padrão) para arquivos de usuários; keep_original_name só quando o nome importa.
  • Use reencode_images em imagens de usuários exibidas publicamente.
  • Guarde arquivos privados fora do acesso direto e entregue com stream(), depois de conferir a permissão.
  • Nunca passe a stream()/delete() um caminho vindo da requisição: busque-o no banco a partir de um id conferido.
  • Não envie path nem base_directory ao navegador: use publicData().
  • Confira o token CSRF (JSession::checkToken()) em todo envio.
