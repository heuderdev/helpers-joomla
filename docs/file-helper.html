FileHelper

Leitura, gravação, listagem, empacotamento ZIP, download stream e gerenciamento de arquivos e diretórios de forma segura, com sandbox contra ataques de Directory Traversal.

Visão geral

O FileHelper abstrai as operações físicas do sistema de arquivos do servidor, integrando-se nativamente com as bibliotecas JFile e JFolder do Joomla, mas adicionando uma camada de segurança robusta e um padrão uniforme de respostas.

Dentre as principais vantagens do seu uso estão:

  • Sandbox de Diretório (Carcereiro): Todas as operações exigem que os arquivos e pastas estejam situados dentro de um diretório base autorizado (por padrão, a raiz do site, JPATH_SITE). Qualquer tentativa de acessar ou escrever em arquivos fora desse escopo (ex.: via ataques de Directory Traversal com ../) gera uma exceção ou retorno de erro imediato.
  • Tratamento Uniforme de Respostas: Os métodos retornam arrays padronizados pelo `ApiResponseHelper` com as chaves success, mensagem e data, permitindo que falhas físicas do servidor (como falta de permissão de escrita) sejam capturadas sem derrubar a aplicação.
  • Controle Dinâmico de Exceções: Com o método setThrowExceptions(true), você pode optar por fazer o helper lançar exceções físicas (Throwable) ao invés de retornar arrays de erro, ideal para blocos de código com transações.
  • Downloads por Stream Inteligentes: O método stream() lida com o envio de arquivos binários grandes limpando buffers ativos, aplicando cabeçalhos HTTP anti-sniffing, anti-cache e suportando a transmissão em blocos (chunking) para economizar recursos do servidor.
  • Limpeza Periódica de Arquivos: Permite fazer manutenção automatizada de pastas temporárias, excluindo arquivos antigos com base no tempo de vida parametrizado de forma recursiva.

Configurações globais

Configurações para governar as permissões, tamanho de arquivos e o comportamento de tratamento de exceções de toda a aplicação.

setBaseDirectory() / getBaseDirectory()estático

FileHelper::setBaseDirectory(string|null $directory): void
FileHelper::getBaseDirectory(): string|null

Define ou consulta o diretório raiz para operações físicas. Se nulo, a raiz do Joomla (JPATH_SITE) é usada como o jail padrão.

// Restringir o FileHelper apenas para trabalhar dentro da pasta de uploads
FileHelper::setBaseDirectory(JPATH_SITE . '/images/uploads');

setDirectoryPermission() / setFilePermission()estático

FileHelper::setDirectoryPermission(int $permission): void
FileHelper::setFilePermission(int $permission): void

Configura as permissões octais usadas automaticamente na criação de pastas (padrão: 0755) e gravação de novos arquivos (padrão: 0644).

setMaxReadSize()estático

FileHelper::setMaxReadSize(int $bytes): void

Define o limite máximo de bytes aceito em leituras de arquivos em memória pelo método read() (padrão: 50MB).

setThrowExceptions()estático

FileHelper::setThrowExceptions(bool $throwExceptions): void

Controla se o helper deve lançar exceções físicas de sistema de arquivos (como `RuntimeException` ou `InvalidArgumentException`) ou se deve apenas retornar um array estruturado indicando 'success' => false.

Verificação e Informações

Métodos para inspecionar arquivos e diretórios sem ler ou modificar seus conteúdos.

exists() / directoryExists()estático

FileHelper::exists(string $path, string|null $baseDirectory = null): bool
FileHelper::directoryExists(string $directory, string|null $baseDirectory = null): bool

Retornam um booleano simples indicando se o arquivo ou diretório físico existe no caminho informado dentro do sandbox autorizado.

ensureDirectory()estático

FileHelper::ensureDirectory(string $directory, string|null $baseDirectory = null): array

Garante a existência de um diretório. Caso a pasta não exista no caminho, ela é criada de forma recursiva aplicando a permissão octal padrão de diretórios.

info()estático

FileHelper::info(string $path, string|null $baseDirectory = null): array

Retorna uma lista exaustiva de informações e metadados sobre o arquivo físico.

Exemplo de retorno do método info()
[
    'success' => true,
    'mensagem' => 'Informações do arquivo carregadas com sucesso.',
    'data' => [
        'path' => '/var/www/site/images/uploads/foto.jpg',
        'relative_path' => 'images/uploads/foto.jpg',
        'site_relative_path' => 'images/uploads/foto.jpg',
        'url' => 'https://seusite.com/images/uploads/foto.jpg',
        'base_directory' => '/var/www/site',
        'file_name' => 'foto.jpg',
        'extension' => 'jpg',
        'size' => 124500,
        'modified_at' => '2026-10-03 14:15:22',
        'created_at' => '2026-10-03 14:12:05'
    ]
]

Leitura de arquivos

Carregamento de dados de arquivos em texto puro ou com parsing estruturado de formatos.

read()estático

FileHelper::read(string $path, string|null $baseDirectory = null, int|null $maxBytes = null): array

Lê todo o conteúdo textual de um arquivo e retorna o seu corpo bruto sob a chave data.content junto com os metadados do arquivo em data.file. Impede a leitura se o arquivo exceder o limite de segurança de bytes configurado.

readJson()estático

FileHelper::readJson(string $path, string|null $baseDirectory = null, int|null $maxBytes = null): array

Carrega o arquivo, executa a decodificação estruturada do seu JSON de forma segura e retorna um array associativo PHP correspondente na chave data.json.

$resultado = FileHelper::readJson('config.json');

if ($resultado['success']) {
    $configuracoes = $resultado['data']['json'];
}

Escrita e Gravação

Operações de gravação e atualização de conteúdos físicos.

write()estático

FileHelper::write(string $path, mixed $content, string|null $baseDirectory = null, array $options = []): array

Grava informações num arquivo de destino físico. Se a pasta de destino não existir, ela é criada de forma recursiva automaticamente.

Opções aceitas por parâmetro:

Opção Tipo Padrão Descrição
overwrite bool true Se true, substitui qualquer arquivo existente. Se false, lança um erro caso o arquivo já exista.
append bool false Se true, concatena o conteúdo no final do arquivo existente de forma atômica (travando o arquivo com lock exclusivo).

writeJson()estático

FileHelper::writeJson(string $path, mixed $data, string|null $baseDirectory = null, array $options = []): array

Converte uma estrutura PHP associativa ou de objetos em uma string JSON formatada (Pretty Print, UTF-8 e escape de barras desabilitado) e grava no arquivo físico de destino.

append()estático

FileHelper::append(string $path, string $content, string|null $baseDirectory = null): array

Atalho para gravação sequencial de logs ou auditorias textuais, adicionando conteúdo no final do arquivo físico sem remover o existente.

Operações de sistema

Cópia, movimentação e exclusão de arquivos e pastas no servidor.

copy() / move()estático

FileHelper::copy(string $sourcePath, string $destinationPath, string|null $sourceBaseDirectory = null, string|null $destinationBaseDirectory = null, array $options = []): array
FileHelper::move(string $sourcePath, string $destinationPath, string|null $sourceBaseDirectory = null, string|null $destinationBaseDirectory = null, array $options = []): array

Copia ou move arquivos de uma origem para um destino, permitindo sandboxes de origem e destino distintos. Suporta a opção booleana ['overwrite' => true] para forçar a substituição do destino caso este já exista.

delete() / deleteDirectory()estático

FileHelper::delete(string $path, string|null $baseDirectory = null): array
FileHelper::deleteDirectory(string $directory, string|null $baseDirectory = null, array $options = []): array

Remove arquivos ou exclui diretórios recursivamente. Por segurança extrema, o método deleteDirectory() impede a remoção do diretório base sandbox inteiro, a menos que a opção ['allow_base_directory' => true] seja declarada de forma consciente.

Listagem e Limpeza

Métodos para varrer diretórios estruturados e realizar a manutenção do espaço em disco.

listFiles() / listDirectories()estático

FileHelper::listFiles(string $directory = '', string|null $baseDirectory = null, array $options = []): array
FileHelper::listDirectories(string $directory = '', string|null $baseDirectory = null, array $options = []): array

Listam arquivos e pastas dentro de um diretório sandbox.

Ambos os métodos aceitam opções avançadas de filtros:

  • 'recursive' => true: Varre todas as subpastas recursivamente.
  • 'filter' => '\.pdf$': Expressão regular para filtrar apenas determinados nomes.
  • 'exclude' => [...]: Nomes de pastas físicas a ignorar na varredura.
  • 'exclude_filter' => [...]: Lista de expressões de arquivos a serem ignorados por padrão.

cleanOlderThan()estático

FileHelper::cleanOlderThan(string $directory, int $days, string|null $baseDirectory = null, array $options = []): array

Analisa todos os arquivos de um diretório de forma recursiva e remove de forma definitiva aqueles cuja data de modificação física seja superior à quantidade de $days informada.

Ideal para rotinas cron (scripts CLI) limpando pastas de relatórios temporários, exportações rejeitadas ou dumps expirados.

// Apagar todos os PDFs criados há mais de 30 dias na pasta de relatórios temporários
FileHelper::cleanOlderThan('tmp/relatorios', 30, null, [
    'filter' => '\.pdf$'
]);

Utilitários Adicionais

Facilidades para compactação, transmissão de downloads e formatação de dados físicos.

createZip()estático

FileHelper::createZip(string $zipPath, array $files, string|null $baseDirectory = null, array $options = []): array

Gera um arquivo comprimido padrão ZIP unindo uma lista de arquivos informados. Utiliza internamente a biblioteca nativa do PHP `ZipArchive`.

Opções aceitas por parâmetro:

  • 'flat' => true: Se definido como verdadeiro, todos os arquivos serão jogados na raiz do arquivo ZIP gerado, descartando a sua estrutura de pastas originais relativa.
  • 'overwrite' => true: Substitui o arquivo ZIP caso este já exista no caminho do destino.

stream()estático

FileHelper::stream(string $path, string|null $downloadName = null, string|null $baseDirectory = null, array $options = []): bool

Inicia a transmissão de download de um arquivo físico do servidor para o cliente de forma otimizada para o navegador web do usuário final.

O método lida de forma automatizada com:

  • Detecção de MIME: Se a opção `mime` não for declarada por parâmetro, lê e aplica o MIME Type correto do arquivo usando a extensão `finfo` do PHP, caindo para `application/octet-stream` em caso de falha.
  • Bloqueio de Sniffing e Cache: Envia cabeçalhos HTTP como X-Content-Type-Options: nosniff para segurança e cabeçalhos privados de Cache-Control para que arquivos que tenham dados do usuário não sejam guardados em proxies intermediários de cache públicos.
  • Suporte a transmissão parcial (Flush): Desliga todos os níveis de buffers de saída ativos do PHP com ob_end_clean() e transmite o arquivo em blocos de 8KB, dando vasão imediata à memória e poupando sobrecarga no servidor.
  • Nome de download amigável: Aceita a opção 'inline' => true para forçar que o arquivo seja aberto diretamente no navegador (como imagens ou PDFs) ao invés de forçar o download.
// Baixar um PDF do sistema
FileHelper::stream('comprovante.pdf', 'recibo-faturamento.pdf', null, [
    'inline' => true
]);

formatBytes()estático

FileHelper::formatBytes(int $bytes, int $precision = 2): string

Converte uma quantidade bruta de bytes em uma string legível formatada com a sua respectiva unidade de grandeza (B, KB, MB, GB, TB).

echo FileHelper::formatBytes(1254300); // Exibe "1.2 MB"

randomFileName()estático

FileHelper::randomFileName(string $prefix = 'arquivo', string $extension = ''): string

Gera um nome de arquivo aleatório e seguro utilizando geradores de bytes pseudo-aleatórios fortes para evitar colisões e adivinhações de arquivos no servidor.

echo FileHelper::randomFileName('comprovante', 'pdf');
// Exibe algo como: comprovante_20261003141522_4e7a1b3d5f60718293a4b5c6d7e8f9a0.pdf
