CsvHelper

Leitura, análise e importação inteligente de arquivos CSV de qualquer tamanho com detecção automática de delimitadores, codificações de caracteres, cabeçalhos e tipos de dados.

Visão geral

O CsvHelper automatiza o trabalho repetitivo e sujeito a erros de importar planilhas fornecidas por usuários finais ou geradas por sistemas terceiros (ERP, CRM, Excel). O helper consegue identificar e resolver sozinho as variações mais comuns de arquivos de texto delimitados:

  • Codificação de caracteres: Descobre se o arquivo é UTF-8, UTF-8 com BOM, UTF-16LE, UTF-16BE ou Windows-1252 (padrão de exportações legadas do Excel em português).
  • Delimitadores (Dialeto): Identifica se o separador é ponto e vírgula (;), vírgula (,), tabulação (\t) ou pipe (|), respeitando inclusive a instrução explícita de cabeçalho sep=; do Microsoft Excel.
  • Cabeçalho inteligente: Localiza em qual linha estão os títulos das colunas, ignorando linhas em branco ou textos introdutórios que fiquem acima do cabeçalho.
  • Normalização de colunas: Converte títulos de colunas cheios de espaços ou acentos em chaves de banco limpas (ex.: "Descrição do Produto (ICMS)" vira "descricao_do_produto_icms").
  • Inferência de tipos: Analisa uma amostra do arquivo para deduzir o tipo de dados de cada coluna (inteiro, decimal localizado com vírgula, data em formato brasileiro, booleano "Sim/Não", etc.) e seus respectivos formatos.
  • Escalabilidade: Lê o arquivo sob demanda linha por linha utilizando geradores PHP (yield), permitindo processar planilhas gigantes de centenas de megabytes com consumo fixo e mínimo de memória.
Fluxo básico de uso
require_once JPATH_COMPONENT . '/helpers/CsvHelper.php';

// 1. Analisar o arquivo (descobre colunas, encoding, delimitador)
$analise = CsvHelper::analyze('uploads/clientes.csv');

if (!$analise['success']) {
    die($analise['message']); // Exceção amigável de validação do arquivo
}

// 2. Mostrar uma prévia amigável ao usuário na tela
$previa = CsvHelper::preview('uploads/clientes.csv', null, 5);

// 3. Importar em lotes para uma tabela do banco de dados
$resultado = CsvHelper::import('uploads/clientes.csv', '#__loja_clientes', null, [
    'mode' => 'upsert',
    'unique_by' => 'documento',
    'defaults' => ['status' => 'ativo']
]);

echo "Sucesso! Inseridos: {$resultado['data']['inserted_rows']}, Atualizados: {$resultado['data']['updated_rows']}";

Configurações globais

Valores e diretórios padrões para todo o ciclo de vida de processamento de CSVs na aplicação.

setBaseDirectory() / getBaseDirectory()estático

CsvHelper::setBaseDirectory(string|null $directory): void
CsvHelper::getBaseDirectory(): string|null

Define ou consulta o diretório raiz para os arquivos de dados. Se definido, todos os caminhos de arquivos passados para as funções do helper que não forem caminhos absolutos serão resolvidos relativamente a esta pasta.

CsvHelper::setBaseDirectory(JPATH_COMPONENT_ADMINISTRATOR . '/data');

// Resolverá para JPATH_COMPONENT_ADMINISTRATOR . '/data/planilhas/vendas.csv'
$analise = CsvHelper::analyze('planilhas/vendas.csv');

setLogDirectory() / setLogCategory()estático

CsvHelper::setLogDirectory(string|null $directory): void
CsvHelper::setLogCategory(string $category): void

Configura o diretório e a categoria onde o helper registrará suas ações, avisos de conversão e erros internos de processamento. Por padrão, ele usa a categoria do logger nativo do Joomla: "csv_helper".

setMaxFileSize()estático

CsvHelper::setMaxFileSize(int $bytes): void

Limita o tamanho máximo permitido de um arquivo CSV a ser aberto (padrão: 100MB). Arquivos que excederem esse limite dispararão uma exceção CsvHelperException.

setDefaultChunkSize() / setMaxChunkSize()estático

CsvHelper::setDefaultChunkSize(int $chunkSize): void
CsvHelper::setMaxChunkSize(int $chunkSize): void

Define e limita os tamanhos padrões de lotes (chunks) de linhas repassados aos callbacks durante o processamento (padrão de lote: 500 linhas; padrão limite máximo: 5000 linhas).

setDefaultDelimiter()estático

CsvHelper::setDefaultDelimiter(string|null $delimiter): void

Define um delimitador padrão fixo (ex.: "," ou ";") para ignorar o processo de auto-detecção por sniff de candidatos.

Detecção e Análise

Métodos para investigar a estrutura e metadados de um arquivo CSV antes de efetuar qualquer gravação ou processamento complexo.

detectEncoding()estático

CsvHelper::detectEncoding(string $path, string|null $baseDirectory = null): string

Retorna o conjunto de caracteres detectado para o arquivo ('UTF-8', 'UTF-16LE', 'UTF-16BE' ou 'Windows-1252').

detectDelimiter()estático

CsvHelper::detectDelimiter(string $path, string|null $baseDirectory = null, array $options = []): string

Realiza uma análise estatística das primeiras 40 linhas (ajustáveis nas configurações) para adivinhar qual o delimitador correto na linha de cabeçalho do arquivo. Retorna um caractere (ex.: ";").

analyze()estático

CsvHelper::analyze(string $path, string|null $baseDirectory = null, array $options = []): array

Varre e analisa toda a estrutura do CSV (codificação, separador, linha do cabeçalho, tipo provável de cada coluna com amostras de valores). É ideal para mostrar ao usuário o que o sistema "entendeu" antes de confirmar a importação física.

Retorna um array padronizado pelo ApiResponseHelper:

[

            [
                'index' => 0,

                'index' => 2,

                'type' => 'bool',

            ]
        ]
    ]
]

preview()estático

CsvHelper::preview(string $path, string|null $baseDirectory = null, int $limit = 10, array $options = []): array

Retorna os metadados do arquivo junto com as primeiras $limit linhas (máximo 100), já convertendo e mapeando as células nos tipos inferidos ou declarados.

Cada linha do array rows de retorno contém as chaves:

  • line: O número físico da linha no arquivo CSV.
  • raw: O array original de strings lido diretamente.
  • mapped: Array associativo onde as chaves são os nomes normalizados das colunas e os valores são strings brutas.
  • converted: Array associativo com os valores convertidos e tipados (ex.: booleanos reais, floats de PHP).
  • errors: Lista de erros de conversão encontrados especificamente nesta linha, se existirem.

Processamento em lote

Leitura sequencial sob demanda com delegação para callbacks, validação por linha e manipulação eficiente de memória.

process()estático

CsvHelper::process(string $path, callable $callback, string|null $baseDirectory = null, array $options = []): array

Lê todo o arquivo CSV de forma encadeada, agrupa as linhas processadas em lotes e entrega cada lote para a função de retorno configurada.

Callback de processamento
$resultado = CsvHelper::process('vendas.csv', function (array $lote, array $relatorio) {
    foreach ($lote as $linha) {
        $nroLinha = $linha['line'];
        $dados    = $linha['data']; // Convertidos segundo o mapeamento e tipos
        $originais = $linha['raw'];  // Strings originais lidas
        
        // Ex.: Enviar a API externa ou processar customizado
        FaturamentoService::registrar($dados);
    }
}, null, [
    'chunk_size' => 100,
    'convert' => true
]);

As opções aceitas pelo método process() e pelo método import() são:

Opção Tipo Padrão Descrição
chunk_size int 500 Tamanho do lote enviado ao callback ou banco.
encoding string null Força um charset (ex.: 'UTF-8', 'Windows-1252'). Se nulo, auto-detecta.
delimiter string null Força o delimitador (ex.: ','). Se nulo, auto-detecta.
convert bool false Se true, converte os valores das células para os tipos de dados correspondentes.
types array [] Tipos de colunas declarados explicitamente (ex.: ['registro_id' => 'int', 'saldo' => 'decimal']). Veja Mapeamento de tipos.
columns array null Lista de nomes de colunas esperados. Se enviado, realiza correspondência aproximada (Fuzzy Match) com as colunas do CSV.
mapping array [] Mapeamento manual de colunas: ['Título da Coluna CSV' => 'nome_banco'].
empty_as_null bool true Campos em branco no CSV viram null.
transform callable null Callback para mutar o array da linha de dados antes de validar e processar: fn($data, $line, $raw) => $data. Se retornar false, a linha é ignorada.
rules array [] Regras declarativas do ValidationHelper para validação. Exige que o ValidationHelper esteja presente.
validate_row callable null Callback de validação personalizado: fn($data, $line, $raw). Deve retornar true se válido, false ou uma string de erro se inválido.
stop_on_error bool false Interrompe o processamento na primeira linha que apresentar falha de conversão ou de validação.
max_errors int 1000 Quantidade máxima de erros permitidos antes de abortar o processamento.
required_headers array [] Lista de cabeçalhos originais que devem obrigatoriamente constar no arquivo CSV.
enforce_column_count bool false Se true, rejeita linhas que tenham número de células diferente do cabeçalho.

O retorno de process() é um array detalhando o relatório da importação:

[
    'success' => true,
    'message' => 'Processamento CSV concluído.',
    'data' => [
        'delimiter' => ';',
        'encoding' => 'UTF-8',
        'total_rows' => 1250,      // Total de linhas de dados no arquivo
        'processed_rows' => 1250,  // Linhas analisadas (inclui rejeitadas e ignoradas)
        'success_rows' => 1242,    // Linhas processadas com êxito
        'skipped_rows' => 8,       // Linhas rejeitadas/ignoradas
        'errors_count' => 8,       // Total de falhas registradas
        'errors' => [              // Detalhamento dos erros por linha
            [
                'line' => 12,
                'message' => 'e_mail: O campo E-mail deve conter um e-mail válido.',
                'data' => [
                    'errors' => ['e_mail' => ['O campo E-mail deve conter um e-mail válido.']],
                    'row' => ['nome' => 'Carlos', 'e_mail' => 'invalido-email']
                ]
            ]
        ]
    ]
]

Importação para banco de dados

Importa diretamente o conteúdo de um CSV para uma tabela do banco de dados, utilizando OrmTables e controle transacional avançado por savepoints.

import()estático

CsvHelper::import(string $path, string $table, string|null $baseDirectory = null, array $options = []): array

O método import() configura por baixo dos panos uma chamada para process(), onde a função de callback executa inserções ou atualizações na tabela informada.

Para máxima confiabilidade, o helper utiliza um mecanismo híbrido de segurança:

  • Definição implícita de tipos pela tabela: Se a tabela do banco possuir uma coluna saldo DECIMAL(10,2) e outra ativo INT, o helper mapeia e converte as strings correspondentes do CSV para float e int automaticamente.
  • Isolamento de lote por Savepoint (DbTransactionHelper): Cada lote de linhas é importado dentro de uma transação do banco. Se uma linha específica falhar por um erro de banco (violando um índice UNIQUE, por exemplo), apenas aquela linha é revertida via savepoint interno da transação. As outras linhas bem-sucedidas do lote são salvas normalmente, e a falha é registrada amigavelmente no relatório geral para o usuário.
Importando em modo Upsert
// Importa os cooperados. Se o CPF já existir, atualiza o nome e o telefone
$relatorio = CsvHelper::import(
    'uploads/cooperados.csv',
    '#__cooperados',
    null,
    [
        'mode' => 'upsert',
        'unique_by' => 'cpf',
        'defaults' => [
            'grupo_id' => 3,
            'atualizado_em' => JFactory::getDate()->toSql()
        ],
        'atomic' => false // Se true, qualquer erro na planilha desfaz todo o processo
    ]
);

Opções exclusivas do método import() (além das aceitas por process()):

Opção Tipo Padrão Descrição
connection string|object null Uma conexão cadastrada no DbConnectionHelper para onde a importação será enviada.
mode string 'insert' Usa 'insert' para apenas adicionar novas linhas, ou 'upsert' para adicionar ou atualizar registros que já existam.
unique_by string|array [] A coluna ou colunas chaves da tabela que identificam o registro para efetuar a atualização no modo upsert.
defaults array [] Array associativo com valores fixos aplicados para preencher colunas da tabela que não existam no CSV (ex.: ['categoria_id' => 5]).
dry_run bool false Simulação de importação. Executa toda a leitura, mapeamento de colunas, conversão e regras de validação sem gravar fisicamente nada no banco.
atomic bool false Tudo ou nada. Se definido como true, se houver um erro em qualquer linha, a transação inteira do banco é cancelada (Rollback), desfazendo toda a planilha.
orm array [] Opções adicionais repassadas diretamente na inicialização interna do OrmTables::table().
use_table_types bool true Habilita o carregamento automático dos tipos de dados de cada coluna diretamente da definição da tabela física do banco de dados.

Mapeamento de tipos

No array types das opções de processamento ou na inferência automática do analisador, o helper suporta e trata as seguintes conversões de tipos:

Tipo declarado Sinônimos Regra de conversão / Tratamento localizado
'int' integer Remove pontos de milhar, trata vírgula decimal se houver e faz o cast para (int).
'decimal' float, number, money Converte formatos numéricos locais. Suporta tanto padrão inglês (1,250.55) quanto brasileiro (1.250,55), resultando em (float).
'bool' boolean Retorna boolean real. Mapeia como true as palavras: '1', 'sim', 's', 'true', 'yes', 'y', 'verdadeiro', 'v', 'x' (não diferencia maiúsculas). Todo o restante vira false.
'date' — Identifica datas. Suporta formatos normais (YYYY-MM-DD) e localizados (DD/MM/YYYY), convertendo e salvando no padrão de banco YYYY-MM-DD.
'datetime' timestamp Combina data com horário localizado (ex.: "03/10/2026 14:30:00") e exporta em formato de banco SQL YYYY-MM-DD HH:MM:SS.
'intbool' — Se o valor for uma palavra booleana (Sim/Não), avalia para booleano (0 ou 1). Caso contrário, tenta fazer cast direto para inteiro numérico.
'digits' — Filtragem agressiva. Elimina do texto qualquer caractere que não seja um número (ex.: CPF com pontos e traços "123.456.789-00" vira apenas string "12345678900").
'string' text Retorna o valor como string normal do PHP, aplicando a codificação de caracteres correta (com limpeza automática de caracteres truncados).
Callable — Passagem de um callback anônimo para customizar totalmente a conversão:
'slug' => function($value, $line, $colName) { return strtolower(trim($value)); }

Gerenciamento de Rejeitados

Permite gerar planilhas de correção sob medida com os dados rejeitados, de forma a fechar o ciclo de importação de ponta a ponta sem perdas.

writeRejectedCsv()estático

CsvHelper::writeRejectedCsv(string $destinationPath, array $errors, string|null $baseDirectory = null, array $options = []): bool

Grava um arquivo CSV contendo todas as linhas que foram recusadas (por erro de validação ou erro de banco) durante o processamento.

Por padrão, utiliza as seguintes configurações padrão no arquivo resultante:

  • Formato Reimportável: Com a opção default 'reimportable' => true, a planilha gerada possui exatamente o mesmo layout e colunas do arquivo original que o usuário enviou, acrescentando apenas as colunas "linha" e "erro" na frente.
  • UTF-8 com BOM automático: Insere o Byte Order Mark (BOM) UTF-8 no início do arquivo para garantir que os caracteres especiais e acentos sejam exibidos perfeitamente no Microsoft Excel de qualquer usuário sem configurações adicionais.
Tratamento de rejeitados no controller
public function importar()
{
    $arquivoTmp = InputHelper::file('planilha');
    
    $resultado = CsvHelper::import($arquivoTmp['tmp_name'], '#__clientes', null, [
        'mode' => 'insert',
        'rules' => [
            'email' => 'required|email',
            'cpf' => 'required|cpf'
        ]
    ]);
    
    // Se houve erros, salvamos a planilha de rejeitados para download
    if ($resultado['data']['errors_count'] > 0) {
        $caminhoErro = 'tmp/rejeitados_' . time() . '.csv';
        
        CsvHelper::writeRejectedCsv($caminhoErro, $resultado['data']['errors'], null, [
            'reimportable' => true
        ]);
        
        return ApiResponseHelper::warning('Algumas linhas possuíam erros e foram rejeitadas.', [
            'importados' => $resultado['data']['success_rows'],
            'rejeitados_count' => $resultado['data']['errors_count'],
            'download_rejeitados' => $caminhoErro
        ]);
    }
    
    return ApiResponseHelper::success('Todos os dados foram importados com sucesso.');
}
