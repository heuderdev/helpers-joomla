ExportHelper

Exporta listas para CSV, em arquivo ou como download direto: colunas com rótulo e cálculo, proteção contra injeção de fórmulas no Excel, BOM para acentos e consultas grandes em lotes, sem estourar a memória.

Visão geral

controller.php
public function exportar()
{
    if (!PermissionHelper::require('core.manage')) {
        return;
    }

    $db = JFactory::getDbo();
    $query = $db->getQuery(true)
        ->select('id, cliente, total, status, created_at')
        ->from('#__loja_pedidos')
        ->order('id');   // ordem estável: obrigatória para ler em lotes

    ExportHelper::download('pedidos-' . date('Y-m-d') . '.csv', ExportHelper::generatorFromQuery($query), array(
        'id' => 'Pedido',
        'cliente' => 'Cliente',
        'total' => array('label' => 'Total (R$)', 'callback' => function ($linha) {
            return number_format((float) $linha['total'], 2, ',', '.');
        }),
        'status' => 'Status',
        'created_at' => 'Data',
    ), array('utf8_bom' => true));

    JFactory::getApplication()->close();   // sem isto, o Joomla acrescenta o HTML do template ao arquivo
}
  • Separador ; por padrão: o Excel em português abre direto, com as colunas certas.
  • Injeção de fórmulas bloqueada: valores que começam com =, +, -, @, tab ou CR ganham um ' na frente, para o Excel não executar =HYPERLINK(...) digitado por um cliente.
  • Memória constante: aceita array, Traversable ou generator; generatorFromQuery() lê o banco em lotes.
  • Arquivos só dentro do site: caminhos com ../ ou fora de JPATH_SITE são recusados.

fromQuery(), downloadFromQuery() e generatorFromQuery() recebem SQL (texto ou JDatabaseQuery) e executam no banco padrão do Joomla (JFactory::getDbo()), não numa conexão registrada no DbConnectionHelper. Para outro banco ou para usar o OrmBase, passe as linhas você mesmo (array ou generator, ex.: lendo com chunk()).

Colunas

O terceiro argumento diz quais colunas sair, em que ordem e com que título. Quatro formas, que podem ser misturadas:

$colunas = array(
    'id',                                              // chave e título iguais
    'nome' => 'Nome do cliente',                       // chave => título
    'endereco.cidade' => 'Cidade',                     // caminho com ponto em arrays aninhados
    'situacao' => function ($linha, $indice) {         // calculada (título = chave)
        return $linha['ativo'] ? 'Ativo' : 'Inativo';
    },
    'valor' => array(                                  // completa
        'label' => 'Valor (R$)',
        'key' => 'total',
        'callback' => function ($linha) {
            return number_format((float) $linha['total'], 2, ',', '.');
        },
    ),
    array('key' => 'email', 'label' => 'E-mail'),      // lista de arrays
);

Linhas podem ser arrays ou objetos. Valores: null → vazio; true/false → Sim/Não; DateTime → Y-m-d H:i:s; arrays e objetos → JSON; texto é aparado (trim).

Métodos

download()estático

ExportHelper::download(string $fileName, array|Traversable $rows, array $columns, array $options = array()): bool

Envia o CSV direto para o navegador (sem gravar no disco): limpa os buffers de saída, manda os cabeçalhos de download (no-store, nosniff, nome com acentos via filename*) e escreve linha a linha. Devolve false se falhar antes de começar. Chame $app->close() logo depois.

csv()estático

ExportHelper::csv(string $filePath, array|Traversable $rows, array $columns, string|null $baseDirectory = null, array $options = array()): array

Grava o CSV num arquivo (relativo à base, criada se não existir). Devolve o envelope { success, status, mensagem, data: { file: {...}, export: {...} } }; file tem relative_path, url, size, size_formatted…; export tem rows_written e bytes_written.

$nome = ExportHelper::temporaryFileName('clientes');   // clientes_20261005143000_9f2c....csv (imprevisível)
$r = ExportHelper::csv('exportacoes/' . $nome, $linhas, $colunas, 'administrator/tmp');

if (!$r['success']) {
    return ApiResponseHelper::error($r['mensagem']);
}

$caminho = $r['data']['file']['relative_path'];

fromQuery() / downloadFromQuery()estático

ExportHelper::fromQuery(string $filePath, string|JDatabaseQuery $query, array $columns, $baseDirectory = null, array $options = array()): array ExportHelper::downloadFromQuery(string $fileName, string|JDatabaseQuery $query, array $columns, array $options = array()): bool

Executam a consulta e exportam o resultado. Carregam todas as linhas na memória (loadAssocList): bom até algumas dezenas de milhares de linhas. Para mais, use generatorFromQuery().

generatorFromQuery()estático

ExportHelper::generatorFromQuery(string|JDatabaseQuery $query, int $batchSize = 1000): Generator

Lê a consulta em lotes (LIMIT/OFFSET, de 1 a 10.000 linhas) e entrega linha a linha. A consulta precisa de ORDER BY por uma coluna única (ex.: id): sem ordem estável, o banco pode repetir ou pular linhas entre os lotes.

temporaryFileName()estático

ExportHelper::temporaryFileName(string $prefix = 'exportacao'): string

Nome com data e 32 caracteres aleatórios. Use para arquivos gravados em pasta acessível: o nome não pode ser adivinhado.

Opções

OpçãoPadrãoO que faz
delimiter;Separador (1 caractere). Use , para sistemas em inglês, "\t" para TSV.
enclosure / escape" / vazioAspas e escape do fputcsv. Escape vazio = padrão RFC 4180 (aspas dobradas); no PHP anterior a 7.4 vira \.
headerstrueEscreve a linha de títulos.
utf8_bomfalseEscreve o BOM: o Excel no Windows passa a mostrar os acentos certos. Deixe desligado para importação em outros sistemas.

overwritetrueSó em csv(): sobrescrever arquivo existente.

on_progress / progress_every— / 1000function ($escritas) a cada N linhas e no fim (ex.: QueueHelper::progress()).

Com protect_csv_injection, -150,00 sai como '-150,00. Se a planilha precisa somar negativos, formate o valor numa coluna calculada sem sinal no início (ex.: (150,00)) ou desligue a proteção só quando todos os dados vierem do próprio sistema.

Exportações grandes (pela fila)

Acima de alguns segundos, a exportação não deve rodar na requisição (timeout, pessoa clicando de novo). Gere o arquivo num job e avise quando ficar pronto:

class ExportarPedidosJob extends AbstractJob
{
    public function handle()
    {
        $db = JFactory::getDbo();
        $query = $db->getQuery(true)
            ->select('id, cliente, total, status, created_at')
            ->from('#__loja_pedidos')
            ->where('created_at >= ' . $db->quote($this->getPayload('desde')))
            ->order('id');

        $nome = 'exportacoes/' . ExportHelper::temporaryFileName('pedidos');
        $self = $this;

        $total = (int) $this->getPayload('total');   // contado ao criar o job

        $r = ExportHelper::csv($nome, ExportHelper::generatorFromQuery($query, 2000), $this->getPayload('colunas'), 'administrator/tmp', array(
            'utf8_bom' => true,
            'on_progress' => function ($linhas) use ($self, $total) {
                $self->progress($linhas, $total);   // a tela acompanha pelo QueueHelper::status()
            },
        ));

        if (!$r['success']) {
            throw new RuntimeException($r['mensagem']);
        }

        return array('arquivo' => $r['data']['file']['relative_path']);   // o worker conclui o job com este resultado
    }
}

Entregue o arquivo pronto com UploadMaster::stream() ou FileHelper, depois de conferir que ele pertence a quem pediu. Veja o guia da fila.

Configuração

MétodoO que faz
setBaseDirectory($pasta) / getBaseDirectory()Pasta base dos arquivos (padrão: raiz do site). Prefira administrator/tmp ou uma pasta bloqueada por .htaccess.
setMaxRows($n)Limite de linhas.
setDirectoryPermission() / setFilePermission()Permissões (0755 / 0644).
setLogCategory() / setLogDirectory()Log das exportações (export_helper.php).
formatBytes($bytes)1.5 MB.

Exportações costumam ter dados pessoais (CPF, e-mail, telefone). Não grave em pasta pública com nome previsível, exija permissão na task (PermissionHelper::require) e apague os arquivos antigos.
