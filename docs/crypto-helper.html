CryptoHelper

Criptografia autenticada para segredos guardados no banco (tokens de API, credenciais de integração), conferência de assinatura de webhooks, links assinados com prazo e tokens e códigos aleatórios seguros.

Visão geral

require_once JPATH_COMPONENT . '/helpers/CryptoHelper.php';

// Gravar o token do ERP que o administrador digitou
$dados['erp_token'] = CryptoHelper::encrypt($tokenDigitado, 'config.erp_token');

// Usar
$token = CryptoHelper::decrypt($config->erp_token, 'config.erp_token');   // null se adulterado ou chave errada

if ($token === null) {
    return ApiResponseHelper::error('Configure novamente o token do ERP.');
}
  • Criptografia autenticada: XChaCha20-Poly1305 (extensão sodium, padrão no PHP 7.2+) ou, sem sodium, AES-256-CBC + HMAC-SHA256. Um byte alterado faz o decrypt devolver null, nunca lixo.
  • Contexto: o valor fica preso ao lugar ('config.erp_token', 'clientes.cpf'). Copiar o valor cifrado de uma coluna para outra não funciona.
  • Nonce aleatório a cada chamada: o mesmo texto cifrado duas vezes dá resultados diferentes (ninguém descobre que dois clientes têm o mesmo dado).
  • Texto ASCII (h1:...), seguro para VARCHAR/TEXT: cerca de 1,4 vez o tamanho original + 60 caracteres. Use TEXT ou um VARCHAR com folga.

Senhas de usuários não se criptografam Senha se guarda com hash lento e irreversível: use o do Joomla (JUserHelper::hashPassword() / verifyPassword()). O CryptoHelper é para segredos que o sistema precisa ler de volta (token de API, senha de SMTP de um cliente, certificado).

A chave

Sem configuração, a chave é derivada do secret do configuration.php. Funciona, mas quem troca o secret (ou restaura o site com outro configuration.php) perde o acesso a tudo que foi cifrado. Em produção, gere uma chave própria e guarde fora da pasta pública:

php -r 'echo base64_encode(random_bytes(32)), PHP_EOL;'      # ou CryptoHelper::generateKey()
// Uma vez, no início do componente: de variável de ambiente ou de um arquivo fora do public_html
CryptoHelper::setKey(getenv('LOJA_CRYPTO_KEY') ?: trim(file_get_contents('/home/loja/chaves/crypto.key')));

Troca de chave (rotação)

CryptoHelper::setKey($chaveNova);
CryptoHelper::setPreviousKeys(array($chaveAntiga));   // decrypt tenta a nova e depois as antigas

// Recifra aos poucos (ex.: num job) e, quando acabar, remova a chave antiga
foreach (OrmTables::table('#__loja_integracoes')->get() as $linha) {
    $novo = CryptoHelper::reencrypt($linha->token, 'integracoes.token');

    if ($novo !== null) {
        OrmTables::table('#__loja_integracoes')->where('id', $linha->id)->update(array('token' => $novo));
    }
}

Faça backup da chave junto com o backup do banco, em lugar separado. Sem a chave, os dados cifrados são irrecuperáveis.

Métodos de criptografia

encrypt() / decrypt()estático

CryptoHelper::encrypt(string $plaintext, string $context = ''): string CryptoHelper::decrypt(string $encrypted, string $context = ''): string|null

decrypt devolve null (e registra no log crypto) se o valor foi adulterado, é de outro contexto, foi cifrado com outra chave ou nem é um valor cifrado. Lança exceção só se o PHP não tiver como decifrar (valor h1: num servidor sem sodium).

isEncrypted() / reencrypt()estático

CryptoHelper::isEncrypted(string $value): bool CryptoHelper::reencrypt(string $encrypted, string $context = ''): string|null

Para migrar colunas que ainda têm valores em claro e para rotação de chave.

// Migração: cifra o que ainda está em claro
if (!CryptoHelper::isEncrypted($linha->cpf)) {
    $atualizar['cpf'] = CryptoHelper::encrypt($linha->cpf, 'clientes.cpf');
}

Coluna cifrada não pode ser buscada com WHERE cpf = ? nem ordenada. Se precisar buscar, guarde também um índice cego: cpf_hash = CryptoHelper::hashToken($cpfSóDígitos), e busque por ele.

Assinatura de webhooks

verifySignature()estático

CryptoHelper::verifySignature(string $payload, string $signature, string $secret, array $options = array()): bool

Confere em tempo constante. Opções: algo (sha256), encoding (hex ou base64), prefix (ex.: sha256=).

$corpo = file_get_contents('php://input');   // o corpo CRU: re-codificar o JSON muda os bytes e quebra a assinatura
$assinatura = isset($_SERVER['HTTP_X_HUB_SIGNATURE_256']) ? $_SERVER['HTTP_X_HUB_SIGNATURE_256'] : '';

if (!CryptoHelper::verifySignature($corpo, $assinatura, $segredoDoWebhook, array('prefix' => 'sha256='))) {
    return ApiResponseHelper::unauthorized('Assinatura inválida.');
}

Para receber webhooks com proteção contra reenvio e processamento pela fila, veja o WebhookHelper.

hmac()estático

CryptoHelper::hmac(string $data, string|null $secret = null, string $algo = 'sha256'): string

HMAC em hex. Sem $secret, usa uma subchave da chave mestra (para assinar coisas do próprio sistema, como webhooks que você envia).

Links assinados com prazo

sign() / verifySigned()estático

CryptoHelper::sign(array $data, int $seconds = 3600): string CryptoHelper::verifySigned(string $token): array|null

Um link que carrega dados e não pode ser alterado nem usado depois do prazo, sem tabela de tokens: "baixar o boleto", "confirmar presença", "descadastrar".

// Gerar (e-mail)
$link = JUri::root() . 'index.php?option=com_loja&task=boleto.baixar&t=' . CryptoHelper::sign(array('pedido' => $pedido->id), 7 * 86400);

// Conferir (controller)
$dados = CryptoHelper::verifySigned(InputHelper::string('t'));

if ($dados === null) {
    return ApiResponseHelper::forbidden('Link inválido ou vencido.');
}

$pedidoId = (int) $dados['pedido'];

Os dados ficam legíveis no link (base64), só não podem ser alterados. Não coloque segredos neles. Para uso único ("redefinir senha"), use um token guardado com hashToken().

$registro = OrmTables::table('#__loja_resets')

    ->first();

Requisitos

  • PHP 7.0+ com openssl; com sodium (padrão no 7.2+) usa XChaCha20-Poly1305. Valores h2: (openssl) são lidos em qualquer servidor; valores h1: exigem sodium no servidor que lê.
  • Sem setKey(), um secret do Joomla com pelo menos 16 caracteres.
