LockHelper

Impede que a mesma tarefa rode duas vezes ao mesmo tempo: cron que se sobrepõe, clique duplo em "gerar boletos", duas importações da mesma planilha. Usa a trava do próprio banco (MySQL/MariaDB ou PostgreSQL) ou de arquivo, e nunca fica presa depois de um erro fatal.

Visão geral

require_once JPATH_COMPONENT . '/helpers/LockHelper.php';

$r = LockHelper::run('gerar-boletos', function () {
    // só um processo por vez chega aqui
    return BoletoService::gerarDoMes();
});

if (!$r['acquired']) {
    return ApiResponseHelper::conflict('A geração de boletos já está em andamento. Aguarde ela terminar.');
}

return ApiResponseHelper::success('Boletos gerados.', $r['result']);

Por que não basta um campo "processando" na tabela

  • Corrida: dois processos leem "processando = 0" no mesmo milissegundo e os dois começam. A trava do banco é atômica.
  • Trava presa: se o processo morre (timeout, erro fatal, kill), o campo fica "processando = 1" para sempre. As travas do LockHelper são do processo/conexão: somem quando ele morre.
  • lockForUpdate() não serve: trava linhas dentro de uma transação, não uma tarefa inteira que lê APIs, gera arquivos e faz várias transações.

Métodos

run()estático

LockHelper::run(string $name, callable $callback, float $wait = 0, array $options = array()): array

Pega a trava, executa o callback e solta a trava no fim, mesmo se o callback lançar exceção (a exceção continua subindo). Devolve array('acquired' => bool, 'result' => retorno do callback). $wait: segundos esperando a trava ficar livre (0 = desiste na hora). Opções: 'throw' => true lança LockHelperException quando não consegue; 'message' troca o texto dela.

acquire() / release()estático

LockHelper::acquire(string $name, float $wait = 0): bool LockHelper::release(string $name): bool

Controle manual, para quando a trava atravessa vários passos. Sempre em try/finally. No mesmo processo é reentrante: pegar duas vezes exige soltar duas vezes.

if (!LockHelper::acquire('importacao:' . $arquivoId, 10)) {
    return ApiResponseHelper::conflict('Este arquivo já está sendo importado.');
}

try {
    // vários passos
} finally {
    LockHelper::release('importacao:' . $arquivoId);
}

isLocked()estático

LockHelper::isLocked(string $name): bool

Se alguém segura a trava agora. Só para informar a tela ("importação em andamento"): entre a consulta e a ação outro processo pode pegar a trava. Para decidir, use acquire()/run().

held() / releaseAll()estático

LockHelper::held(): array LockHelper::releaseAll(): void

Travas deste processo; soltar todas (também é feito sozinho no fim do script).

Escolhendo o nome

O nome define o que não pode acontecer ao mesmo tempo:

NomeEfeito
'gerar-boletos'uma geração por vez no site todo
'pedido:' . $idoperações no mesmo pedido em fila; pedidos diferentes em paralelo
'estoque:' . $produtoIdbaixa de estoque concorrente do mesmo produto
'sync-erp:' . $empresaIduma sincronização por empresa

O nome é transformado num hash junto com o banco e o prefixo das tabelas do site: dois sites Joomla no mesmo servidor MySQL não se travam mutuamente.

Receitas

Cron que não se sobrepõe

cli/sincronizar-erp.php
// Roda a cada 5 minutos; se a anterior ainda estiver rodando, esta sai sem fazer nada.
$r = LockHelper::run('cron:sincronizar-erp', function () {
    return ErpSync::executar();
});

if (!$r['acquired']) {
    LogHelper::notice('Sincronização anterior ainda em andamento; pulando.', 'erp');
    exit(0);
}

Clique duplo numa ação cara

public function faturar()
{
    try {
        if (!JSession::checkToken()) {
            return ApiResponseHelper::forbidden('Sua sessão expirou. Recarregue a página.');
        }

        $id = InputHelper::int('id');

        $r = LockHelper::run('pedido:' . $id, function () use ($id) {
            $pedido = OrmTables::table('#__loja_pedidos')->findOrFail($id);

            if ($pedido->status === 'faturado') {   // releia o estado dentro da trava
                return array('ja_faturado' => true);
            }

            return FaturamentoService::faturar($pedido);
        });

        if (!$r['acquired']) {
            return ApiResponseHelper::conflict('Este pedido já está sendo faturado.');
        }

        return ApiResponseHelper::success('Pedido faturado.', $r['result']);
    } catch (Throwable $e) {
        return ApiResponseHelper::exception($e);
    }
}

A trava evita execuções simultâneas, não repetidas: depois que a primeira termina, a segunda pega a trava e roda. Por isso o exemplo relê o estado dentro da trava e não fatura de novo.

Dentro de um job da fila

O QueueHelper já garante que um job não é processado por dois workers. Use o LockHelper para recursos compartilhados entre jobs diferentes, como "só um job de importação por cliente por vez": com $wait 0 e, se não conseguir, $this->release(60) devolve o job à fila para tentar daqui a um minuto.

public function handle()
{
    $r = LockHelper::run('importacao:cliente:' . $this->getPayload('cliente_id'), function () {
        return ImportacaoService::processar($this->getPayload('arquivo'));
    });

    if (!$r['acquired']) {
        $this->release(60);   // tenta de novo em 1 minuto, sem gastar tentativa
        return;
    }

    return $r['result'];
}

Drivers

DriverComo funcionaVale entre
mysqlGET_LOCK() / RELEASE_LOCK() (MySQL 5.7+, MariaDB 10.0.2+)todos os servidores que usam o mesmo banco
pgsqlpg_try_advisory_lock() (de sessão)todos os servidores que usam o mesmo banco
fileflock() num arquivo em tmp/lockssó processos do mesmo servidor

O padrão (auto) usa o banco do Joomla e, se não houver banco, arquivo. Configuração:

LockHelper::setDriver('file');                        // 'auto', 'mysql', 'pgsql' ou 'file'
LockHelper::setConnection('erp');                     // trava no banco de outra conexão do DbConnectionHelper
LockHelper::setDirectory(JPATH_ROOT . '/tmp/locks');  // pasta das travas em arquivo

Limites conhecidos. As travas de banco pertencem à conexão: se ela cair no meio (wait_timeout do MySQL num script parado muito tempo), a trava some junto. Com PgBouncer em modo transaction, travas de sessão não funcionam: use o driver file (um servidor) ou conecte direto ao PostgreSQL. No MySQL anterior a 5.7, pegar uma segunda trava solta a primeira.
