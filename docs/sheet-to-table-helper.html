SheetToTableHelper

Importa CSV, XLSX, XLS ou ODS direto para uma tabela, casando o cabeçalho do arquivo com os campos da tabela pelo nome, em qualquer ordem. Cada valor é conferido contra o tipo da coluna no banco, cada erro volta com a linha e o campo exatos e, por padrão, qualquer erro desfaz a importação inteira (rollback). Lê arquivos de 1 milhão de linhas ou mais linha a linha, sem carregar o arquivo na memória.

Visão geral

Tabela e arquivo
// tabela #__desempenho:  ID (auto) | NUM_CENTRAL | PRODUTO | DATA_BASE | PRODUCAO
// arquivo.csv:           PRODUCAO;Data Base;num_central;Produto     -> importa (ordem e grafia não importam)
// arquivo.csv:           PRODUCAO;NUM_CENTRAL;PRODUTO                -> bloqueia:
//   "Importação cancelada. Falta a seguinte coluna no arquivo: DATA_BASE."

$res = SheetToTableHelper::import($arquivo, '#__desempenho', [
    'mode'     => 'replace',    // append (padrão) | replace | upsert | insert_new
    'on_error' => 'rollback',   // padrão: qualquer erro desfaz tudo; 'skip' grava as boas
]);

if (!$res['valido']) {
    echo $res['mensagem'];                                   // texto pronto para o usuário
    print_r(SheetToTableHelper::errorLines($res));           // ["Linha 37, campo DATA_BASE: Data inválida: \"31/02/2026\".", ...]
}

O que ele faz por você:

  • Cabeçalho flexível: Data Base, data-base, DATA_BASE e Dáta Base casam com DATA_BASE. Coluna faltando, repetida ou (se você quiser) sobrando bloqueia antes de tocar no banco, com sugestão: Falta DATA_BASE (no arquivo há "DATA_BAS").
  • Tipo da coluna lido do banco: inteiro e os limites de TINYINT a BIGINT (com UNSIGNED), DECIMAL(p,s), data, data e hora, TIMESTAMP, hora, ano, texto e tamanho, ENUM, JSON, UUID e booleano.
  • Formatos brasileiros: 1.234,56, R$ 10,00, (10) negativo, 17/11/2026, sim/não, além de ISO, padrão americano e datas seriais do Excel.
  • Arquivo grande: CSV e XLSX lidos em fluxo, gravação em lotes de 1000 linhas por INSERT e lote dividido sozinho se passar do max_allowed_packet.
  • Erro exato: se o banco recusar um lote (duplicado, chave estrangeira), ele volta ao savepoint e grava linha a linha para apontar qual linha o banco rejeitou.
  • Quatro modos: inserir, substituir (tudo, por filtro ou pelas chaves que vieram no arquivo), upsert e inserir só os novos.

Dependências: DbConnectionHelper, DbTransactionHelper e OrmTables, carregados sozinhos se estiverem na mesma pasta (ou IncludeHelper::load('SheetToTableHelper')). Usa o LogHelper se estiver carregado (categoria sheet_to_table). PHP: extensões mbstring; zip e xmlreader para XLSX. XLS e ODS (e o modelo em .xlsx) precisam da phpoffice/phpspreadsheet (composer require phpoffice/phpspreadsheet). Roda no Joomla 3 a 6 sem configurar nada; no Laravel e em PHP puro com a conexão registrada no DbConnectionHelper.

Como funciona uma importação

  1. Estrutura: lê as colunas da tabela no banco (getTableColumns, guardado em cache na requisição). Colunas AUTO_INCREMENT/serial/identity e colunas geradas nunca entram.
  2. Plano: separa os campos em procurados no arquivo, obrigatórios, opcionais, fixos (fixed) e ignorados (ignore, only).
  3. Cabeçalho: casa o cabeçalho com os campos (matchHeaders()). Se faltar coluna, devolve o alerta sem abrir transação.
  4. Linhas: para cada linha não vazia: trim, vazio vira NULL, transform do campo, conversão pelo tipo, campos fixos e row_callback. Erros vão para a lista com linha, campo, mensagem e valor.
  5. Gravação: dentro de uma transação (padrão), apaga o que o modo pedir, monta INSERT com várias linhas e bindings, e grava em lotes. Lote recusado pelo banco é refeito linha a linha dentro de savepoints.
  6. Fim: com on_error = rollback e qualquer erro, desfaz tudo (inclusive o DELETE do modo replace) e devolve a lista de erros; senão confirma e devolve o resumo.

Com on_error = rollback, depois do primeiro erro ele para de gravar, mas continua lendo o arquivo para listar os erros de todas as linhas (até max_errors). O usuário corrige tudo de uma vez, não um erro por envio.

Ponta a ponta no Joomla: tela de importação com prévia

Sistema completo: o usuário baixa o modelo, envia a planilha, vê a prévia com os erros e confirma. A importação é protegida por token e por grupo, presa à cooperativa do usuário, travada contra clique duplo, auditada e com download das linhas com erro.

sql/install.mysql.sql
CREATE TABLE `#__credito_producao` (
  `id`           INT UNSIGNED NOT NULL AUTO_INCREMENT,
  `cod_singular` SMALLINT UNSIGNED NOT NULL,
  `cod_pa`       SMALLINT UNSIGNED NOT NULL DEFAULT 0,
  `produto`      VARCHAR(40) NOT NULL,
  `data_base`    DATE NOT NULL,
  `producao`     DECIMAL(14,2) NOT NULL,
  `situacao`     ENUM('ativo','inativo') NOT NULL DEFAULT 'ativo',
  `obs`          VARCHAR(255) NULL,
  `importado_por` INT NOT NULL,
  `criado_em`    TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_producao` (`cod_singular`, `cod_pa`, `produto`, `data_base`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

O usuário envia só cod_pa, produto, data_base, producao, situacao e obs. A singular e o autor vêm do UserHelper (fixed): ninguém importa dados para outra cooperativa mudando uma coluna da planilha.

helpers/ImportacaoProducao.php
<?php

defined('_JEXEC') or die;

/*
 * Regras da importação num lugar só: a tela de prévia e a gravação usam
 * as mesmas opções, então o que passou na prévia passa na gravação.
 */
class ImportacaoProducao
{
    const TABELA = '#__credito_producao';

    // Sem $userId/$singular, usa o usuário logado. No worker (sem login), passe os dois.
    public static function opcoes($dataBase, $userId = null, $singular = null)
    {
        $userId   = $userId !== null ? (int) $userId : UserHelper::id();
        $singular = (int) ($singular !== null ? $singular : UserHelper::singular());

        return [
            'require'  => 'not_null',                 // situacao e obs podem faltar no arquivo
            'ignore'   => ['criado_em'],
            'fixed'    => [
                'cod_singular'  => $singular,
                'importado_por' => $userId,
            ],
            'aliases'  => [
                'cod_pa'   => ['PA', 'Posto'],
                'producao' => ['Produção (R$)', 'Valor'],
            ],
            'transform' => [
                'produto' => function ($valor) {
                    return $valor === null ? null : mb_strtoupper($valor);
                },
            ],
            // A data-base tem que ser a escolhida na tela: protege contra planilha do mês errado.
            'row_callback' => function (array $linha) use ($dataBase) {
                if ($linha['data_base'] !== $dataBase) {
                    throw new RuntimeException('Data-base diferente da escolhida (' . date('d/m/Y', strtotime($dataBase)) . ').');
                }

                return $linha;
            },
            // Substitui só a produção desta singular nesta data-base.
            'mode'          => 'replace',
            'replace_where' => ['cod_singular' => $singular, 'data_base' => $dataBase],
            'show_db_errors' => false,
        ];
    }
}

<?php

defined('_JEXEC') or die;

require_once JPATH_COMPONENT . '/helpers/IncludeHelper.php';

IncludeHelper::load([
    'SheetToTableHelper', 'InputHelper', 'ApiResponseHelper', 'PermissionHelper',
    'UserHelper', 'LockHelper', 'AuditHelper', 'ExportHelper', 'UploadMaster', 'LogHelper',
]);
require_once JPATH_COMPONENT . '/helpers/ImportacaoProducao.php';

class CreditoController extends JControllerLegacy
{
    // Pasta com .htaccess "Require all denied": só sai pelo baixarErros(), que confere o grupo.
    const PASTA_ERROS = JPATH_SITE . '/media/com_credito/privado/erros';

    // GET: planilha modelo só com o cabeçalho esperado.
    public function modelo()
    {
        if (!UserHelper::requireGroup(['Gerentes', 'TI'])) {
            return;
        }

        $arquivo = tempnam(sys_get_temp_dir(), 'modelo') . '.csv';
        SheetToTableHelper::template(ImportacaoProducao::TABELA, $arquivo, ImportacaoProducao::opcoes(date('Y-m-d')));

        header('Content-Type: text/csv; charset=UTF-8');
        header('Content-Disposition: attachment; filename="modelo-producao.csv"');
        header('Content-Length: ' . filesize($arquivo));
        readfile($arquivo);
        unlink($arquivo);

        JFactory::getApplication()->close();
    }

    // POST: confere cabeçalho e as 20 primeiras linhas, sem gravar.
    public function previa()
    {
        try {
            if (!PermissionHelper::requireToken() || !UserHelper::requireGroup(['Gerentes', 'TI'])) {
                return;
            }

            // XLSX é um ZIP: $raw = true evita o isSafeFile do Joomla recusar o arquivo por engano.
            $planilha = InputHelper::file('planilha', null, true);
            $dataBase = InputHelper::date('data_base');

            if ($planilha === null || $dataBase === '') {
                return ApiResponseHelper::error('Escolha a planilha e a data-base.', null, [], ['http_status' => 422]);
            }

            $previa = SheetToTableHelper::preview($planilha, ImportacaoProducao::TABELA, 20, ImportacaoProducao::opcoes($dataBase));

            if (!$previa['valido']) {
                return ApiResponseHelper::error(SheetToTableHelper::missingMessage($previa) ?: $previa['mensagem'], [
                    'faltantes' => $previa['faltantes'],
                    'sugestoes' => $previa['sugestoes'],
                ], [], ['http_status' => 422]);
            }

            return ApiResponseHelper::success($previa['mensagem'], [
                'aba'       => $previa['aba'],
                'cabecalho' => $previa['cabecalho'],
                'linhas'    => $previa['linhas'],                 // [['linha' => 2, 'dados' => [...], 'erros' => [...]], ...]
                'erros'     => SheetToTableHelper::errorLines($previa),
            ]);
        } catch (SheetToTableException $e) {
            return ApiResponseHelper::error($e->getMessage(), null, [], ['http_status' => 422]);   // "O arquivo está vazio.", "Formato não suportado..."
        } catch (Throwable $e) {
            return ApiResponseHelper::exception($e);
        }
    }

    // POST: grava (tudo ou nada).
    public function importar()
    {
        try {
            if (!PermissionHelper::requireToken() || !UserHelper::requireGroup(['Gerentes', 'TI'])) {
                return;
            }

            $planilha = InputHelper::file('planilha', null, true);
            $dataBase = InputHelper::date('data_base');

            if ($planilha === null || $dataBase === '') {
                return ApiResponseHelper::error('Escolha a planilha e a data-base.', null, [], ['http_status' => 422]);
            }

            // Uma importação por singular de cada vez (clique duplo, duas abas abertas).
            $trava = LockHelper::run('credito-producao-' . UserHelper::singular(), function () use ($planilha, $dataBase) {
                return SheetToTableHelper::import($planilha, ImportacaoProducao::TABELA, ImportacaoProducao::opcoes($dataBase));
            });

            if (!$trava['acquired']) {
                return ApiResponseHelper::conflict('Já existe uma importação desta cooperativa em andamento.');
            }

            $res = $trava['result'];

            AuditHelper::imported('credito_producao', [
                'arquivo'   => $planilha['name'],
                'data_base' => $dataBase,
                'valido'    => $res['valido'],
                'gravadas'  => $res['gravadas'],
                'apagadas'  => $res['apagadas'],
                'com_erro'  => $res['com_erro'],
            ]);

            if (!$res['valido']) {
                return ApiResponseHelper::error($res['mensagem'], [
                    'erros'        => SheetToTableHelper::errorLines($res, 50),
                    'download'     => $res['erros'] ? $this->salvarErros($res['erros']) : null,
                    'truncados'    => $res['erros_truncados'],
                ], [], ['http_status' => 422]);
            }

            return ApiResponseHelper::success($res['mensagem'], [
                'gravadas' => $res['gravadas'],
                'apagadas' => $res['apagadas'],
                'segundos' => $res['tempo_segundos'],
            ]);
        } catch (SheetToTableException $e) {
            return ApiResponseHelper::error($e->getMessage(), null, [], ['http_status' => 422]);
        } catch (Throwable $e) {
            return ApiResponseHelper::exception($e);
        }
    }

    // Lista de erros em CSV (pasta privada, nome aleatório).
    private function salvarErros(array $erros)
    {
        $nome = bin2hex(random_bytes(16)) . '.csv';

        $r = ExportHelper::csv($nome, $erros, [
            'linha'    => 'Linha',
            'campo'    => 'Campo',
            'mensagem' => 'Problema',
            'valor'    => 'Valor enviado',
        ], self::PASTA_ERROS, ['utf8_bom' => true]);

        return $r['success'] ? $nome : null;
    }

    // GET: baixa a lista de erros gerada acima.
    public function baixarErros()
    {
        if (!UserHelper::requireGroup(['Gerentes', 'TI'])) {
            return;
        }

        $nome = InputHelper::string('arquivo', '', 'get');

        // Só o formato que o salvarErros() gera: sem "../", sem outro arquivo da pasta.
        if (!preg_match('/^[a-f0-9]{32}\.csv$/', $nome)) {
            return ApiResponseHelper::notFound('Arquivo não encontrado.');
        }

        UploadMaster::stream($nome, 'erros-importacao.csv', ['base_directory' => self::PASTA_ERROS]);
        JFactory::getApplication()->close();
    }
}

Segurança da tela: o token e o grupo são conferidos nas três tasks que leem ou gravam; a singular vem do servidor (fixed), não da planilha; o replace_where limita o DELETE à singular do usuário (com replace_by => ['data_base'] ele apagaria a data-base de todas as cooperativas); o arquivo de erros tem nome aleatório numa pasta bloqueada ao acesso direto (.htaccess com Require all denied) e o download só aceita esse formato de nome; o JavaScript usa textContent, então um texto da planilha nunca vira HTML.

Arquivo de 1 milhão de linhas: importação em segundo plano

Uma planilha de 1 milhão de linhas leva alguns minutos. Em vez de deixar a requisição aberta, salve o arquivo com o UploadMaster, enfileire um job no QueueHelper e mostre o progresso.

controller.php: enfileirar
public function importarGrande()
{
    try {
        if (!PermissionHelper::requireToken() || !UserHelper::requireGroup(['Gerentes', 'TI'])) {
            return;
        }

        $planilha = InputHelper::file('planilha', null, true);
        $dataBase = InputHelper::date('data_base');

        if ($planilha === null || $dataBase === '') {
            return ApiResponseHelper::error('Escolha a planilha e a data-base.', null, [], ['http_status' => 422]);
        }

        // Confere o cabeçalho na hora: o usuário não espera o job para saber que falta coluna.
        $cabecalho = SheetToTableHelper::validate($planilha, ImportacaoProducao::TABELA, ImportacaoProducao::opcoes($dataBase));

        if (!$cabecalho['valido']) {
            return ApiResponseHelper::error(SheetToTableHelper::missingMessage($cabecalho), null, [], ['http_status' => 422]);
        }

        // Pasta bloqueada ao acesso direto (.htaccess "Require all denied").
        $salvo = UploadMaster::upload($planilha, 'media/com_credito/privado/importacoes/' . date('Y-m'), null, [
            'allowed_extensions' => SheetToTableHelper::supportedExtensions(),
            'raw' => true,
        ]);

        if (!$salvo['success']) {
            return ApiResponseHelper::error($salvo['mensagem'], null, [], ['http_status' => 422]);
        }

        $job = QueueHelper::push('importar_producao', [
            'arquivo'   => $salvo['data']['path'],
            'data_base' => $dataBase,
            'user_id'   => UserHelper::id(),
            'singular'  => (int) UserHelper::singular(),   // o worker não tem usuário logado: leva daqui
        ], [
            'usuario_id'      => UserHelper::id(),
            'unico'           => ['arquivo'],
            'max_tentativas'  => 1,           // rollback já garante tudo ou nada: não tenta de novo sozinho
            'timeout_seconds' => 3600,
        ]);

        return $job['success']
            ? ApiResponseHelper::created('Importação na fila. Acompanhe o progresso.', ['uuid' => $job['data']['uuid']])
            : ApiResponseHelper::error($job['mensagem']);
    } catch (SheetToTableException $e) {
        return ApiResponseHelper::error($e->getMessage(), null, [], ['http_status' => 422]);
    } catch (Throwable $e) {
        return ApiResponseHelper::exception($e);
    }
}

// GET: a tela consulta de tempos em tempos.
public function statusImportacao()
{
    $status = QueueHelper::status(InputHelper::string('uuid', '', 'get'), UserHelper::id());

    return $status['success'] ? ApiResponseHelper::success($status['mensagem'], $status['data']) : ApiResponseHelper::notFound($status['mensagem']);
}
jobs/ImportarProducaoJob.php
<?php

defined('_JEXEC') or die;

class ImportarProducaoJob extends AbstractJob
{
    public function handle()
    {
        $arquivo  = (string) $this->getPayload('arquivo');
        $dataBase = (string) $this->getPayload('data_base');
        $userId   = (int) $this->getPayload('user_id');

        // As mesmas regras da tela, com o usuário e a singular gravados no payload.
        $opcoes = ImportacaoProducao::opcoes($dataBase, $userId, (int) $this->getPayload('singular'));

        $opcoes['batch_size'] = 2000;
        $opcoes['on_progress'] = function (array $p) {
            // ['lote' => 12, 'linhas_lidas' => 24000, 'com_erro' => 0, 'memoria_mb' => 18.0]
            $this->progress($p['linhas_lidas']);
        };

        try {
            $res = SheetToTableHelper::import($arquivo, ImportacaoProducao::TABELA, $opcoes);
        } catch (SheetToTableException $e) {
            return $this->fail($e->getMessage(), true);     // arquivo ilegível não melhora tentando de novo
        }

        AuditHelper::imported('credito_producao', array_intersect_key($res, array_flip(['valido', 'gravadas', 'apagadas', 'com_erro'])), [
            'user' => ['id' => $userId],
        ]);

        if (!$res['valido']) {
            return $this->fail($res['mensagem'] . ' ' . implode(' | ', SheetToTableHelper::errorLines($res, 20)), true);
        }

        @unlink($arquivo);

        return $this->complete([
            'mensagem' => $res['mensagem'],
            'gravadas' => $res['gravadas'],
            'apagadas' => $res['apagadas'],
            'segundos' => $res['tempo_segundos'],
            'memoria'  => $res['memoria_pico_mb'],
        ]);
    }
}
jobs.php (registro, carregado no componente e no worker)
JobRegistry::register('importar_producao', JPATH_SITE . '/components/com_credito/jobs/ImportarProducaoJob.php', 'ImportarProducaoJob', 'imports');

Em 1 milhão de linhas, com atomic (padrão) a transação fica aberta durante toda a gravação. Isso é o que garante o "nada foi gravado" no erro. Se o banco reclamar do tamanho da transação, use 'validate_first' => true, 'atomic' => false: ele lê o arquivo inteiro uma vez sem gravar e só grava se não houver erro, uma transação por lote (veja atomic).

Laravel e PHP puro

Fora do Joomla, registre a conexão no DbConnectionHelper (pacote joomla/database pelo Composer) e passe 'connection'. O resto é igual.

app/Providers/AppServiceProvider.php
public function boot(): void
{
    $db = config('database.connections.mysql');

    \DbConnectionHelper::register('app', [
        'driver'   => 'mysqli',

Métodos

$arquivo é sempre um caminho ou a entrada do $_FILES (['tmp_name', 'name', 'error'], como devolve o InputHelper::file()): o formato sai do name original, porque o temporário do upload não tem extensão. $tabela aceita o prefixo #__. Problemas no arquivo ou nas opções lançam SheetToTableException, com mensagem que pode ser mostrada ao usuário.

import()estático

SheetToTableHelper::import(string|array $arquivo, string $tabela, array $opcoes = []): array

Importa para a tabela. Confere o cabeçalho, converte cada linha e grava conforme o modo, dentro de uma transação. Devolve o resumo; $res['valido'] diz se deu certo. Não aceita a opção columns (lê a estrutura real); para isso use process().

$res = SheetToTableHelper::import($_FILES['planilha'], '#__desempenho', [
    'mode'       => 'upsert',
    'unique_by'  => ['NUM_CENTRAL', 'PRODUTO', 'DATA_BASE'],   // obrigatório no PostgreSQL; no MySQL usa as chaves únicas da tabela
    'batch_size' => 2000,
]);
// "Importação concluída: 18342 linha(s) gravadas."

validate()estático

SheetToTableHelper::validate(string|array $arquivo, string $tabela, array $opcoes = []): array

Confere só o cabeçalho contra a tabela, sem ler as linhas nem gravar. Rápido mesmo em arquivo enorme: use antes de enfileirar. Devolve o resultado de matchHeaders() mais cabecalho, linha_cabecalho, aba, campos_esperados, campos_fixos e campos_ignorados.

$v = SheetToTableHelper::validate($arquivo, '#__desempenho', ['require' => 'not_null']);

if (!$v['valido']) {
    echo SheetToTableHelper::missingMessage($v);
    // Importação cancelada. Faltam as seguintes colunas no arquivo: DATA_BASE (no arquivo há "DT_BASE"), PRODUCAO.
}

preview()estático

SheetToTableHelper::preview(string|array $arquivo, string $tabela, int $limite = 10, array $opcoes = []): array

Primeiras $limite linhas de dados já convertidas, inclusive as que têm erro, sem gravar. Devolve o resumo com linhas => [['linha' => 2, 'dados' => [...], 'erros' => [...]], ...]. Em dados, campo que receberá o padrão do banco aparece como null; campo com erro não aparece.

$p = SheetToTableHelper::preview($arquivo, '#__desempenho', 5, ['require' => 'not_null']);

foreach ($p['linhas'] as $l) {
    echo $l['linha'], ': ', json_encode($l['dados']), $l['erros'] ? ' ✗ ' . $l['erros'][0]['mensagem'] : ' ✓', "\n";
}
// 2: {"NUM_CENTRAL":"300","PRODUTO":"Crédito","DATA_BASE":"2026-11-17","PRODUCAO":"1234.56","OBS":"x"} ✓   (na ordem da tabela)

process()estático

SheetToTableHelper::process(string|array $arquivo, string $tabela, callable $callback, array $opcoes = []): array

Lê, valida e converte, e entrega lotes prontos para $callback(array $registros, int $numeroDoLote), sem gravar nada. Você grava como quiser (Eloquent, API, outro banco). Linhas com erro não entram nos lotes e aparecem em erros. Com on_error = rollback (padrão), para de entregar lotes no primeiro erro, mas segue lendo para listar todos. Com columns, não precisa de banco.

$res = SheetToTableHelper::process($arquivo, '#__desempenho', function (array $registros, $lote) {
    HttpHelper::post('https://erp.interno/api/producao/lote', ['itens' => $registros]);
}, ['on_error' => 'skip', 'batch_size' => 500]);

O process() não abre transação: se o seu callback gravar e um lote seguinte falhar, os anteriores ficam gravados. Para tudo ou nada, envolva a chamada numa transação sua (DbTransactionHelper::run(), DB::transaction()) e lance exceção no callback.

matchHeaders()estático

SheetToTableHelper::matchHeaders(array $campos, array $cabecalho, array $opcoes = []): array

Núcleo puro, sem banco nem arquivo: casa uma lista de campos com um cabeçalho. Opções: match, aliases, optional e extra_columns (veja opções de cabeçalho). Devolve valido, mensagem, faltantes, duplicados, extras, sugestoes ([CAMPO => 'cabeçalho parecido']) e mapeamento ([CAMPO => posição], vazio se inválido).

SheetToTableHelper::matchHeaders(['NUM_CENTRAL', 'DATA_BASE'], ['Data Base', 'num-central']);
// ['valido' => true, 'mapeamento' => ['NUM_CENTRAL' => 1, 'DATA_BASE' => 0], 'extras' => [], ...]

SheetToTableHelper::matchHeaders(['NUM_CENTRAL', 'DATA_BASE'], ['NUM_CENTRAL', 'DATA_BAS']);
// ['valido' => false, 'faltantes' => ['DATA_BASE'], 'sugestoes' => ['DATA_BASE' => 'DATA_BAS'],
//  'mensagem' => 'Importação cancelada. Falta a seguinte coluna no arquivo: DATA_BASE (no arquivo há "DATA_BAS").']

A sugestão aparece quando um cabeçalho que sobrou é pelo menos 75% parecido com o campo que falta. Ela nunca casa sozinha: é só uma dica na mensagem. Para aceitar outro nome, use aliases.

headers() / sheets()estático

SheetToTableHelper::headers(string|array $arquivo, array $opcoes = []): array SheetToTableHelper::sheets(string|array $arquivo, array $opcoes = []): array

headers() devolve ['cabecalho' => [...], 'linha' => 1, 'aba' => 'Dados', 'formato' => 'xlsx']: a primeira linha não vazia (ou header_row) da aba escolhida (sheet), com as colunas vazias do fim removidas. sheets() devolve os nomes das abas na ordem do arquivo; CSV devolve ['CSV']. Use para montar um <select> de abas antes de importar.

SheetToTableHelper::sheets('relatorio.xlsx');                                      // ['Resumo', 'Dados']
SheetToTableHelper::headers('relatorio.xlsx', ['sheet' => 'dados', 'header_row' => 3]);
// ['cabecalho' => ['NUM_CENTRAL', 'PRODUTO', 'DATA_BASE', 'PRODUCAO'], 'linha' => 3, 'aba' => 'Dados', 'formato' => 'xlsx']

template()estático

SheetToTableHelper::template(string $tabela, string $destino, array $opcoes = []): string

Grava em $destino um arquivo modelo só com o cabeçalho que a tabela espera (com as mesmas opções ignore, only, fixed da importação). .csv sai com ; (ou delimiter) e BOM, para o Excel abrir com acentos; .xlsx, .xls e .ods precisam da phpspreadsheet. Devolve o caminho. A pasta precisa existir e ter permissão de escrita.

SheetToTableHelper::template('#__desempenho', JPATH_SITE . '/tmp/modelo.xlsx', ['ignore' => ['CRIADO_EM']]);

tableColumns() / expectedColumns()estático

SheetToTableHelper::tableColumns(string $tabela, array $opcoes = []): array SheetToTableHelper::expectedColumns(string $tabela, array $opcoes = []): array

tableColumns() devolve a estrutura interpretada de cada coluna: [NOME => ['name', 'type', 'base', 'int_kind', 'length', 'bytes', 'unsigned', 'precision', 'scale', 'enum', 'nullable', 'default', 'has_default', 'auto', 'generated', 'required_value']]. base é o tipo usado na conversão (int, decimal, date, datetime, timestamp, time, year, enum, json, uuid, bool ou text); required_value é NOT NULL sem padrão. expectedColumns() devolve a lista de colunas que o arquivo precisa ter com as opções informadas: mostre na tela de importação.

SheetToTableHelper::expectedColumns('#__desempenho');                              // ['NUM_CENTRAL', 'PRODUTO', 'DATA_BASE', 'PRODUCAO', 'SITUACAO', 'OBS', 'CRIADO_EM']
SheetToTableHelper::expectedColumns('#__desempenho', ['require' => 'not_null']);   // ['NUM_CENTRAL', 'PRODUTO', 'DATA_BASE', 'PRODUCAO']

missingMessage() / errorLines()estático

SheetToTableHelper::missingMessage(array $resultado): string SheetToTableHelper::errorLines(array $resultado, int $limite = 100): array

missingMessage() devolve o texto do alerta de cabeçalho, ou '' se o resultado é válido. errorLines() transforma erros em frases prontas: "Linha 37, campo DATA_BASE: Data inválida: \"31/02/2026\"." (sem o trecho do campo quando o erro é da linha inteira).

supportedExtensions() / supportsPhpSpreadsheet() / clearCache() / exportRecord()estático

SheetToTableHelper::supportedExtensions(): array SheetToTableHelper::supportsPhpSpreadsheet(): bool SheetToTableHelper::clearCache(): void SheetToTableHelper::exportRecord(array $registro, bool $comoNull = false): array

supportedExtensions(): csv, txt, tsv, xlsx, xlsm e, com a phpspreadsheet, xls e ods; use no accept do formulário e no allowed_extensions do UploadMaster. clearCache() esquece a estrutura das tabelas lida nesta requisição (chame depois de um ALTER TABLE no mesmo script). exportRecord() tira de um registro a marca interna "use o padrão do banco" (ou a troca por null); o process() e o preview() já chamam por você.

runFor() e writeBatchFor() são públicos só porque são chamados de dentro de closures; não use direto.

Modos de gravação (mode)

ModoApelidosO que fazSQL
append (padrão)insertInsere junto com o que já existe. Linha com chave única repetida é erro.INSERT
replacetruncate_insertApaga e insere o arquivo, na mesma transação: se der erro, o que foi apagado volta. Sem filtro apaga tudo.DELETE + INSERT

Filtros do replace (use um ou outro):

// Apaga só o que bate com o filtro. Valor array = IN; null = IS NULL; array vazio = não apaga nada.
'mode' => 'replace', 'replace_where' => ['DATA_BASE' => '2026-11-17', 'NUM_CENTRAL' => [300, 301]],

// Apaga só as chaves que vieram no arquivo: o arquivo de novembro troca novembro e não mexe em outubro.
// Cada chave é apagada uma vez, antes do primeiro lote em que aparece.
'mode' => 'replace', 'replace_by' => ['DATA_BASE'],
'mode' => 'replace', 'replace_by' => ['NUM_CENTRAL', 'DATA_BASE'],   // combinação de colunas

replace_by apaga pela chave em toda a tabela, de qualquer dono. Em tabela com dados de vários usuários ou cooperativas, use replace_where com o dono vindo do servidor (UserHelper::singular()) e o dono também em fixed, como no exemplo completo.

replace_strategy

'delete' (padrão) apaga com DELETE dentro da transação. 'truncate' usa TRUNCATE (mais rápido em tabela enorme, zera o AUTO_INCREMENT), só sem filtro, e roda antes da transação: se a importação falhar, os dados antigos não voltam. No MySQL o TRUNCATE confirma na hora, então ele exige 'atomic' => false. Use sempre com 'validate_first' => true, que lê e valida o arquivo inteiro antes de apagar.

SheetToTableHelper::import($arquivo, 'dw_fato_producao', [
    'mode' => 'replace', 'replace_strategy' => 'truncate', 'atomic' => false, 'validate_first' => true,
]);

Segurança

  • SQL: os valores vão sempre por bindings; nomes de tabela e de coluna saem da estrutura do banco (nunca do arquivo) e passam por quoteName. Nome de tabela fora de [A-Za-z0-9_#$.] é recusado.
  • XML: o XLSX é lido com LIBXML_NONET, sem acesso à rede.
  • Quem pode importar: o helper não confere permissão. Exija token e permissão no controller (PermissionHelper, UserHelper::requireGroup()).
  • Dono dos dados: campos como usuário, empresa ou cooperativa vêm do servidor em fixed. Com replace, limite o DELETE ao dono com replace_where.
  • Upload: XLSX é um ZIP; o isSafeFile() do Joomla recusa ZIPs por engano, então leia o campo com InputHelper::file($nome, null, true). Restrinja a extensão no formulário e no servidor com supportedExtensions().
  • Mensagens: erros do PHP e do banco nunca chegam ao usuário; vão para o log. Com 'show_db_errors' => false, nem o detalhe do banco por linha.
  • Saída: os valores da planilha voltam em erros e na prévia. Mostre com textContent ou htmlspecialchars(), nunca como HTML.

PostgreSQL

  • upsert precisa de 'unique_by' => [...] (as colunas da restrição única). insert_new sem unique_by usa ON CONFLICT DO NOTHING em qualquer restrição.
  • serial, bigserial, nextval() e GENERATED ... AS IDENTITY são detectados como automáticos. Coluna preenchida por trigger: informe em auto.
  • timestamp do PostgreSQL aceita qualquer data comum (o limite 1970–2038 é só do TIMESTAMP do MySQL).
  • Cada lote roda num savepoint: um erro do banco não aborta a transação inteira (o "current transaction is aborted" do PostgreSQL).
