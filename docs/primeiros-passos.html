Primeiros passos

Instale os arquivos, faça o primeiro CRUD e a primeira transação em poucos minutos.

Instalação

  1. Copie os quatro arquivos para a pasta de helpers do seu componente, por exemplo components/com_loja/helpers/:

    components/com_loja/helpers/
├── DbConnectionHelper.php
├── DbTransactionHelper.php
├── OrmBase.php
└── OrmTables.php

  2. Carregue onde for usar (controller, model, script). Um único require_once basta:

    require_once JPATH_SITE . '/components/com_loja/helpers/OrmTables.php';

    Cada arquivo carrega o que precisa:

    Arquivo carregadoTambém carrega
    OrmTables.phpOrmBase.php, DbTransactionHelper.php, DbConnectionHelper.php
    OrmBase.phpDbTransactionHelper.php, DbConnectionHelper.php
    DbTransactionHelper.phpDbConnectionHelper.php
    DbConnectionHelper.php(nada)

  3. Pronto. Não há configuração obrigatória: tudo usa a conexão do Joomla (JFactory::getDbo()) até você registrar outra.

Só dentro do Joomla

Todos os arquivos começam com defined('_JEXEC') or die;. Eles só funcionam dentro do Joomla, inclusive em scripts CLI que façam o bootstrap do Joomla.

Tabela usada nos exemplos

Os exemplos desta documentação usam uma loja simples. O prefixo #__ é trocado automaticamente pelo prefixo das tabelas do Joomla (por exemplo, jos_).

MySQL
CREATE TABLE `#__loja_produtos` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `nome` VARCHAR(150) NOT NULL,
  `preco` DECIMAL(10,2) NOT NULL DEFAULT 0,
  `estoque` INT NOT NULL DEFAULT 0,
  `ativo` TINYINT(1) NOT NULL DEFAULT 1,
  `created_at` DATETIME NULL,
  `updated_at` DATETIME NULL
) ENGINE=InnoDB;
PostgreSQL
CREATE TABLE jos_loja_produtos (
  id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,
  nome VARCHAR(150) NOT NULL,
  preco NUMERIC(10,2) NOT NULL DEFAULT 0,
  estoque INTEGER NOT NULL DEFAULT 0,
  ativo BOOLEAN NOT NULL DEFAULT TRUE,
  created_at TIMESTAMP NULL,
  updated_at TIMESTAMP NULL
);

As colunas created_at e updated_at existem porque o OrmBase as preenche sozinho por padrão. Se a sua tabela não tiver essas colunas, passe ['timestamps' => false]. Veja timestamps.

Seu primeiro CRUD

Criar

$produto = OrmTables::table('#__loja_produtos')->create([
    'nome' => 'Caneta azul',
    'preco' => 2.50,
    'estoque' => 100,
]);

echo $produto->id;          // id gerado pelo banco
echo $produto->created_at;  // preenchido automaticamente

create() devolve o registro recém-gravado, lido de volta do banco, como stdClass.

Ler

$produtos = OrmTables::table('#__loja_produtos');

$um = $produtos->find(1);                          // por id, ou null

$ativos = $produtos
    ->where('ativo', 1)
    ->where('preco', '<=', 10)
    ->orderBy('nome')
    ->get();                                       // array de stdClass

foreach ($ativos as $produto) {
    echo $produto->nome . ' - ' . $produto->preco . PHP_EOL;
}

$total = $produtos->where('ativo', 1)->count();    // int

Reaproveitar a variável $produtos é seguro: cada método que executa a consulta (get, count, first…) limpa os filtros ao terminar, mesmo quando dá erro. Veja o ciclo de uma consulta.

Atualizar

// Um registro, pelo id: devolve o registro atualizado
$produto = OrmTables::table('#__loja_produtos')->update(1, [
    'preco' => 2.90,
]);

// Vários registros, pelos filtros: devolve quantas linhas mudaram
$alterados = OrmTables::table('#__loja_produtos')
    ->where('estoque', 0)
    ->updateWhere(['ativo' => 0]);

Excluir

OrmTables::table('#__loja_produtos')->delete(1);

$removidos = OrmTables::table('#__loja_produtos')
    ->where('ativo', 0)
    ->deleteWhere();

updateWhere() e deleteWhere() sem nenhum filtro lançam erro, para você não alterar a tabela inteira por engano. Veja allowMassOperation().

Sua primeira transação

Quando várias gravações precisam acontecer juntas (todas ou nenhuma), coloque-as dentro de DbTransactionHelper::run(). Se qualquer exceção acontecer lá dentro, tudo é desfeito.

try {
    $pedido = DbTransactionHelper::run(function () {
        $pedido = OrmTables::table('#__loja_pedidos')->create([
            'cliente_id' => 7,
            'status' => 'aberto',
        ]);

        $produto = OrmTables::table('#__loja_produtos')->decrement(10, 'estoque', 2);

        if ($produto->estoque < 0) {
            // A exceção desfaz o pedido E a baixa de estoque
            throw new RuntimeException('Estoque insuficiente.');
        }

        return $pedido;
    });
} catch (RuntimeException $e) {
    echo $e->getMessage();
}
