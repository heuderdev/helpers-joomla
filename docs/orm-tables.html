OrmTables

Use o ORM direto, sem criar classes: uma linha para consultar qualquer tabela, em qualquer conexão.

Visão geral

O OrmTables é a porta de entrada mais curta para o ORM. Ele cria instâncias de OrmBase sem que você precise escrever uma classe. O objeto devolvido tem todos os métodos do OrmBase: consultas, escrita, transações, travas e outras conexões.

require_once JPATH_COMPONENT . '/helpers/OrmTables.php';

$produtos = OrmTables::table('#__loja_produtos')
    ->where('ativo', 1)
    ->orderBy('nome')
    ->get();

Há duas formas de uso:

FormaComoQuando
DiretaOrmTables::table('#__tabela', $opcoes)Consultas pontuais. A configuração vai na chamada.
RegistradaOrmTables::register('nome', '#__tabela', $opcoes) uma vez, e depois OrmTables::get('nome')A mesma tabela usada em vários lugares, configurada uma vez só.

As opções ($opcoes) são as mesmas do construtor do OrmBase: casts, fillable, guarded, timestamps, softDeletes, primaryKey, connection… Veja a lista completa.

Métodos

table()estático

OrmTables::table(string $table, array $opcoes = []): OrmBase

Cria uma instância nova do ORM para a tabela. Cada chamada devolve um objeto novo, sem filtros.

ParâmetroTipoDescrição
$tablestringNome da tabela, normalmente com #__. Aceita alias para consultas: '#__loja_produtos AS p'.
$opcoesarrayOpções de configuração.

Retorna: OrmBase.

// Mínimo
$total = OrmTables::table('#__loja_pedidos')->count();

// Com opções
$pedidos = OrmTables::table('#__loja_pedidos', [
    'softDeletes' => true,
    'casts' => ['total' => 'float', 'metadados' => 'json'],
]);

$recentes = $pedidos->latest()->limit(10)->get();

// Em outro banco
$clientes = OrmTables::table('#__clientes', ['connection' => 'erp'])->get();

// Tabela sem created_at/updated_at
OrmTables::table('#__loja_logs', ['timestamps' => false])->create([
    'mensagem' => 'Importação concluída',
]);

Alias no nome da tabela ('#__x AS x') funciona em consultas (get, join…), mas não em create, update e delete. Para gravar, use o nome sem alias.

make()estático

OrmTables::make(string $table, array $opcoes = []): OrmBase

Sinônimo de table().

register()estático

OrmTables::register(string $nome, string $table, array $opcoes = []): OrmBase

Guarda uma configuração de tabela com um nome, para reutilizar com get(). Registrar de novo o mesmo nome substitui a configuração. Devolve uma instância pronta para uso.

ParâmetroTipoDescrição
$nomestringNome curto, à sua escolha.
$tablestringTabela.
$opcoesarrayOpções de configuração.
// No carregamento do componente
OrmTables::register('produtos', '#__loja_produtos', [
    'casts' => ['preco' => 'float', 'estoque' => 'int', 'ativo' => 'bool'],
    'fillable' => ['nome', 'preco', 'estoque', 'ativo'],
]);

OrmTables::register('pedidos', '#__loja_pedidos', [
    'softDeletes' => true,
    'casts' => ['total' => 'float'],
]);

OrmTables::register('clientesErp', '#__clientes', ['connection' => 'erp']);

get()estático

OrmTables::get(string $nome, string|null $table = null, array $opcoes = []): OrmBase

Devolve uma cópia nova da instância registrada. Como é uma cópia, os filtros de uma consulta nunca vazam para outra. Se o nome ainda não foi registrado e você passar $table, registra e devolve. Sem $table e sem registro, lança InvalidArgumentException.

$baratos = OrmTables::get('produtos')->where('preco', '<', 5)->get();
$total = OrmTables::get('produtos')->count();     // não herda o where acima

// Registra na primeira chamada, se ainda não existir
$logs = OrmTables::get('logs', '#__loja_logs', ['timestamps' => false]);

Se o nome já estiver registrado, $table e $opcoes são ignorados: vale o registro existente. Para mudar a configuração, use register().

has()estático

OrmTables::has(string $nome): bool

Indica se o nome foi registrado.

forget()estático

OrmTables::forget(string $nome): bool

Remove um registro. Devolve true se ele existia.

flush()estático

OrmTables::flush(): void

Remove todos os registros. Útil em testes e scripts longos.

all()estático

OrmTables::all(): string[]

Lista os nomes registrados.

Os registros ficam em memória e duram um request, ou uma execução de script CLI. Registre no carregamento do componente para que estejam disponíveis em todas as telas.

Exemplo completo: controller sem models

controllers/produtos.php
<?php

defined('_JEXEC') or die;

require_once JPATH_COMPONENT . '/helpers/OrmTables.php';
require_once JPATH_COMPONENT . '/helpers/ApiResponseHelper.php';
require_once JPATH_COMPONENT . '/helpers/InputHelper.php';

class LojaControllerProdutos extends JControllerLegacy
{
    protected function produtos()
    {
        return OrmTables::table('#__loja_produtos', [
            'casts' => ['preco' => 'float', 'estoque' => 'int', 'ativo' => 'bool'],
            'fillable' => ['nome', 'preco', 'estoque', 'ativo'],
        ]);
    }

    public function listar()
    {
        try {
            $resultado = $this->produtos()
                ->where('ativo', true)
                ->when(InputHelper::string('busca', '', 'get'), function ($q, $busca) {
                    $q->whereLike('nome', $busca);
                })
                ->orderBy('nome')
                ->paginate(20, InputHelper::uint('pagina', 1, 'get'));

            return ApiResponseHelper::paginated($resultado, 'Produtos carregados.');
        } catch (Throwable $e) {
            return ApiResponseHelper::exception($e);
        }
    }

    public function salvar()
    {
        try {
            $id = InputHelper::uint('id', 0, 'post');
            $dados = [
                'nome' => InputHelper::string('nome', '', 'post'),
                'preco' => InputHelper::decimal('preco', 0, 'post'),
                'estoque' => InputHelper::uint('estoque', 0, 'post'),
            ];

            $produto = $id > 0
                ? $this->produtos()->update($id, $dados)
                : $this->produtos()->create($dados);

            return ApiResponseHelper::success('Produto salvo.', $produto);
        } catch (Throwable $e) {
            return ApiResponseHelper::exception($e);
        }
    }

    public function excluir()
    {
        try {
            $this->produtos()->delete(InputHelper::uint('id', 0, 'post'));

            return ApiResponseHelper::deleted();
        } catch (Throwable $e) {
            return ApiResponseHelper::exception($e);
        }
    }
}

O método produtos() do controller centraliza a configuração da tabela. É um passo intermediário natural antes de um model: quando a configuração começar a se repetir em outros controllers, mova-a para uma classe.
