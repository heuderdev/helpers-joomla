FormatHelper

Formatação brasileira para telas, e-mails, PDFs e exportações: dinheiro (inclusive em centavos, sem erro de ponto flutuante), números, CPF/CNPJ, CEP, telefone, slug, resumo de texto, bytes, plural e nomes próprios.

Visão geral

require_once JPATH_COMPONENT . '/helpers/FormatHelper.php';

echo FormatHelper::money($pedido->total);              // R$ 1.234,50
echo FormatHelper::cpfCnpj($cliente->documento);       // 123.456.789-09 ou 11.222.333/0001-81
echo FormatHelper::phone($cliente->celular);           // (11) 98765-4321
echo FormatHelper::limit($produto->descricao, 120);    // resumo sem cortar palavra, sem HTML
echo FormatHelper::plural($total, 'pedido', 'pedidos', 'Nenhum pedido');

Nunca lança exceção: um valor que não dá para formatar volta como veio (texto) ou vazio (null, texto que não é número). Funciona sem a extensão mbstring. Na view, escape o resultado como qualquer texto (htmlspecialchars).

Dinheiro e números

MétodoEntradaSaída
money($v, $simbolo = true, $casas = 2)1234.5, '1234.5', '1.234,50', -10R$ 1.234,50, -R$ 10,00 (sem símbolo: 1.234,50)
moneyFromCents($centavos)123456R$ 1.234,56
toCents($v)'R$ 1.234,56', '19.9', 0.1 + 0.2123456, 1990, 30 (null se não for número)
toNumber($v)'1.234,56', '1,234.56', '12,5%'1234.56, 1234.56, 12.5
number($v, $casas = 2) / integer($v)1234.5671.234,57 / 1.235
percent($v, $casas = 1, $fracao = false)12.5 (ou 0.125 com $fracao)12,5%
bytes($n)15361,5 KB

Com um único separador, ele é o decimal ('10,5' e '10.5' são 10,5), como no ValidationHelper e no Vigia.js.

Centavos para somar e cobrar 0.1 + 0.2 é 0.30000000000000004 em ponto flutuante. Para somar itens, aplicar desconto ou enviar a um gateway (que trabalha em centavos), converta com toCents(), faça a conta com inteiros e formate com moneyFromCents(). No banco, use DECIMAL(12,2) ou inteiro em centavos, nunca FLOAT.

$totalCentavos = 0;

foreach ($itens as $item) {
    $totalCentavos += FormatHelper::toCents($item->preco) * (int) $item->quantidade;
}

$desconto = (int) round($totalCentavos * 0.10);   // 10%
echo FormatHelper::moneyFromCents($totalCentavos - $desconto);

Formatar não valida: um CPF com dígito errado sai formatado. Valide com o ValidationHelper (cpf, cnpj) antes de gravar. Para esconder parte do documento, use CryptoHelper::mask().
