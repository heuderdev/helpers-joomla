DbConnectionHelper

Registro de conexões de banco. Use o banco do Joomla por padrão e outros bancos por nome.

Visão geral

O DbConnectionHelper decide qual banco cada consulta usa. Sem configuração, é sempre a conexão do Joomla. Para consultar outro banco (um ERP, um sistema legado, um banco de relatórios), registre a conexão uma vez com um nome e use esse nome onde precisar.

// 1. Registrar (uma vez, no carregamento do componente)
DbConnectionHelper::register('erp', [
    'driver' => 'pgsql',
    'host' => 'erp.interno',
    'user' => 'loja',
    'password' => 'segredo',
    'database' => 'erp',
    'prefix' => 'erp_',
]);

// 2. Usar
$clientes = OrmTables::table('#__clientes', ['connection' => 'erp'])->get();

Os outros helpers aceitam a opção connection, sempre com o mesmo significado:

Valor de connectionConexão usada
ausente ou nullA do Joomla (JFactory::getDbo())
'default'A do Joomla
nome registrado, ex.: 'erp'A conexão registrada com esse nome
um objeto driverEsse driver, sem precisar registrar

Onde registrar

Registre num ponto que roda antes de qualquer consulta: o arquivo de entrada do componente, um helper de bootstrap ou o display() do controller principal. Registrar não abre a conexão: ela só conecta no primeiro uso, então registrar sem usar não custa nada.

Lendo os dados da configuração do componente
// components/com_loja/loja.php (ou o bootstrap do seu componente)
require_once JPATH_COMPONENT . '/helpers/OrmTables.php';

$params = JComponentHelper::getParams('com_loja');

if (!DbConnectionHelper::has('erp')) {
    DbConnectionHelper::register('erp', [
        'driver' => $params->get('erp_driver', 'pgsql'),
        'host' => $params->get('erp_host'),
        'port' => (int) $params->get('erp_port', 5432),
        'user' => $params->get('erp_user'),
        'password' => $params->get('erp_password'),
        'database' => $params->get('erp_database'),
        'prefix' => $params->get('erp_prefix', ''),
    ]);
}
Credenciais

Não deixe usuário e senha fixos no código-fonte. Use os parâmetros do componente, o configuration.php ou variáveis de ambiente.

Opções de configuração

ChaveObrigatóriaDescrição
driversimTipo de banco. Veja a tabela de drivers abaixo.
hostsimEndereço do servidor.
portnãoPorta. Padrão do banco: 3306 (MySQL) ou 5432 (PostgreSQL).
usersimUsuário.
passwordsimSenha.
databasesimNome do banco.
prefixnãoValor que substitui #__ nas consultas desta conexão. Ex.: com 'erp_', #__clientes vira erp_clientes.
outrasnãoQualquer outra chave é repassada ao driver do Joomla sem alteração.

O nome do driver pode ser escrito de várias formas. O helper converte para o nome que a versão do Joomla em execução espera:

Você escreveJoomla 3Joomla 4 / 5
mysql, mysqli, mariadbmysqlimysqli
pdomysqlpdomysqlmysql (PDO)
pgsql, postgres, postgresqlpostgresqlpgsql

A versão é detectada sozinha: com Joomla\Database\DatabaseFactory disponível (Joomla 4/5), é ele que cria o driver; senão, JDatabaseDriver::getInstance() (Joomla 3).

Métodos

register()estático

DbConnectionHelper::register(string $nome, array|object $configuracaoOuDriver): void

Registra uma conexão com um nome. Aceita um array de configuração (a conexão é criada no primeiro uso) ou um driver já criado.

ParâmetroTipoDescrição
$nomestringNome da conexão. Não pode ser vazio nem 'default'.
$configuracaoOuDriverarray|objectArray com as opções (exige driver) ou um objeto driver do Joomla.
// Com configuração
DbConnectionHelper::register('relatorios', [
    'driver' => 'mysql',
    'host' => 'replica.interna',
    'user' => 'leitura',
    'password' => 'segredo',
    'database' => 'loja',
    'prefix' => 'jos_',
]);

// Com um driver que você já tem
DbConnectionHelper::register('legado', $driverLegado);

Registrar de novo um nome existente substitui o registro anterior. Se a conexão antiga já estava aberta, ela não é fechada. Chame forget() antes para fechá-la.

get()estático

DbConnectionHelper::get(string|null $nome = null): object

Devolve o driver da conexão. Sem nome, com null, '' ou 'default', devolve a conexão do Joomla. Na primeira chamada de um nome registrado por configuração, cria o driver; nas seguintes, devolve a mesma instância.

ParâmetroTipoDescrição
$nomestring|nullNome registrado.

Retorna: o driver do Joomla.

$db = DbConnectionHelper::get('erp');

$query = $db->getQuery(true)
    ->select('COUNT(*)')
    ->from($db->quoteName('#__clientes'));

$total = (int) $db->setQuery($query)->loadResult();

Lança InvalidArgumentException se o nome não estiver registrado.

resolve()estático

DbConnectionHelper::resolve(string|object|null $conexao = null): object

Igual a get(), mas também aceita um objeto driver, que é devolvido como está. É o que os outros helpers usam para interpretar a opção connection. Útil nas suas próprias funções que também querem aceitar "nome ou driver".

function contarClientes($conexao = null)
{
    return OrmTables::table('#__clientes', ['connection' => DbConnectionHelper::resolve($conexao)])
        ->count();
}

contarClientes();          // banco do Joomla
contarClientes('erp');     // banco do ERP

has()estático

DbConnectionHelper::has(string $nome): bool

Indica se o nome está registrado. 'default' sempre existe.

if (!DbConnectionHelper::has('erp')) {
    DbConnectionHelper::register('erp', $config);
}

forget()estático

DbConnectionHelper::forget(string $nome): bool

Remove o registro e fecha a conexão, se ela estiver aberta e o driver tiver disconnect(). Devolve true se o nome existia.

// Script longo que só precisava do legado no começo
DbConnectionHelper::forget('legado');

all()estático

DbConnectionHelper::all(): string[]

Lista os nomes conhecidos, sempre começando por 'default'.

print_r(DbConnectionHelper::all());   // ['default', 'erp', 'relatorios']

serverType()estático

DbConnectionHelper::serverType(string|object|null $conexao = null): string

Tipo do servidor da conexão: DbConnectionHelper::MYSQL (MySQL e MariaDB), DbConnectionHelper::POSTGRESQL ou, para outros bancos, o nome informado pelo driver.

if (DbConnectionHelper::serverType('erp') === DbConnectionHelper::POSTGRESQL) {
    // SQL específico do PostgreSQL
}

isPostgres() / isMysql()estático

DbConnectionHelper::isPostgres(string|object|null $conexao = null): bool DbConnectionHelper::isMysql(string|object|null $conexao = null): bool

Atalhos para serverType(). Use para escrever SQL cru diferente em cada banco, que é raro: o ORM já adapta o SQL que ele gera.

$agora = DbConnectionHelper::isPostgres('erp') ? 'NOW()' : 'CURRENT_TIMESTAMP()';
